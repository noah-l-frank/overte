# Original Lifecycle input ownership

This closes the ordinary field/Back input and lost-return component beside the
[editor history](LIFECYCLE_EDITOR_HISTORY.md). Feature 14 remains partial and its
complete capability is closed. Native sources are uncompiled; no device or
simulator execution is claimed.

The existing normal input observer has a third closed Lifecycle profile. Avatar
remains its default and Snapshot retains its separate original literal. Only
the dedicated iOS E2E build records Lifecycle inputs. The observer reads the
actual control selected by the original token before the one existing `edit`
dispatch, then retains its actual return. It sends no input itself. The profile
accepts only the Create initial-text field, unsent Chat draft, Scripts filter
and actual semantic tablet Back. Submit, unrelated navigation/private fields
and arbitrary text are excluded.

The native originals retain both outer/inner request IDs, the actual field's
weak context/root/window/loader identity or the actual Back source/history,
original event clocks and exact positive or negative delivery return. A return
without the matching original reception cannot resolve an uncertain input.
The closed `feature-ios-lifecycle-inputs` probe consumes each nonce once and
uses the existing atomic private writer and AFC path. Missing native support is
unavailable, never an empty successful history.

`LifecycleInputOwner` is a closed profile of the existing `SnapshotInputOwner`
WAL and immutable proof store. Protected profile hooks preserve the Snapshot
and Photos defaults, exact old schemas and stable-root rule. Lifecycle retains
each original context separately while preserving native instance/sequence,
PID and installed binding. Before delivery it rechecks the current actual
field/token/root/text or Back source/history. Issued intent is durable before
HTTP transport. Closed Unicode/reply/retry strings are bound to the actual run;
unowned drafts cannot be cleared or adopted.

A successful direct receipt reports delivery only. It does not supply text,
focus, keyboard, generation, navigation or world facts. A lost return stays
issued. Recovery adopts only its exact original native reception/return and
saves that packet in a private immutable proof file. It neither repeats input
nor refreshes the original clocks. Negative/missing receipts and changed roots
remain unresolved. File-only historical reads preserve the same limited result.

The canonical `_lifecycle_inputs` and `_lifecycle_input_runtime` reuse the
existing installed Script/session/native-clock gates. A runtime input scope
holds the original source lock; its reader cannot be used after that scope
ends. No new session, editor opening or app launch is performed. The unbound
adapter refuses these factories. Refused durable intent also prevents every
native pending-owner mutation; the default successful callback behavior remains
unchanged.

Ordinary installed describe/invoke/cleanup and component cleanup refuse any
unresolved Lifecycle namespace before SDK teardown. No complete Lifecycle
restoration/quiet/end proof exists yet, so delivered input or a retained editor
archive cannot silently retire that responsibility. The internal source/runtime
recovery paths remain available through their unchanged candidate guards.
