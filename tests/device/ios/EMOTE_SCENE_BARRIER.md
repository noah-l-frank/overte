# Original camera and scene readiness

The complete Emote owner requires both roles' actual initial raw GPU/PNG owners
before either role performs ordinary Scope camera setup. Each cleanup/finalization
fence similarly follows both roles' actual released Scope, restored body/view,
returned dialog/listener and EntityTree API-return/weak-expiry originals.

The marker script creates a local entity. This barrier does not presume that
marker replication exists: the real `MyAvatar::getSkeletonPosition()` path can
add `_skeletonOffset` in LOOK_AT mode, including in outbound avatar data. A normal
camera change with a nonzero offset may therefore affect the other target's
frame. Successful full-frame equality alone would reject the legitimate bad
schedule instead of preventing it.

`IOSEmoteSceneGate` retains closed private host precondition originals, never
feature projections. Its original installed/process admission is reciprocal and
binds the actual existing SDK directories, run, roles, targets, process births,
source, phase instance and ticket. A candidate is input readiness metadata until
the exact immutable original has been decoded. Its acquisition cannot supply a
clip, pose, expected outcome or cleanup result. No endpoint or shared fixture
projection is added.

The public operation's existing deadline includes waiting. `retry_scene` yields
through both existing source-lock finally blocks and polls only outside both
locks. On reacquisition it verifies the actual unchanged phase, fully decodes the
other original, then acquires its own passive privacy-qualified Keys2/native
clock receipt. That own receipt causally follows the read and precedes the normal
camera change or cleanup fence. Native clocks from different devices are never
compared. Missing/foreign originals or a lost partial host write retain ownership;
a complete unchanged original can be adopted without reacquiring its endpoint.
After phase retirement, an already admitted exact immutable peer scene endpoint
can be reused when that peer has retired fixed metadata. No peer SDK is reopened.

The gate and carrier schemas are v1. New final archives are v2, require the gate
in their deterministic paths, and replay every initial/cleanup temporal join.
An independent read-only inventory lease protects all fully decoded local and
foreign originals throughout the historical replay. Carrier membership is only
ownership membership. Final-copy DTOs stay v1. Genuine final-archive v1 envelopes
and copies remain readable with their original pre-barrier path grammar and are
never relabeled as v2. A missing gate cannot qualify a new v2 archive. Session
teardown treats any remaining role gate metadata as unresolved responsibility.

Targeted host checks cover both stage orderings, foreign process and held locks,
unknown host-write return, historical replay without new peer reads, genuine
GPU/PNG originals, retained weak objects, actual Keys2/native ACK after the peer
read, unchanged operation deadlines, independently authored v1 archive/copy bytes,
and native override/restore history crossing the untouched barrier. The sources
are not compiled and no iOS/device execution is claimed.
