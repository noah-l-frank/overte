# Independent original Worlds observations and publication

`NavigationObserver` reserves distinct role/stage/request ownership before
invoking the existing `NavigationObservationOwner`. Its version-1 private ledger
stores references to the actual original carriers rather than repacking their
compressed sources. The `ios-navigation-observed` version-1 return contains
derived state, original acquisition beginning, original image name/hash, actual
native endpoint and exact owner hash. It is a private measurement, not the whole
public feature operation or proof of cleanup.

Each accepted measurement reopens the actual sealed image archive, original
owner and PNG. An embedded image archive cannot replace a missing or modified
sealed file. All predecessor source floors remain active, including explicitly
abandoned source prefixes. Marker-pending, source-failed and unresolved image
attempts yield no public state. A reconstructed pending acquisition can adopt
its complete retained old result or explicitly abandon its retained source
prefix. It cannot repeat a capture or source query. A new fresh measurement
always has another request identity. Historical `latest()` does not become a
fresh acquisition or publication merely because it is read again.

The supplied URL/label is a capture intent. Original scene, physics, view,
challenge and feature pixels must independently establish that location.
Requested checkpoint state is never supplied. Missing or ignored navigation
therefore cannot turn a requested B into measured B. Per-role original facts
are acquired separately and never copied from a primary normalized result.

`IOSNavigationRuntime._navigation_observer` wires the existing candidate-gated
SDK session, source lock, native clocks, HTTP/AFC sources and Vulkan owner
factory. It creates no session, launches nothing and sends no product input.
The outer controller must still admit the original static scene, own normal
input, prove restart transfer and final restoration, and derive complete
resource inventories from actual lifetime/quiet sources.

Actor publication uses the existing `PhaseWitnessPublisher`, the separate
`Client` publisher authority and original fixture URL. Its callback reopens
the exact original owner rather than forwarding a primary normalized result.
The exact body is journaled before one POST. A lost
return blocks another send or measurement until an explicit passive journal
read rejoins the actual server receipt to the same original facts, sequence
and timestamp. Rejection or a missing receipt remains owned; absence of a
receipt cannot authorize a resend. An actual later phase or retired run may
resolve publication responsibility through the shared protocol; that proves
neither successful publication nor product cleanup. Each confirmed body and
receipt remains in the shared private immutable publication prefix. The fresh source deadline is checked
again after the durable publication intent, without restamping its beginning.
Primary observers cannot publish. Stage-1 publication is deliberately refused
until the whole coordinator joins actual process transfer and the cross-cohort
publication cursor; a stage number cannot prove restart or reset that cursor.

Host counterexamples cover actual actor HTTP authority, ignored pose input,
pending markers, lost acquisition/publication returns, explicit interrupted
source retirement, stale publication, slow intent storage, modified memory,
foreign journal clients, missing sealed archives and immutable publication
history across distinct tickets. Files, PNG decoding and the short-lived
loopback journal are real. Native/GPU/Qt/SDK boundaries and their clocks are
modeled. Native compilation and devices remain unverified. Worlds is partial;
the complete action/observation/cleanup coordinator remains required.
