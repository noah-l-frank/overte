# Lifecycle 14/14: owned held-world input component

This component joins an actual retained first intercepted World attempt with a
second, still-held ordinary contact. It does not complete Lifecycle, advertise
its capability, prove physical iOS timing or retire the existing installed
session. Complete areas remain 5/14; native sources remain uncompiled.

`IOSLifecycleWorldHoldRuntime.child` uses the existing canonical
`IOSScriptRuntime._sources` gate. The candidate, installed binding, selected
existing session, PID and foreground checks remain current. It requires the
actual original `LifecycleWorldAttempt` and original editor/history lock. It
creates no SDK session, installs nothing and opens no tunnel or service.

## Original order and ownership

The first attempt must already have its original intercepted Create-editor
contact proof. Its original text, keyboard and world proof are replayed without
another contact. The second attempt requires a later independently sampled
closed editor and hidden keyboard before acquiring fresh native geometry,
window and World originals. Geometry must lie inside their native clock join.
The mapped window/start/end coordinates alone enter the new WAL. No W3C
request, pause or future Up-body is stored or dispatched.

The caller supplies an **already owned authenticated touch-session factory**.
On the same retained actual context and HID object, the unchanged TouchLease1
worker sends an ordinary center Down. The same original 1.5s geometry/native/host
freshness bounds are checked again after authenticated context acquisition,
immediately before Down and before the upper move; acquisition cannot renew
that baseline. After fresh source continuity and the
original host deadline are checked, it sends one upper-pad move. The complete
coordinate path is durable before the initial Down. A lost Down or move return
is not resent. A pending original call keeps its original task/context and the
once-only ordinary Up follows only after that call settles. A late Down cannot
start a new move after release was requested or the original deadline passed.

TouchLease1's watchdog schedules a host release request against its existing
at-most-12s deadline. A stuck original transport call can delay physical release; this is
not a hard physical lifetime guarantee. Context exit returning is separately
reported and does not establish SDK, media-task, native-holder or process
absence. Failed release, failed exit or an absent retained worker stays owned.
An archived open journal cannot create another context or Down.

## Independent native proof

Host delivery does not supply World facts. Fresh original World2 packets must
independently join the new active Qt contact to the actual pad/native contact,
raw/effective forward drive, grounded avatar and measured 0.3–3m displacement.
The actual new contact must match the original mapped center and upper native
points within one native pixel; a nearby unrelated contact cannot lend effect.
An ACK with ignored movement remains unqualified. Each candidate original is
retained even if it cannot establish that held effect.

After ordinary Up/context exit, a separate original must show that exact
contact's terminal event, no active contact, no pad motion and zero raw and
effective drive. Four further original samples must then establish at least
three seconds of native stationarity about one anchor. Disabled nonzero raw
keys and even a completed intervening tap fail quiet qualification. Quiet
samples must have the same actual touch-event journal as the release original.
No old source timestamp, contact ID or event is relabeled.

The original FrameStore WAL retains planned/opened/saved responsibility and
actual immutable files. A saved held sample interrupted before parent append
is adopted from its exact inode/bytes without another query. The new private
files use the already closed `ios-lifecycle-` installed-session ownership fence;
they do not authorize generic SDK cleanup.

## Remaining production boundary

The repository still lacks a canonical RPC/factory that hands this component
the authenticated HID context for the selected installed session and retains
its worker/event loop across act, observe and release. The factory remains a
required explicit parameter; target values, a second tunnel or a fabricated
binding cannot substitute for it. Returning from an `asyncio.run` scope would
also destroy that ownership and is not a production integration.

Full Lifecycle composition, background/cancellation, holder retirement,
restoration, Actor evidence and canonical end remain open. A component's native
quiet or returned context exit is not their completion proof.
