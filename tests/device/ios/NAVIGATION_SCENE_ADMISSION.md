# Original static-scene admission prerequisites

`navigation_scene_admission.admit` validates necessary original conditions
before the first ordinary Worlds input. It does not send an input, prepare or
restore a scene, publish a state, own a process replacement or retire a run.
The whole scene coordinator and complete Worlds operation triple remain partial.
The [durable admission owner](NAVIGATION_ADMISSION_OWNER.md) now acquires and
retains this proof through the existing iOS runtime without replaying reads.

One original bounded native clock join covers eight actual sources: whole-tree
inventory, current navigation/physics/view, saved/loaded bookmarks, Places
model/preferences, HTTP lifetime, dialogs, native lookup replies and normal UI.
Every source must match the admitted installed-candidate/process binding. Native
source brackets must lie inside the original outer acquisition. Host acquisition,
client native time and original fixture-server time remain separate domains.

The independently attached static provider must be available, have an actual
completed socket receipt and match the selected source revision and instance.
The current native imported body/resource must match that static resource's
exact bytes/hash. The frozen native commit map must still equal the complete
current editable map. Exactly the five original static geometry IDs are admitted;
an additional unowned local/avatar/domain entity prevents leaving the scene.
The independently read current native navigation must retain the same scene
history/birth/generation, follow the inventory and show the supported grounded
root A, original orientation/scale and first-person view. A requested URL cannot
replace any of those actual conditions.

Admission refuses pre-existing visible or retained Go To roots, an open tablet,
retained Places roots, unknown error/dialog history or prior Places HTTP work.
The original bookmark map must load and agree with its real saved file, and
owned bookmark names must be absent. A real existing persistence file is required:
ordinary add/delete cannot restore physical nonexistence without removing a
product file behind its loaded object. The adapter does not do that as cleanup.
This is an explicit target preparation condition, not a fabricated default file.

The actual metaverse origin/protocol must match the selected controlled provider.
Pinned/fetched lists must be empty or absent, preserving their exact native type
and presence; the flow need not touch them. Maturity must already admit Everyone
through an unchanged supported value or the original absent/default path. This
component refuses a required checkbox change rather than claim an implemented
preference-restoration recipe. Actual page admission must still independently
observe Everyone in the loaded model when the page opens.

The version-1 private proof retains all unchanged originals, their original
clock join and digest, actual static provider source, original bookmark baseline
and native commit. `validate` recomputes that same proof. Historical validation
cannot refresh it. The durable admission owner saves it, retains partial
acquisition and enforces its original freshness deadline before ordinary input.
The whole scene coordinator must separately own input delivery, actual arrival, restart, callback
drainage, restored scene/body/map/pose/preferences and repeated quiet cleanup.

Host tests use real static loopback bytes and bookmark files with modeled
native/SDK/codec sources. They reject unsaved edits, unknown entities, wrong
body/source clocks, pre-existing UI, unsupported storage/preferences, source
replacement and stale/missing originals despite a newly recomputed outer hash.
Native compilation and all device functionality/timing remain unverified.
