# Source-driven Avatar cleanup inputs

`avatar_cleanup_plan.next_step` reads immutable historical Avatar sources and
chooses one narrow ordinary cleanup input. It joins wearable ownership to actual
script add-return originals and retained phase inputs; preserves all unowned
inventory and persisted bookmark bytes; restores original requested model and
scale; and waits for actual resource/geometry readiness instead of repeating a
setter. The People path requires the genuine completed connection table before
selecting a peer row for removal. A requested state or an input return cannot
replace that table.

`IOSAvatarCleanupControls.run(..., whole_clock=...)` can bind every admitted
cleanup step to the same original 25-second API deadline. Reconstruction checks
the stored clocks unchanged. The runtime factory uses the separate cleanup
input/read owners and the existing actual native UI client. Standalone callers
retain their previous per-step clock behavior.

Host composition runs ordinary appearance mutations and then four independently
chosen cleanup inputs, checking the actual original appearance sources after
each. An unrelated bookmark mutation refuses cleanup. Native producers remain
explicit synthetic seams; this packet does not implement whole paired cleanup
or qualify a device.
