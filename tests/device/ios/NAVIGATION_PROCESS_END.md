# Worlds once-only process and SDK end

`NavigationTerminal.finish` connects the original live seal to a separate final
process owner, SDK retirement and immutable final archive. The actual retired
phase/navigation/scene fixture authority must retain the final cleanup ticket.
The original installed-code/source binding is checked before normal Stop.
Typed live source/PNG graphs are decoded before pinning their original inode,
owner and file metadata. Only exact bounded coordinator/OS/session output names
are mutable. Changed source files prevent the input.

Normal `app.stop` owns installed-code retirement and ordinary `terminateApp`.
The final owner saves its Stop intent before transport and forbids SDK recreation.
A lost result permits only passive OS observations. Each logical role retains
its own genuinely issued DVT numeric-PID/bundle-state originals. At least three
samples must span three seconds in both controller and both original OS clocks.
The roles share one SDK and one Stop, with distinct OS original histories.
The owner now derives the original stage directly from the validated feature
journal. Original-process and post-restart end use their own exact OS namespaces;
neither path manufactures a transfer or reuses another stage's receipt.

SDK retirement preserves the actual session, retired installed-code record and
fresh OS absence original. GETs have durable pending/abandoned records. One
DELETE is retained before transport; an uncertain return is resolved solely by
another GET. An ignored DELETE acknowledgment is not absence. Only actual GET
404 permits removal of the same original local SDK/installed binding metadata.
A foreign replacement remains untouched. No fallback termination runs.

The final archive binds the original live seal, typed process windows, SDK 404
history and source inventory. Repeated finish decodes these originals without
SDK, fixture, native or GPU transport. Original live images and retained-root
metadata remain available; process death never becomes a new live observation.
A completed archive requires its actual completed process and SDK owners.
Missing or rolled-back owners reject reconstruction before any new acquisition,
Stop or SDK operation.

Ten focused host tests exercise actual loopback SDK/fixture HTTP, the existing
installed-code binding and native-bundle reader, private CAS journals and file
continuity. They cover separate role OS windows, original Node/controller clock
offset, lost Stop/DELETE/GET results, ignored DELETE, foreign SDK replacement,
slow Stop intent persistence, changed source bytes and transport-free repeat.
A fully rehashed role wrapper cannot reuse Primary's original OS nonces/counters
as independent Actor observations.
The live Navigation seal and OS/native producers are explicitly models in these
mechanics tests. A separate connected compact eight-step Navigation source/PNG
journey now passes the entire same-owner final end and actual worker exit:
ordinary restoration, original paired seal, one Stop, separate OS windows,
one DELETE/404/CAS and transport-free repeated finish/worker completion. Its
372 frozen source hashes remain unchanged. OS/native producers and clocks are
still explicit models; the qualified Python/HTTP/file/PNG joins are actual.
These tests qualify neither physical iOS behavior nor CPU/transport performance.

Worlds is still partial: error-interrupted/partial-setup restoration, canonical
configuration/dispatch and the full final fifteen-step run
remain open. No complete capability is advertised. Native compilation and all
devices remain untested.
