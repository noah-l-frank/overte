# Emote observation and retirement originals

This packet supplies internal Emote source, pixel and cleanup owners. The
complete Feature 5 adapter remains unfinished: final coordinator/archive/runtime
admission and whole journey tests are still required. It advertises no feature
capability. Native instrumentation remains uncompiled and unexecuted.

`emote_observation.py` reconstructs facts from actual private source originals,
selected installed Script/QML bytes, original Rig caller/history and current
loaded animation measurements. Requested names never select a Sit variant.
Actual native restore timing establishes early restoration. Actor facts use a
separate original acquisition on the independently qualified Primary SDK,
combined with the Actor SDK's received packets, Renderer4 external poses and
actual remote subject image. The Actor does not consume Primary public facts;
the two native clocks remain separate.

`emote_samples.py` retains the original pre-HUD Vulkan PNG, chunk transcript,
private inode, submitted capture and actual native GPU retirement. Original
World/Renderer4 bounds identify the subject independently of the controlled
marker. Both roles acquire actual Renderer4 inventories around the frame. The
entire marker projection and every other rendered Avatar projection must be
disjoint from the subject ROI; unknown mesh bounds fail closed. Marker-only changes cannot establish pose pixels. Failed challenges
remain original negative samples. `emote_sample_recovery.py` preserves returned
partial data and honestly empty files. A lost capture is never repeated; a lost
release is followed only by inspection. An identity reserved before native owner
creation requires an actual release tombstone, not an absent lookup alone.

`emote_observer.py` journals original acquisition before performing reads and
keeps each source/peer/sample owner until it can be resolved or preserved as an
abandoned passive attempt. Historical decoders use immutable original bytes and
never refresh their clocks or invoke an SDK/HTTP/installed-code guard. Actor
fact publication uses the independent phase witness journal and its existing
once-POST ownership rules.

`emote_cleanup.py` owns ordinary Cancel, Home, tablet close and pointer release.
It verifies the actual owned override before touching controls. Unknown delivery
never authorizes replay: exact native input sequence or actual subsequent SDK
state can settle appropriate lost returns; an uncertain pointer release retains
ownership rather than guessing whether a remote release arrived. Original Rig history
is never reset by cleanup.

`emote_file_receipts.py` preserves raw `NativeScriptFiles` observe commands and
returned exact pinned file bytes or actual absence, with the original native and
host acquisition bracket. Lost queries retain their original partial records and
are never resent. Raw receipts supplement the marker owner's normalized delivery
acknowledgments without changing the original marker v1 format.

`peer_admission.py` only reads an already prepared independent SDK's actual
installed binding and process source twice. It does not call `_sources()`,
`gate.verify()`, create a session, send native commands, write the installed-code
binding, or take the Actor source lock. Exact original admission binds later
paired retirement to the actual earlier candidate, target, session and process.

`emote_retirement.py` is the local historical native cleanup decoder. A valid
record requires the full actual released marker scope, callback-return and
listener-death originals, original Script terminal receipts, actual Web/UI/map
absence and restored body/view. Its repeated quiet interval excludes both end
acquisitions and spans at least three seconds in host and same-process native
clocks. Native file absence must follow that quiet interval. A later current
own-process original extends these immutable prefixes and proves the restored
scene; Actor and Primary native timelines are never compared across targets.
The separate closed-profile `OriginalMarkerEntities` owner retains the unchanged
CreateEntities native DTO. Its original pre-load baseline and post-quiet sample
join the exact submitted marker VM/code to the actual add-returned UUID and Tree
birth, followed by the matching delete return and independently observed weak
EntityItem expiry. Map absence, a fabricated UUID, an old birth, an API delete
operand or a still-live object cannot substitute. Already ended transient
markers retain their actual return and weak lifetime; unloaded/no-call/null
execution remains explicitly distinguished. Scope1's original format is
unchanged. Lost passive queries and local artifact returns do not resend. During a quiet
refresh, the last valid released Scope proof remains intact until a complete
new interval is admitted; an interrupted first or middle read retains the
original pending source and reconstructs without relaxing Scope1.
`emote_pointers.py` retains passive original Qt startup, contact, dispatch,
returned/finally callback and global-button/world-tap inventories under durable
query ownership. Pointer originals before and after each actual Scope frame
contain the entire resource quiet interval; their complete event histories
must remain unchanged and contact inventories empty. Native elapsed durations
are compared within each source's own clock. A final actual pointer read after
the public source observation independently extends the original measured
acquisition end; it never refreshes the public/source beginning. A release ACK
cannot replace any of these originals. Unknown passive queries are retained,
never resent, and constrain every later original prefix.

Every sample's original GPU retirement and every input/background owner must
also validate. Three seconds of quiet does not delete or reset native history.
`emote_retirement_scope.py` refreshes those same actual passive sources without
normal inputs after local resource retirement.

Retirement candidates themselves have durable pending ownership before an
immutable file is created. A lost file or metadata return adopts the exact
candidate. An invalid candidate is preserved as an abandoned original and cannot
be published; only a distinct later original can progress. Rewriting the
original file, native source, process, hash or quiet interval refuses validation.
The decoder returns the closed native quiet/provenance input for the separate
phase retirement publisher. A POST acknowledgment, digest, phase change or run
retirement alone never establishes product cleanup.

Selected host tests cover actual private files/inodes/PNG/CAS,
original decoding and authenticated loopback publication. The tests model the
native/SDK/renderer/GPU producers. They are not device acceptance. Positive
whole active-episode-to-changed-pixels-to-peer-to-publication composition,
coordinator final archival/re-entry and final runtime dispatch remain open.

`emote_final_archive.py` is a host metadata retirement primitive. Its caller
must supply a separate historical native closure validator; the actual test
validator rereads full Scope/source/entity originals before any deletion. It
freezes exact private copies before removing fixed metadata, adopts lost copy
or discard returns, and refuses changed/foreign runtime owners. Original source
artifacts and PNG files remain intact. Whole runtime finalization still needs
the role/phase/current-source integration; this primitive alone establishes no
complete feature or session teardown.

Image/sample writers are version2/read1,2; v1 self-image frames remain historical
only and cannot qualify current observation identity. Other new internal
envelopes in this packet write/read version 1. Existing
`ios-emote-sources` remains writer2/read1,2 and the original marker scope remains
v1. The shared public journey contract remains v16.
