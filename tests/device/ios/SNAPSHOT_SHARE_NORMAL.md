# Snapshot normal Share transfer

Feature 11/14 now joins an ordinary Qt Share row to ordinary system cancel or
receiver selection, the independently admitted receiver, and the independently
admitted archive. `IOSSnapshotShareRuntime.share_owner` holds both existing
source locks in sorted order, retains the actual installed main binding, and
forbids session recreation. Accessibility selectors describe input locations;
they never assert an expected effect.

`IOSSnapshotShareOwner` pins the completed capture owner and its actual PNG
original. Its separate literal input/source namespaces cannot adopt Capture or
Photos journals. A Share input has one durable issue intent. Recovery needs the
original native input receipt bound to the exact command, run, process, root and
control. An acknowledged input with no actual native Share presentation remains
pending. Cancellation requires the original native cancelled outcome and a
drained operation, independently of the system button return.

Ordinary receiver fields and buttons each have durable once-only slots. Lost
clear, write or click returns cannot resend a mutation. A readonly accessibility
value exposes the exact freshly persisted receiver journal, including its
actual query nonce, completed resource callback and weak operation lifetime.
The independently captured original DVT PID must equal the journal PID and
qualified embedded extension ID. A retained resource object blocks Finish. A
lost Finish return is resolved from actual native completion; it cannot cause
the finished extension to be reactivated or its read to repeat.

After actual native Share success and drain, an existing archive process is
activated once. Its ordinary Import action persists the original extension
JSON and unchanged copied bytes. The host retains exact AFC JSON originals and
bounded chunk originals, checks initial file/root revisions and source clocks,
and decodes the reconstructed PNG. It must match the capture original byte for
byte. Foreground return is bound to the same two existing processes. Replaying
the completed transfer reads retained originals without another Share,
receiver read, import or chunk action.

Host files retain planned/opened/saved transitions, exact device/inode/hash
identity and complete-before-parent-CAS adoption. A partial opened original
remains owned and cannot be overwritten. Passive source queries can acquire a
new nonce after an unqualified historical observation; mutation inputs cannot
repeat. Callback ACKs, window visibility and app state alone do not qualify the
transfer.
