# Avatar cleanup source joins

The pure cleanup source predicates reopen the existing immutable Avatar source
history. They invoke neither the SDK nor a normal input. Appearance restoration
requires the actual original model/resource, geometry, rig and scale, persisted
bookmark absence and preservation of every unowned entry, with every original
owned wearable absent from both renderer and tree inventories.

`restored` additionally requires closed visible controls and the complete
passive retained-root inventory, actual Pal callback/timer/pagination drainage,
the installed Avatar/Pal code pins, every newly born ScriptManager timer's weak
death and complete dispatch return, and destruction of every newly born tracked
XHR, reply and callback/timer owner. Baseline unowned births are retained under
their original identity. Its endpoint is the actual latest owned timer or HTTP
endpoint, never an acknowledgement or a newly invented capture time.
All relevant current timer snapshots, including old unowned default periodic
timers, must also have no callback or native dispatch executing at that cut.
Old periodic births may keep running between observations; they cannot hide an
already active dispatch behind the owned-birth filter.

`wearable_lifetimes` joins all actual AvatarApp add returns derived independently
from the source history to the unchanged native CreateEntities original DTOs.
The complete returned UUID, method, call sequence, VM membership and submitted
code must agree with the generic original API return. Its original Tree birth
must occur inside that call and be absent from the earlier baseline. Every such
birth needs actual Tree removal and actual EntityItem weak expiry; a live reused
UUID refuses cleanup. Applying a bookmark can remove avatar entities through
native setters, so this predicate does not fabricate a script deleteEntity
return where the product made none.

Host tests execute normal appearance recipes, retain a real host weak object
after tree removal, then release it independently. Wrong returned UUIDs, caller
sequences, births, live weak objects, incomplete sources, hidden detached Qt
roots, retained timers and retained XHRs refuse qualification. These are
component joins. Whole cleanup still requires fresh bilateral relationship
absence, ordinary account/logout restoration, input dispatch closure, marker
and file/GPU retirement, native and host quiet, unchanged post-cleanup output
and the separately committed independent actor retirement.
