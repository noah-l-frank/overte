## Attribution and completion remain separate

A lone pending invoke or identical receiver/GPU/dimensions does not prove which
queued producer supplied a Qt event: an unobserved KTX producer can be
indistinguishable. Queued receipts therefore remain explicitly unattributed.
Only an actual synchronous invocation scope on that thread, the same live
Resource and actual GPU sharing/argument identity and dimensions can attach a
direct receiver. This is not a heuristic upgrade after a later getter.

The host codec refuses unknown fields/versions, malformed identities or URL
hashes, foreign parents, impossible phase/clock order, unsupported capacities,
erased/rebound history, resurrected weak groups, failure healing and invented
completion. Normal source queries accept only schema/run/request/action;
they cannot select a wanted task, URL, hash, result or drained state. Probe
nonces are consumed once, including missing-getter/unavailable outcomes.

The weak model deliberately retains independent input storage and a base/pool
holder after the derived marker dies. A queued callback also retains an actual
Python GPU model object after the task is gone. Direct and delayed/foreign
identical payloads exercise the distinct modeled TLS boundary. Those are
explicit C++/Qt-boundary specifications, not actual Qt pool or GPU execution.

The canonical host selection executes the actual factory/native-clock/AFC
reader with an explicit SDK fixture. It preserves the existing session/launch
count and original source packet. Changed candidate bytes, wrong PID and
background state refuse before source dispatch or AFC reading. Epoch and
initial monotonic configuration are selected at fresh producer construction,
before any acquisition. These host cases do not connect to a device or execute
the new C++ collector; no old packet or source clock is relabeled.

KTX task completion, arbitrary byte-copy completion, QRunnable base/pool,
decoder, GPU and full resource retirement remain unavailable. No original
TextureRelease1 result, Owner metadata, Actor/peer/backend/source/process/SDK
responsibility is retired by these lifecycle observations. Assets remains
