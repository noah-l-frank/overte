installed-source guard and unchanged private binding/run. Each combined original

Every reconstruction reopens and hashes the original files, revalidates their

cannot manufacture current facts. A saved original interrupted before its parent

without reacquiring or retiming it. A planned file with no established inode is
not silently adopted or discarded.

observed hidden UIKit keyboard and no original event or pending holder for the

unfocused Scripts context and hidden keyboard while the actual original pending
event remains bound to alias 3. A retained old object cannot borrow alias 4.
Closing the editor projects historical generation zero without deleting aliases
or resetting original event history.
