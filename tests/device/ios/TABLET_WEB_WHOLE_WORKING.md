Feature 7 remains partial. None of the files below establishes device behavior;
all native Qt/UIKit/WK instrumentation remains uncompiled and unexecuted.

`IOSTabletWebRuntime._tablet_web_feature` creates the existing architecture's
feature owner from private prepared binding/setup originals, origins, and a
native-screen image policy. Construction sends nothing. `parts()` performs the
current existing-SDK admission and retains the actual new CLI admission without
rewriting the earlier native bootstrap. No SDK is created or installed.

Before the first page click, Primary persists the prepared input responsibility
and releases the shared lock. Actor independently admits the actual live Home
controls and app bytes. The private readiness reference contains ownership and
source identities only; it carries no page/effect/publication fact. Missing or
foreign readiness permits no new app click or cleanup Stop. A Home delegate
destroyed by the real QML Loader is never reused: later normal input selects a
new original control identity while preserving the initial app admission.

`tablet_web_feature` composes ordinary app files/Running Scripts, source-token
app buttons, actual WK/DOM input, separate background/resume, independent actor
publication, ordinary close/Stop-Script, actual NativeFiles absence and repeated
native/host quiet tails. The Actor is another host process observing the same
prepared physical SDK under the shared source lock. It does not read Primary
feature facts, create a session, Stop the app, or delete the SDK.

Screen evidence uses the existing original WDA PNG endpoint. A real current
controlled WK page is admitted before GET. Matching safe original PNG bytes are
retained in bounded immutable fragments before any later native-after/DOM

`tablet_web_terminal` qualifies both roles' original quiet tails and exact
canonical `PhaseWitnessPublisher` actor records before sealing the common
terminal window. Actual cached UIKit/Qt objects remain explicit held resources.
`tablet_web_process_end` then owns one Primary normal Stop and separate role-
issued original OS quiet histories. Its role WAL records intent before child
progress and preserves the original issuing host for recovered child records;
a new Primary CLI is not treated as a new native process. Native/source/frame
files are held under the unchanged original-file lease. Only exact bounded
Stop/OS/SDK/worker/final output paths may change.

`tablet_web_session_end` accepts only that Tablet process owner. It uses the
existing WebDriver DELETE transport, without ordinary cleanup fallbacks. An
issued or uncertain DELETE is never repeated. Actual GET/404 precedes exact CAS
removal of the old SDK metadata and neutral installed-code cleanup. All accepted
session OS originals retain their own history and must continue the actual
earlier Primary OS anchor/counter. A foreign replacement blocks deletion.

`tablet_web_terminal_finish` waits outside the shared SDK lock. The Actor issues
its own old-PID OS reads and records its own worker retirement only after the
same original SDK deletion is independently decoded. Both final roles reference
the same Stop/SDK-deletion original and distinct OS originals.
