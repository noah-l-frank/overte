# Failed Worlds preparation before the first capture

`NavigationPreparationAbort` owns an earliest failed preparation through one
canonical Stop, separate Primary/Actor original OS-absence windows, one SDK
DELETE, actual GET 404 and matching SDK/installed-metadata CAS. The original
whole/preparation files and their original bytes/inodes remain unchanged.
Its result explicitly says `failed`; it supplies no Scene, restored image,
successful terminal seal or Complete.

Admission requires the actual typed preparing whole owner, no feature-entry
owner, both baseline requests and scene admission still planned, no baseline
image/GPU/component child and no ordinary input or competing feature owner.
A capture intent cannot borrow this earliest authority. The complete partial
GPU-command/host-PNG graph needs its own historical decoding before that later
failure path can be admitted. Native Vulkan PNG/readback storage is held in
process memory (`gpu::FeatureCompletedFrames`); its quarantined allocations end
at process exit. No native source or product behavior is changed here.

The owner saves its original Stop intent before the ordinary installed lifecycle
call. Lost Stop delivery is followed only by independently retained OS queries;
it never authorizes another Stop. Both roles use distinct original commands and
sequences, and every final OS window retains the existing original host/node
epoch and monotonic three-second bounds. An incomplete window cannot authorize
SDK deletion. Local source-file inventories remain unchanged apart from exact
declared process/SDK transaction carriers.

DELETE follows a separate fresh actual OS-absence original. Unknown DELETE
delivery resolves only through separately journaled GETs. A present SDK leaves
responsibility intact. Only actual 404 permits discarding the exact SDK and
typed retired installed-code originals. The original thirty-second input budget
cannot be renewed by reconstruction; slow durable intent storage prevents the
send. All failed originals remain available after metadata retirement.

Nine no-build host cases pass (7.924 seconds). They exercise actual whole
preparation failure before capture, private CAS/ownership files, real loopback
SDK HTTP and actual process/SDK owner codecs with explicitly modeled bundle,
SDK, OS and acquisition clocks. Cases cover successful failed-end replay with
all transports forbidden, role-original substitution, lost Stop/DELETE returns,
ignored DELETE, uncertain original input, changed candidate, slow intent,
incomplete OS windows and an issued capture retaining its separate ownership.
No physical iOS behavior, native compilation or device qualification is claimed.

The separate `navigation_preparation_reads.inspect` now reopens actual failed
baseline, native command/storage, host-file and admission prefixes. It uses the
existing typed historical owners, original component hashes and exact host PNG
file identity. A complete recorded capture runs its existing pixel decoder;
an empty or partial file retains only its actual bytes/hash/phase. Neither can
be promoted to a successful baseline or scene. Independent inventories bracket
the complete read; no parent phase, clock, file or input is changed.

Three additional no-build cases pass (1.942 seconds): interrupted real baseline

Version two now joins that actual prefix decoder to the same once-only

well as the original whole/preparation carriers. Literal version one remains
the stricter pre-capture reader; persisted versions dispatch explicitly. No

Public whole cleanup routes a genuinely preparing, pre-entry owner directly to
this transaction. Once any abort intent exists, ordinary preparation cannot
resume. The canonical post-cleanup guard reopens the actual failed-end graph
instead of verifying a dead SDK. Generic installed cleanup also checks the
typed Navigation namespace before unrelated feature scans or lifecycle inputs.
Its first failed cleanup needs explicit matching private configuration; after
the original end, historical replay needs only the retained exact fixture URL
and local candidate scope. It cannot contact the fixture or recreate an SDK.

Twenty-five focused cases pass (22.022 seconds), including the earlier literal
version-one cases, actual source/captured-PNG/empty-file/Actor failures, real
public and generic cleanup, historical replay and unknown Stop delivery.
Five further counterexamples pass (7.369 seconds): replaced partial PNG inode,
unresolved public abort/new input ownership, candidate-loss ordinary fallback,
retained cleanup deadline and slow durable intent. A former cleanup-clock test
expected an obsolete pending exception; its actual fixture has no observer
images, so it now explicitly expects the real reader's incomplete-evidence

This version admits failed setup only while the feature-entry carrier is
absent. Scene-entry/input failures and other live partial ownership cannot
borrow its authority. The complete full journey, all remaining failure branches
and complete capability admission remain separate requirements. Worlds stays
partial; native compilation and physical timing remain unqualified.
