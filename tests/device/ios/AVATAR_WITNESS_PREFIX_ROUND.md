## Explicit read-only integration

[AvatarWitnessPublisher](adapters/avatar_witness_publisher.py) overrides only
the shared publisher's read-only `decode`. It enables an explicit
`immutable_prefix_round` in [the existing Final decoder](adapters/avatar_final.py)
and calls the original complete publisher decoder. The terminal Actor factory
uses this iOS Avatar subclass. Other publishers and ordinary Final cache scopes
keep their previous complete-envelope keys.

Only the existing historical group/component cache is reused. Each complete
owner envelope, record reference, component prefix and new group still follows
its literal reader. A shared group must have the exact same original argument,
root/store/run/role, locks, authority/client, bindings, inputs, grammar and
participating parser identities. Every borrower additionally retains its own
exact original owner-envelope hash and current-state agreement. Complete
inventory leases and actual original-file pins are checked on every use and
at round exit. Separate read collections cannot inherit cached membership.

This adds no cache of a public result, quiet/effect verdict, current clock,
fresh observation, publisher response or live guard. Quiet, resource, current
ticket, expiry, candidate and SDK checks still run. The group bound remains
256 and each entry explicitly bounds borrowers at 512. Borrower hashes avoid retaining
another full serialized metadata copy per group. No serialized field, native
source, source pin or registry version changes.

The synchronous decode scope ends before its caller can write a publication
CAS journal or issue an HTTP request. Issued uncertainty remains durable;
neither a failed read nor the new reuse can repeat normal input or publication.
