`IOSEmoteRootedInventory` closes the internal inspect/seal read set over both
actual artifact roots and SDK directories. Every Emote, phase and ambiguous
GPU carrier must belong to the files actually read by the typed original
validators or to the terminal journal's exact current output paths. A filename
or namespace alone grants no exemption. Unknown carriers retain responsibility.

`emote_rooted_gpu.validate` additionally joins every retained sample/restoration
GPU parent to its actual current owner metadata. The original identity and
transcript prefix remain exact; later entries may only be completed absence
inspections. An unresolved return, captured current owner or newly present
owner where the parent had none prevents terminal persistence. Validation sends
no GPU query, release or retry and never creates missing originals.

The paired guard pins actual file identities and timestamps, including ctime,
and checks private parents on reuse. New carriers and same-inode rewrites with
restored bytes/mtime are rejected. Only the typed journal's current metadata,
record and pending file may change during persistence. Nested original-reader
scopes contribute their actual validated signature membership explicitly.
