# Original Worlds source transfer after restart

Feature 1/14 is still partial. This packet acquires and validates original
new-process sources on an existing candidate-qualified session. It does not
stop or launch an app, publish a whole observation, retire old files or enable
a complete capability. Native code remains uncompiled and devices are untested.

`navigation_restart_proof.py` reuses the existing pure iOS candidate/native/PID
and kernel validation from Graphics. It has no dependency on Graphics inputs,
fixtures or scene behavior. A new numeric PID must retain the full actual
candidate/session/target binding, exhibit a new native birth and lifecycle,
preserve actual graphics preferences, and independently report the old PID
absent with native ESRCH. An unknown/present PID or a launch ACK is insufficient.
The wrapper also binds the independently chosen runtime owner files in order:

1. `ios-navigation-scene-admission.json`
2. `ios-navigation-primary-0-samples.json`
3. `ios-navigation-actor-0-samples.json`

The list supplied by a receipt cannot select different owners, siblings,
relative paths or aliases. This validates responsibility only; those original
owner files remain present until their separate whole-run retirement.

`navigation_process_context.py` keeps the first static admission as the exact
restoration baseline. The original pre-stop eight-source group must follow it,
and the last old native packet must follow that group. A newly acquired group
must independently follow the actual new-process packet. Every process-local
source birth, native scene-load/commit ledger and tree birth must change.
No PID, native time, source counter, original body or bookmark map is relabeled.

Both groups must independently establish an actual unchanged owned run scene,
settled native pose, original camera mode, quiet closed supported UI, unchanged
actual Places preferences and original loaded/persisted bookmark agreement.
The new process must retain the exact actually observed pre-stop bookmark map.
The initial bookmark baseline remains bound to the old process; its existing
cross-process validator compares candidate/target identity without inventing
new old-file clocks. An actual missing bookmark cannot be reconstructed from
its requested name or previous action acknowledgment.

`navigation_scene_scope.py` shares the existing pure owned-scene return gate.
The ordinary return wrapper still validates the original admission and all its
same-process history floors. Only the separately proven transfer can admit a
new-process group without such an old-process source floor.

`NavigationProcessOwner` reserves its fixed private journal before the first
post-restart source read. It retains the original admission, pre-stop group,
restart receipt, both native brackets, both independent provider originals and
each returned source. Partial groups remain owned and are not re-read under a
new envelope. A complete lost return can recover solely from retained originals;
recovery cannot refresh its original 1.5-second host/native input deadline.
Historical reconstruction sends no SDK or HTTP command. A source basis is an
explicit process-source DTO, not a replacement static-admission proof.

`IOSNavigationRuntime._navigation_process_owner` uses the existing qualified
new-process source factory, fixed owner files, typed HTTP/AFC channels and an
independent native clock reader seeded from the actual restart packet. It never
creates a session or launches an app to repair missing binding.

Host tests use real private journals, actual static/scene HTTP and persistence
bytes with explicitly modeled app/kernel/SDK originals. Counterexamples cover
ignored persistence, reused old sources, foreign candidate/files, unknown PID
death, unsaved edits, changed UI/preferences, original history tampering, lost
middle reads, lost final writes, expired input and SDK-free reconstruction.
They do not establish real product restart behavior.

Context and source basis now write version 2 and read versions 1 and 2.
Version 2 can retain the actual process-qualified `NavigationAddressInputs`
private carrier as `before.addressOwner`. Its complete original recipe journal
must bind the same old candidate/process/run, the actual normal opening and
acknowledged native input history. The pre-stop source must extend that journal,
retain the same closed QML root and preserve its actual owned field text.
Unresolved input, foreign text/root, changed ownership or reused source counters
refuse transfer. This adds no SDK query or input to historical validation.

The old scope keeps its genuine `retained`, `drained=false` root observation.
The separate actual ESRCH receipt proves the old process ended; a new-process
complete native inventory must independently contain no address root. No old
root UUID, clock or input sequence is carried into that process. The three
restart input companion files remain fixed; they are not an exhaustive list
of feature resources. The complete address carrier is separately retained
inside the pre-stop group and original process-owner journal.

Original version-1 root-free contexts remain version 1 when reconstructed,
including their source basis and exact original shape. They cannot adopt a
retained root. The compatible process-owner version-1 envelope retains its
versioned context as an explicit nested original, including archived v1 data.

The ordinary restart controller and pre-stop input/image drainage still need
whole-journey integration. This transfer accepts only a reloaded owned run
scene. A default/foreign startup world requires a fresh, explicitly owned
normal entry.

`NavigationProcessScope` connects the proven live source basis to ordinary
surface, Places, missing-destination and composite owners. It validates the
actual new process and source floors before each action. Their private journal
filenames include that actual PID, so earlier input journals remain unchanged.
The scope exposes the original admission separately and cannot substitute the
new source basis for it. `NavigationProcessReturn` now owns an ordinary return to the unchanged first
static resource. It acquires fresh actual current-process inventory/navigation/UI
and provider originals, validates the owned scene and original camera/scale, then
journals a single normal Go To recipe in that process's retained-root owner. A
lost final parent result adopts only the complete actual child original without
an SDK read or replay. Interrupted source reads and incomplete native receipts
remain owned. Slow journaling cannot send an expired scene gate. Ignored Go To
still establishes only delivery. The independent restored scene, pixels and
whole cleanup must be proved separately. Fifty-four host tests cover these
owners, runtime factories and process scope, including stale PID and source
counters; they do not demonstrate product restart behavior.

Full independent publication, static restoration, callback/resource drainage
and repeated quiet finalization remain open.

Source inspection confirms that normal iOS Go To close retains its QML root.
The separate [address-root ownership validator](NAVIGATION_ADDRESS_ROOTS.md)
distinguishes that actual hidden object from destruction. Its durable ordinary
scene entry/return journal now supplies the explicit version-2 root handoff.

The live process scope seals the fully validated immutable context once. Every
use still compares its actual private carrier, current owner state and source
binding against that seal; callers receive copies. Original archive validation
remains unchanged. A local modeled timing check measured about 267 ms per full
archive reconstruction and about 4 ms per sealed use. The seal changes no
original clock, deadline, source version or historical bytes. Changed cached
basis, in-memory owner or private journal fails closed.
