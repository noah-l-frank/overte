# Ordinary Emote tablet entry host boundary

The Emote host fixture can use the real `NativeUI` W3C lookup, displayed,
enabled and click implementation. The model exposes original UIKit widget
objects, validates each original native UI DTO and retains only weak element
references plus the actual root birth. Opening or closing retires the former
widget; a retired original cannot be refound or replayed after its durable
input intent. The normal token chooser then invokes the actual pinned Emote
script handlers. This replaces the earlier direct tablet-click stub in tests
that explicitly select this boundary.

The fixture also supports delaying marker preparation so whole-owner tests
can acquire their actual untouched original image, pointer baseline and native
entity lifetime baseline before the first ordinary marker input.

These are modeled UIKit/W3C/native producers, not installed-device tests. The
complete Feature 5 actor, paired retirement, final archive and runtime dispatch
still require whole integration; these boundaries advertise no capability.
