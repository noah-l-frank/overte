# Failed Avatar preparation ownership

`AvatarFailedPreparation` joins the actual unchanged feature, child account,
input and resource owners. Its outcome remains failed. It never completes
preparation, emits a successful Scene/Complete receipt, constructs a terminal
live window or relabels a stored feature phase for cleanup.

Before ordinary account cleanup, the coordinator retires a known private
credential transfer through `AvatarAbortCredentials`. Protected request and
origin releases retain the exact source-generated command before dispatch.
Unknown releases are followed only by distinct Inspect/Observe commands.
Returned native absence, not a release acknowledgement, authorizes removal of
the associated private ownership record.

An admitted partial marker is closed through its existing normal Scope owner.
Pending untouched-frame and sampled-image GPU owners are drained without a new
capture. No marker baseline is created to repair a missing preparation result.
Marker cleanup precedes logout because its native World originals require the
still-admitted Avatar identity. Ordinary logout and preference restoration then
retain the exact original account samples, input history and preference basis.
An already-restored preference input can be passively adopted; uncertain input
is never repeated merely to obtain a cleanup acknowledgement.

Both actual account-cleanup originals must exist before either Stop. The same
`IOSAvatarAbort` owns one Stop, at least three OS observations over three seconds
on all four original clock coordinates, one SDK DELETE and independent actual
404 reads. Both process ends precede once-only controlled provider revocation.
Both complete failed-end originals precede a successful cleanup API return.
The independent worker exits with failed status after fixture retirement.

The local coordinator writes `iosAvatarFailedPreparationVersion: 1`. Its private
file is `ios-avatar-ROLE-RUN-failed-preparation.json`. Actual feature bytes and
their phase stay unchanged; all original graphs remain at their original paths.
