# iOS Graphics implementation and original source handoff

Graphics is in progress and advertises no full feature capability. Scripts and
Authentication remain the two complete source-level iOS areas. All new native
code remains uncompiled and all devices remain untested.

## Original subject source

The read-only `feature-graphics-subject-observe` query selects a run, never an
expected setting, geometry or result. Gated native code reads the seven actual
owned entity UUIDs, full geometry/visual properties, absent IDs, original world
address, camera frustum and avatar feet/orientation/scale. A bounded 128-metre
scan records original visual-property hashes for unowned entities. Actual owned
UUIDs are read directly even if moved, hidden or renamed. No entity, camera,
avatar, preference or scene setter is added.

The native source is derived from frozen Phone
`fe4684bf46585088370b3a328a738f147e670b97`, retaining existing iOS declarations,
instrumentation and private channels. The iOS HTTP command validator, probe
dispatcher, original atomic AFC file and `FeatureObservation.graphics_subject`
factory are connected. The query is inactive outside the dedicated E2E build
and `--testScript`. Original version 2 adds avatar pose, with version 1 reader
compatibility. Native source sequence is bounded before overflow.

The full iOS source reader requires an independently measured native clock,
original nonce/PID/birth/source sequence and bounded original acquisition.
Native times are untouched. It rejects stale epochs even when the response
contains the current command nonce. Legacy passive component reader semantics
remain available only through its separate explicit construction; they cannot
stand in for full acquisition clock joins.

The shared Graphics stimulus advances to version 2: the orange object now
intersects the real mirror reflection, and the challenge card is near enough
to preserve black/white contrast under haze. Deterministic entity identities
are unchanged. Fixture geometry is stimulus, never measured product evidence.
The `graphics-subject` and `native-graphics-subject` registry entries describe
these two distinct versioned contracts.

`graphics_source.py` also projects the actual generic immediate Graphics
controls from a new original iOS receipt. It retains actual native window and
transport UUIDs, source/input/elapsed cursors, unmodified clocks and the complete
original receipt. A projection cannot change metadata or claim a Phone source.
`IOSGraphicsRuntime` constructs this reader and the subject query exclusively
through the existing canonical candidate/session/native-clock factory. The
existing `IOSGraphicsIO` and `TokenGraphicsUI` still deliver ordinary UIKit/Qt
pointer, scrollbar and on-grid slider input. Read-only acquisition refuses all
mutations. Actual window-generation changes remain in the original records;
individual input recipes must pin the context after opening the tablet.

The [original iOS scene-load ledger](../native/SCENE_LOAD_OBSERVATION.md)
records actual local-file/ResourceRequest outcomes, current generations and
retained owner-thread/viewpoint callbacks. The full runtime's existing native
source factory reads this separate immutable original ledger. A current commit
requires all traced leases to drain, including older replaced loads. Native
input, scene, camera, provider and rendered evidence remain separate joins.

## Remaining whole-journey work

The iOS Graphics coordinator must still compose normal generic Graphics/Go To/
View-menu tokens, measured original preferences, original scene-load history,
owned scene/camera restoration, background/restart provenance, independent
role images and verified lifetime cleanup. Preserve the shared v16 fifteen-step
journey and actual initially measured baseline. Do not expose the full triple
until that composition and meaningful counterexamples pass.

The existing world-target PNG sampler only reads actual main-mono OpenGL
framebuffers; Vulkan's product `downloadFramebuffer` is unimplemented. iOS
uses Vulkan/MoltenVK. A Vulkan capture must either add a separately gated,
actually completed GPU readback with original allocation/pass/retained-callback
provenance, or join original native-screen pixels to independently completed
Vulkan frame/target/pass measurements. Requested texture sizes, CPU command
recording, a generic presentation counter or an old periodic file cannot prove
the current image or render scale. Do not label Vulkan pixels as OpenGL or
import Phone's backend assumptions.

## Local verification

Fifty-eight selected no-build host tests passed for original subject parsing,
closed fixture/probe dispatch, geometry stimulus and iOS HTTP/AFC seams. They
cover actual original clock separation, stale/foreign/missing sources, bounded
queries and no command replay. Node runs the existing probe implementation;
native/SDK packets are synthetic. No compiler, app, device or laboratory is
executed. Further whole-journey and integration results belong here as the
implementation progresses.

Eighteen further source/input host tests cover original iOS Graphics receipt
projection, generic-source admission, read-only input refusal, altered/stale/
foreign originals, and the existing meaningful scroll/slider/ignored-input
counterexamples. These do not yet exercise the full iOS Graphics journey.
