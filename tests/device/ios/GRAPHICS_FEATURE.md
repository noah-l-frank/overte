# iOS Graphics implementation and original source handoff

Graphics is in progress and advertises no full feature capability. Scripts and
Authentication remain the two complete source-level iOS areas. All new native
code remains uncompiled and all devices remain untested.

## Original subject source

The read-only `feature-graphics-subject-observe` query selects a run, never an
expected setting, geometry or result. Gated native code reads the seven actual
owned entity UUIDs, full geometry/visual properties, absent IDs, original world
address, camera frustum and avatar feet/orientation/scale. A bounded 128-metre
scan records original visual-property hashes for unowned entities. Actual owned
UUIDs are read directly even if moved, hidden or renamed. No entity, camera,
avatar, preference or scene setter is added.

The native source is derived from frozen Phone
`fe4684bf46585088370b3a328a738f147e670b97`, retaining existing iOS declarations,
instrumentation and private channels. The iOS HTTP command validator, probe
dispatcher, original atomic AFC file and `FeatureObservation.graphics_subject`
factory are connected. The query is inactive outside the dedicated E2E build
and `--testScript`. Original version 2 adds avatar pose, with version 1 reader
compatibility. Native source sequence is bounded before overflow.

The full iOS source reader requires an independently measured native clock,
original nonce/PID/birth/source sequence and bounded original acquisition.
Native times are untouched. It rejects stale epochs even when the response
contains the current command nonce. Legacy passive component reader semantics
remain available only through its separate explicit construction; they cannot
stand in for full acquisition clock joins.

The shared Graphics stimulus advances to version 2: the orange object now
intersects the real mirror reflection, and the challenge card is near enough
to preserve black/white contrast under haze. Deterministic entity identities
are unchanged. Fixture geometry is stimulus, never measured product evidence.
The `graphics-subject` and `native-graphics-subject` registry entries describe
these two distinct versioned contracts.

`graphics_source.py` also projects the actual generic immediate Graphics
controls from a new original iOS receipt. It retains actual native window and
transport UUIDs, source/input/elapsed cursors, unmodified clocks and the complete
original receipt. A projection cannot change metadata or claim a Phone source.
`IOSGraphicsRuntime` constructs this reader and the subject query exclusively
through the existing canonical candidate/session/native-clock factory. The
existing `IOSGraphicsIO` and `TokenGraphicsUI` still deliver ordinary UIKit/Qt
pointer, scrollbar and on-grid slider input. Read-only acquisition refuses all
mutations. Actual window-generation changes remain in the original records;
individual input recipes must pin the context after opening the tablet.

`graphics_surface.py` supplies ordinary generic Graphics/Go To/View-menu input
under caller-owned persisted intent and UI leases. It navigates only original
or caller-owned URLs through the actual address editor/IME, searches actual
tablet pages, scrolls real Graphics controls, and clicks original QAction
delegates for camera changes. The generic `look at` mode maps to the product's
**Third Person** action; no Phone label or package selector is reused. View-menu
source v1 binds the actual source QObject, kind, label hash and checked state,
and rechecks source plus hit ownership before pointer delivery. The dedicated
test UI is required to use the current English menu labels.

All UIKit E2E proxies now expose their original source token, including Home,
tablet-page and address controls used by these ordinary recipes. A replaced Qt
source retires the actual UIKit proxy. Field text is read from its native source
or private carrier, never confused with this token attribute. Graphics input
identity is pinned after the actual tablet window opens and released only after
observed closure. The surface returns input receipts only; scene/preferences/
images and durable whole-run cleanup remain separate owner responsibilities.

The [original iOS scene-load ledger](../native/SCENE_LOAD_OBSERVATION.md)
records actual local-file/ResourceRequest outcomes, current generations and
retained owner-thread/viewpoint callbacks. The full runtime's existing native
source factory reads this separate immutable original ledger. A current commit
requires all traced leases to drain, including older replaced loads. Native
input, scene, camera, provider and rendered evidence remain separate joins.

The selected shared `graphics_resources.py` backend binds actual socket writes
to its configured original origin, stable owned scene UUIDs and immutable
response/status/body histories. Read/activation/retirement remain separately
authorized. `phase_fixture.py` exposes only original activation input metadata,
with immutable prefixes retained through retirement, never actor/product facts.
These sources and their dependencies are selected from the same frozen Phone
commit. The shared fixture server, Client and quick-test inventory are extended;
existing adapter-reader masking and mutation refusal remain enforced. A private
fixture server configuration explicitly opts in with
`graphicsProvider: {fixtureUrl: <actual canonical fixture URL>}`.

## Remaining whole-journey work

The iOS Graphics coordinator must still compose normal generic Graphics/Go To/
View-menu tokens, measured original preferences, original scene-load history,
owned scene/camera restoration, background/restart provenance, independent
role images and verified lifetime cleanup. Preserve the shared v16 fifteen-step
journey and actual initially measured baseline. Do not expose the full triple
until that composition and meaningful counterexamples pass.

The existing world-target PNG sampler only reads actual main-mono OpenGL
framebuffers; Vulkan's product `downloadFramebuffer` remains unimplemented.
The [completed Vulkan frame source](../native/COMPLETED_FRAME_OBSERVATION.md)
now records successful original allocations, issued Vulkan API draws, camera
geometry, actual fence observation and retained capture groups. It is metadata,
not pixels or an effect verdict. The remaining image/feature owner must join
independently acquired original native-screen bytes to those actual completed
frame measurements and retain meaningful subject/marker comparisons. Requested
texture sizes, CPU command recording, generic presentation counters and periodic
files cannot replace this evidence. No Vulkan pixels are labelled OpenGL.

`graphics_images.py` now acquires the actual existing WDA screenshot endpoint
without changing PNG bytes. A private full-candidate/run/role/stage ledger
persists planned/opened file responsibility before acquisition, actual inode
identity before writing, original bytes/SHA/extents, and separate host and
independently sampled native clock intervals. It deliberately has no native
capture timestamp or GPU frame-ID field: WDA does not return those facts.
Failed/lost acquisition cannot be silently retried by constructing a new owner.
Historical reading verifies exact bytes and inode; cleanup refuses foreign,
replaced, linked or resurrected files and observes actual path absence. It
retains the ledger for the outer feature's final quiet-window proof.

The existing `native_geometry.py` command now also has a full-feature reader
using the canonical closed HTTP/AFC transport, separately guarded process and
actual native clock. The unchanged legacy component API remains compatible.
Its original geometry receipt contains no PID; that binding is independently
guarded rather than inserted into the native receipt. This reader and original
PNG acquisition are constructed through `IOSGraphicsRuntime`. The next packet
must join both to bracketing completed Vulkan frames and actual viewport/subject
geometry, decode the current challenge, and compare meaningful haze/mirror
pixels. Acquiring a well-formed PNG alone does not complete that proof or the
whole Graphics journey.

## Local verification

Fifty-eight selected no-build host tests passed for original subject parsing,
closed fixture/probe dispatch, geometry stimulus and iOS HTTP/AFC seams. They
cover actual original clock separation, stale/foreign/missing sources, bounded
queries and no command replay. Node runs the existing probe implementation;
native/SDK packets are synthetic. No compiler, app, device or laboratory is
executed. Further whole-journey and integration results belong here as the
implementation progresses.

Eighteen further source/input host tests cover original iOS Graphics receipt
projection, generic-source admission, read-only input refusal, altered/stale/
foreign originals, and the existing meaningful scroll/slider/ignored-input
counterexamples. These do not yet exercise the full iOS Graphics journey.

The ordinary surface packet passed 45 selected no-build host cases. The SDK
model exercises actual W3C lookup/token/click and native HTTP/AFC framing,
generic settings open/scroll/set/toggle/close/reopen, actual mode reads after
View-menu pointers, normal address IME input and failed persisted intent.
Ignored slider/camera inputs, foreign source metadata and retired tokens fail
without resend. Native/UIKit positives remain synthetic; these checks cannot
establish native compilation, ordinary iOS accessibility or device behavior.

The Graphics provider/phase/fixture packet passed 150 shared host tests,
including all existing journey logic, closed role access and actual loopback
socket response histories. The deterministic shared journey SDK now uses the
real Journal registration constructor; it no longer fabricates an incomplete
internal record. All six iOS Script/Authentication journey regression cases
also passed after the shared server/Client extension. These are host-only
regressions, with the same explicit compiler/device exclusions as before.

The screen/geometry packet passed 22 no-build cases: eight new original-image/
geometry cases plus twelve existing geometry/viewport and two completed-frame
transport regressions. They cover one-send capture, native/host clock skew,
late or missing results, changed process, original SHA/inode preservation,
foreign-file cleanup refusal, stale/rotating geometry, and real closed HTTP/AFC
framing at a synthetic SDK boundary. Screen pixels and native receipts are
synthetic; there is no physical rendering or device qualification.
