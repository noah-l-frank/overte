# Immutable original Qt key carriers

`adapters.original_key_packets.OriginalKeyPackets` stores unchanged global
current `IOSWorldWebKeys2` carriers in original files. The closed `avatar`, `emote` and
`worldweb` profiles keep separate filenames, subjects, contexts and DTO keys.
The native source name does not restrict these qApp key/IME originals to Web
pages. No SDK request or cleanup interpretation occurs in this helper.

`write(index, query, raw)` first validates exact nonce/run/process and the
closed source-2 privacy boundary, then returns the full saved original descriptor. The
parent callback owns each planned/opened/saved transition before it continues.
`read(descriptor)` validates the exact private carrier; `packet(descriptor)`
additionally validates the genuine original native nonce, process and grammar.
The unchanged underlying `originals` store is available for compact/expand and
strict original-file inspection. `inspect_partial(descriptor)` preserves actual
inode identity, size, SHA and bytes of an opened or saved file. A complete opened
file can be decoded without relabelling its ownership phase. An incomplete
inode remains owned and cannot be overwritten by this helper.

Stale AFC source-1 responses, foreign nonces and malformed/unsafe payloads are
refused before any host ownership transition or file creation. Historical
`read`/`packet` preserve genuine prior raw/source-1 originals without relabelling;
they cannot qualify current whole-feature privacy. No saved bytes are sanitized.

Large transcripts use the existing OriginalFrameStore byte limit. Private
metadata and native readers keep their existing separate limits. Malformed and
foreign-nonce responses cannot become new host originals.
Host tests cover an actual carrier above 400 KiB, all three write transitions,
profile/subject refusal, hardlinks and lost partial/complete writer returns.
No native compilation, device input or installed renderer is exercised.

The carrier contract `native-keys-raw` writes/reads 1. The configured original
file envelopes retain the common original-file version 1. Acquisition owners
must separately retain every query, native bracket, abandoned source prefix,
held-key/IME lifetime and actual editor/UI/keyboard absence before retiring a
feature. A raw carrier or completed write supplies none of those verdicts.
