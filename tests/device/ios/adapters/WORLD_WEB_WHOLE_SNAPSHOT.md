# World Web whole Snapshot2

This is a passive source prerequisite. It does not qualify the complete World
Web feature or a native/device run. The C++ header has not been compiled.

The dedicated `feature-ios-world-web-whole-snapshot` command and JSON file use
outer `iosWorldWebSnapshotVersion=2` and `iosWorldWebSnapshotBodyVersion=2`.
`Test.featureIOSWorldWebWholeSnapshot` calls twelve original getters: the nine
Snapshot1 names plus `surfaces`, `closures`, and `emissions`. Document may be
null only when the actual preceding ledger has no current document. Every
getter retains its exact query, original JSON result and before/after clocks.
The closure getter keeps its genuine point capture timestamp; the batch does
not invent a getter clock bracket inside that packet.

Snapshot1's action, method, native class, default reader behavior and original
grammar remain unchanged. Its optional scoped pure body memo supplies no file
ownership or new freshness; returned bodies and selected children are copied. The new live reader accepts only version 2. It never converts a
legacy packet, substitutes a prior child, resends a pending command, or obtains
a fresh replacement for an evicted nonce. The original DOM callback remains
owned independently even when the batch is ready or unavailable.

The lossless bounds remain 8 MiB plain, 1,500,000 compressed bytes and 2 MiB
wire JSON. The canonical base64/qCompress decoder checks the original byte
counts and SHA-256 before accepting a single bounded zlib member. Dictionaries,
trailing/concatenated members, duplicate fields and nonfinite values fail.
Native child limits stay unchanged, including the 2 MiB emitter source and
240,000-byte surface source. All maximum child capacities need not fit together;
an overflowing batch is explicitly unavailable and never truncated.

The native owner retains at most two complete payloads, eight pending reads,
512 known nonces and 64 actual calls per nonce. Known evicted nonces remain
unavailable. The enclosing 1.5-second acquisition limit is unchanged.

The standalone host fixture has no executing Script VM and genuinely emits no
messages. A live Node VM must supply its actual interception inventory; the
fixture refuses to replace a missing live observer with an empty collection.
The standalone typed source boundary and current-view trace have no feature
owner dependency. The cache fixture optionally samples injected clocks and PID
before producing each new original; old packets and weak lifetimes stay intact.

Thirty-three host cases cover both versions, scoped body memo isolation, actual
Probe/fixture/factory routing, pending nonce retention, unknown delivery without
resend, original native PID rejection, strict legacy decoder bounds and genuine
weak lease retention. The new AFC case transported 1,402,228 wire bytes,
1,051,096 compressed bytes and 2,232,745 plain bytes (random entropy changes
compressed sizes between runs). This is host transport verification, with native
getter implementations modeled. Source5 CPU composition remains separate work.
