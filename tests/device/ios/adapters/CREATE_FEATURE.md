# Existing-session Create feature

The catalog operation enters `IOSCreateRuntime._create_feature`, then
`IOSCreateFeature.act/observe/cleanup`. The runtime only uses already prepared,
candidate-bound sessions. It does not launch, install, discover a peer, start an
observer or repair a product. The independent actor uses `ios/create_observer.py`
with its own token and existing SDK session.

Primary owns the ordinary editor, exact JSON import/export browser inputs,
model/texture/PolyVox edits, measured normal world touch, original export and
fenced world PNGs. Actor independently reads the primary editor and its own
replicated scene/default worker. Actor creates no extra marker. Every source,
owner and archive remains tied to the actual run/candidate/target/PID/session.

Each public call owns one 25-second host budget across nested calls and lock
release/reacquisition. The original deadline cannot restart at the next cleanup
stage. Invalid/backwards host time or a caught expiry remains poisoned for that
call. This budget limits work; it never supplies native timestamps, image clocks
or product evidence. Candidate checks, durable input intentions, native sends,
rez HTTP and W3C input all check it before further delivery. An expired or
uncertain intention remains owned for separate original recovery.
The outer installed entry starts this same budget before candidate preflight
and keeps it through final binding verification. Rez HTTP checks the deadline
after actual opener preparation, immediately before delivery.

Normal input retains exact original tokens and NativeInput HTTP/AFC admissions,
receipts and observed widget cursors. ActionOwner2 keeps immutable event carriers
under the same private state directory; the bounded main journal contains their
exact digests. Original inline ActionOwner1 remains readable without migration
or writes. Only a new durable intention writes version 2. A storage failure
prevents delivery; uncertain input never resends a recipe or token command.
The ordinary Properties tab is explicitly selected before naming/sizing a newly
admitted entity, including imports and detailed dialogs that leave another tab
visible. Ordinary Properties position fields also place every newly admitted unit entity in the
actual measured camera's view. Active setup requires State4 in the original
source before its first input. Before deleting a positively admitted owned UUID, the ordinary
Properties control restores the original observed search draft while that
selection still exposes the field. Passive NativeState4 retains the unique
actual editor child's text even when selection loss hides it. Close checks that
same root and original draft without attempting input to a hidden field. State
originals 1/2/3 remain readable; absent historical search data cannot establish
this new hidden-draft proof.

The image rectangles are illustrative preselected policy, never guessed from a
requested outcome. Every original PNG independently checks actual marker
challenge, whole projected marker exclusion, measured subject geometry and GPU
provenance. The token and domain ID must come from the separately provisioned
private fixture; example values do not provision an authority. Only actual
normal settings API originals and independent native effective permissions
qualify denial/retry/restoration.

Actor config is closed: `iosCreateObserverVersion=1`, `target`, explicit
`candidateArguments`, `fixtureUrl`, `actorToken`, bounded `durationSeconds`, and
`create` containing the private `artifactRoot`, `imagePolicy`, `primaryTarget`.
It has no rez mutation authority or selected-result fields. Actor admission uses
actual existing installed-code and process originals before marker setup.

Whole local cleanup is documented in `CREATE_RETIREMENT.md`. Primary releases
both source locks while waiting for an actual committed Actor retirement bound
to the earlier actual SDK admission. A receipt/POST ACK is not native cleanup.
Primary takes a new local whole confirmation after the exact receipt acquisition.
Repeated cleanup uses new read-only originals and new Actor receipts; no Stop,
touch, token input or file mutation is repeated merely because a reply was lost.
The logical public cursor spans the actual retained active-history prefix plus
actual retirement records; native counters and timestamps stay unchanged.

Only after the fixture's actual inactive original may `finalize()` seal the
qualified local original and paired receipt. `CreateFinalArchive` compares an
unchanged full private Create metadata closure before/after pure qualification,
then retains exact path/device/inode/bytes/SHA originals. The API seal also
retains the actual loaded coordinator header, including fixture origin and
image policy. Both direct and installed-adapter archive reopening compare the
entire coordinator state and header, allowing only the recorded terminal phase
transition. A standalone typed local archive does not claim this API header. Actual PNGs and export
files remain, including their original identity. These are proof artifacts,
not live scene/provider/GPU resources. Reopening a completed final archive calls
no SDK or fixture HTTP and refuses replaced files even with identical bytes.
An interrupted immutable archive save resolves actual saved bytes read-only;
unknown/partial storage remains owned. An earlier issued Actor facts
publication is resolved against the actual inactive fixture without replaying
its POST; its original journal/carriers enter the unchanged archive closure.
`create_finalization.finalize_existing`
must run before the installed adapter's ordinary SDK teardown.
The installed adapter always invokes that finalizer. Missing fixed coordinator
metadata with any retained Create, facts-publication or retirement carrier
refuses SDK deletion. Carrier names can establish outstanding responsibility;
their unqualified contents cannot establish cleanup. A genuinely absent Create
scope requires no candidate or SDK access in this check.

Host tests exercise the real owners, normal token recipes, NativeInput HTTP/AFC,
normal settings HTTP, Node execution of the exact staged Script/companion,
private PNG/export files, original publication journals and OS source locks.
App/native/Qt/renderer SDKs are modeled. All passive native instrumentation is
still uncompiled: this source integration is not a physical iOS result. Keep
capability activation explicit in configuration version 3. The complete source
integration is host-tested; actual native compilation and devices remain open.

Shared reconciliation includes passive `ios-create-state` 4/read1–4,
`ios-create-action-owner` 2/read1,2 and event carrier1, seven new closed Create
owner/archive contracts, and `ios-script-feature-configuration` 3/read1–3.
The shared retirement protocol writes2/reads1,2 with an explicit complete stage;
Avatar's separately closed scene stage cannot satisfy Create retirement.
The new Create API budget also uses the shared final SDK/native HTTP guard.
No global CI, device configuration or build was changed.
