originals, complete Script membership/code inventory, ordinary action journals,

all sample/GPU owners, and delivered Qt pointer state. Three seconds of quiet
exclude boundary acquisitions and must pass all host/native intervals. No ACK,
requested UUID, scene absence, counter reset or timer reset establishes cleanup.

input remains owned. Native JSON is removed only after actual default-worker
and Entity/Model callbacks drain. Scope2 proves the actual marker UUID's native
birth and eventual weak expiry. Fresh source reads include transient Entity IDs
seen by unsuccessful acquisitions; these IDs do not authorize deletion, but
their lifetime responsibility cannot disappear from cleanup.

inode/bytes. Actual GPU storage must be absent. A final fenced raw image is
compared with the pre-marker image after the actual Scope terminal/weak barrier.
The entire measured marker projection is compared; if no original geometry
was admitted, the entire viewport must be unchanged with the stricter full-view
threshold. Unknown geometry never selects an invented box.

It advances actual sequence/clock originals without repeating cleanup input.
`frozen().validate_original(...)` retains typed original resolvers for pure final
validation; it still reopens actual immutable source/component carriers, PNGs
and exports, including warmed validation paths. It supplies no fresh result.

The logical public cursor spans the actual frozen active-history prefix and
actual retirement record count. Later frames retain that exact growing prefix;
an older valid history cannot replace it. Native counters and timestamps remain
unchanged. Thus cleanup cannot rewind a role after its ordinary observations.

Scope is still new. It permits cleanup of that native GPU owner and positively
unexecuted Scope, with a complete source/pointer baseline. It cannot admit
marker setup or claim missing pixels; the lost image is never read again.
