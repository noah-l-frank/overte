# Original Avatar and People timer dispatch closure

Scripts1 workers may include the closed optional `uiWork` component, writing
`avatarUiWorkVersion: 1`. Legacy workers without it retain their original
meaning. Whole Avatar cleanup requires the component; its absence cannot be
converted into an empty timer inventory. Once observed, it cannot disappear.

The gated native source observes actual ScriptManager timer creation, firing,
callback entry/exit, full native dispatch return and QTimer destruction for
the five reviewed installed Avatar/Pal/request/protocol origins. It changes no
timer, callback, product handler or script. Immutable birth information and
actual weak destruction remain retained. Monotonic counters/depth snapshots
avoid an ever-growing log for the normal People 100ms update interval.

`pendingDispatch` spans the entire original `timerFired` function through a
native Finally scope. This distinguishes a real singleShot that was destroyed
before its JS callback entered from a callback stack that actually returned.
Weak death and callback depth zero by themselves do not close that gap. The
original protocol-only `worker.avatar` packet and its meaning are unchanged.

The strict decoder retains actual timer IDs, handles, installed caller chain,
birth/destroy clocks and firing/callback counters across observations. It
refuses disappearing or renamed births, counter rollback, changed once-known
destroy time, source birth reset or component downgrade. Cleanup selects every
original relevant manager by independently reviewed installed code pins; it
cannot substitute an unrelated empty manager. Only timer births absent from
the original baseline are owned by this feature. Earlier unowned periodic
timers may continue without being relabeled as owned cleanup work.

Every owned timer must have actual native destruction, no callback depth and
no pending native dispatch. The predicate reports the latest actual owned
endpoint, for joining to separate Qt/entity/file/pointer/HTTP and quiet-window
originals. It establishes no arbitrary avatar pose or pixel stability.

Host counterexamples exercise destruction before callback entry, a retained
QTimer, an active callback/native stack, changed source/module, missing and
rewritten histories, legacy packets and a continuing unowned periodic timer.
Native compilation and devices remain unverified. This component advertises
no whole-feature capability.
