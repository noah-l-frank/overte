# Original native Web script emissions

This prerequisite observes the actual `TabletProxy::emitScriptEvent` and
`EntityScriptingInterface::emitScriptEvent` call, its original ScriptManager
membership/submitted root code, each real queued capture, and actual native Web
sink entry/return. It does not advertise complete Tablet or World coverage.
Native Qt/V8 code has not been compiled or executed in this session.

The new `feature-ios-web-script-emissions` source has its own version 1,
instance, process clock, cumulative counters and bounded 2 MiB DTO. It records
only the closed four-member parity echo reply. Duplicate/escaped/private JSON,
login/protocol traffic, function names, source URLs and Script arguments are
not retained. Missing caller context is explicit `null`; equal message bytes
or a Work callback interval cannot manufacture attribution.

At the original World Surface connection registration point, a sender-owned
Direct relay captures metadata and emits an internal typed signal. That signal
uses Qt Auto delivery to the original Surface. Earlier/later public listeners
retain their registration order. The relay neither dereferences nor posts a
weak Surface pointer; Qt retains receiver cancellation semantics. The original
public `emitScriptEvent` body remains one unchanged signal emission. Ordinary
runtime-disabled connections remain unchanged. Tablet's original self/target
queue hops carry the same metadata through actual Qt metacalls.

Capture tokens own metadata only. API body return, real dispatched body return,
`finally`, queued cancellation, and actual weak capture expiry remain separate.
An exceptional original body keeps its original exception behavior. No retry
of uncertain product delivery is permitted. API target QObjects are weak and
never become owned by the observer. Their continued lifetime is not a leak
claim: the actual queued capture responsibility is tracked independently.

## Actual V8 stack and compiled source

A new engine-local metadata registry observes actual V8 `CurrentStackTrace`
frames by index. Each real frame supplies its actual Script ID, line/column,
original resource-name hash and the exact compiled source from V8's
`GetScriptSource`. The UTF-16 digest/unit count comes from that actual V8 string;
it never hashes a source URL or rereads a file in place of code. Each Script ID
retains its actual first source-observation epoch; this is explicitly **not** a
compilation timestamp. Identical repeated source preserves that first epoch;
a changed source under the same Script ID invalidates provenance. Unknown/eval/
aliased source, missing frames and overflow stay unavailable. Version is 1.
There are no product compilation/evaluation path hooks.

`selected_vm` proves actual native API/VM/root-code provenance only.
`selected(..., locations)` additionally requires the entire actual compiled
stack, exact locations and independently pinned compiled-source digests/units.
A URL hash alone is insufficient. Locations must be derived from the actual
pinned source bytes, including real compiler wrappers where present. A
same-VM untracked frame or nested frame fails that stronger join. The ordinary
pinned Tablet responder is synchronous and has no timer/event pump; the host
Node test runs its actual generated bytes and distinguishes an untracked
same-VM call. This is not execution of the native V8 hook on an iOS process.

Existing `featureAvatarTimerCallers()` is deliberately unchanged: its V8
ScriptFunctionContext wrappers currently repeat top-frame metadata instead of
indexing a full actual V8 stack. Avatar/Snapshot consumers need their own
reviewed/versioned use of the new seam before making stronger caller claims.
No instrumentation overflow mutates those unrelated ledgers.

The pure reader preserves actual World and Tablet identity schemas. Historical
prefix validation rejects native resets, rewritten API/caller/compiled source,
source birth changes, retimed terminal clocks and resurrected captures.
`settled` proves only the selected VM's observed API/capture/sink closure; it
is not product page/view/OS/SDK retirement. Those remain independent owners.

The optional transport factory is `FeatureObservation.web_script_emissions`.
Probe nonce de-duplication and closed Fixture validation prohibit replay and
caller-supplied expected success/caller data. Shared registry keys are
`ios-web-script-emissions` and `ios-v8-script-stack`, current/read version 1.

## Read-only native dependency review

`cmake/init.cmake` selects `BUILD_SHARED_LIBS OFF` on iOS. All four owning
libraries use `setup_hifi_library` without a per-target SHARED override; the
application links that closed static graph. The inline observer State and TLS
therefore refer to one program definition in this source configuration. No
cross-dylib symbol-visibility behavior is assumed. This is a source/link-design
review, not a compiled binary or device qualification.

No pinned V8 development package was present in the searched local paths.
The exact upstream V8 12.4.254.21 tag was read without installing anything:
[v8-debug.h](https://raw.githubusercontent.com/v8/v8/12.4.254.21/include/v8-debug.h),
[v8-script.h](https://raw.githubusercontent.com/v8/v8/12.4.254.21/include/v8-script.h),
[v8-primitive.h](https://raw.githubusercontent.com/v8/v8/12.4.254.21/include/v8-primitive.h).
The stack explicitly requests `kScriptId` in addition to `kDetailed`: that tag's
`kDetailed` enum does not include the Script ID bit, although the same header
states that deprecated options currently collect available information. This
is an explicit portability guard, not proof of a pinned runtime failure. Native/API compilation is
still unverified. The host Node Inspector test independently observes real V8
Script IDs and original compiled source across repeated execution and a changed
script under the same filename; it does not execute the iOS hook.
