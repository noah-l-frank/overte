# Explicit held-marker scene stage

The proposed retirement body5 is restricted to `avatar-people` and
`avatar-held-marker-scene-quiet`. It preserves the literal body1–4 readers and
the default Complete writer2. A scene5 receipt never satisfies a Complete
reader, closes an account, or proves that a retained Qt/native allocation died.
The existing journal rule still permits at most one scene stage for a cleanup
ticket, before its Complete receipt. A recorded older scene cannot be rewritten
as stage5.

`marker-gpu-sampler` covers retirement of the owned frame acquisitions. Actual
cached QSG, image, Vulkan and native-view allocations remain independently
listed as holders. `avatar-people-ui-current` and `marker-script-ui-current`
cover quiet current controls; complete native retained-root inventories keep
observed weak-alive operands owned through the process-end path. Original
marker entity/file/VM/listener/timer endpoints, restored view and marker-pixel
comparison remain mandatory. The scene summary retains account-session,
Login-root and process-resource responsibilities explicitly.

`IOSAvatarHeldScene` writes scene2 and produces this summary from the unchanged
original acquisitions and quiet endpoints. Its historical reader validates
the original marker scope2, sample2, entity weak lifetime, files, GPU originals,
PNGs, source histories and four independent quiet clocks. It also returns the
already decoded inputs for the later scoped/terminal join; this local dataflow
does not cache a derived cleanup verdict. Scene1 keeps its existing schema and
full-drain interpretation and rejects a scene2 envelope.

The shared protocol patch is not yet applied to the repository. An isolated
Python process loaded the exact proposed three source changes in memory:
five new authenticated protocol cases passed, the 45 existing body1–4 and
default Complete cases passed, and one complete Scene2 private-record case
passed. All three repository source hashes remained unchanged. These runs are
draft qualification, not production integration. Qt, native and GPU producers
are explicit host models; the marker Script, HTTPS routes, private files,
weak references and historical decoders execute as host code. Whole Avatar
terminal/SDK end and physical CPU/native/iOS qualification remain separate.
