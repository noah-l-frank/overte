# Durable authorization originals around an actual owned recording Start

`IOSAudioRuntime.authorization_sources` constructs a readonly collector under
the existing recording owner's held source lock and installed binding. It
retains each issued native/session query before delivery and every received
nonempty raw body before parsing. A closed profile of the existing immutable
file-source codec preserves bytes, hashes, inode identities and interrupted
prefixes. It cannot adopt a legacy journal or manufacture a replacement body.

Each successful cut joins the [passive session source](AUDIO_SESSION_SOURCE.md)
to actual enclosing native clocks and independent host UTC/monotonic clocks.
The `sessionClock` alias must equal the original session's native clock-after
epoch exactly; it is checked against the original body and native bracket.
No host file timestamp or saved sample is converted into native freshness.
The session/native instance, PID and lifecycle must agree. All issued query
IDs match retained raw bodies; unknown or partial readback remains diagnostic.

The cut links to an actual owned recording ticket and before/after reference.
A before-Start cut requires the still-pending operation with no issued Record
intent, the actual earlier input prefix and an inactive unchanged native cycle.
Once Start completes, its actual first recording event must follow that cut.
An after-Start cut must link to the completed owned operation's after reference.
An earlier successful Start cannot be relabeled as new before-input authority.
The collector pins the parent envelope and in-memory state throughout its
readonly acquisition; concurrent mutation cannot qualify a cut.

A saved logical original interrupted before reference append is adopted with
the same bytes and inode, without a new query. A failed readonly acquisition
can instead be retained as interrupted and followed by a genuinely new bracket
and new nonces. The original failure bodies remain unchanged. An incomplete
raw file prefix stays owned and cannot be reconstructed, abandoned as empty,
or substituted by a later source. Complete current inventory checks include
both artifact and session directories and refuse unknown ownership carriers.

Ten focused cases and the 45-case session/recording/background compatibility
selection pass. The connected case places a retained authorization cut in the
existing normal Record intent callback, delivers the actual normal Start, then
retains the after cut and replays both through the pure parent/source codecs.
Other cases cover denied OS permission, malformed original retention, new-cut
recovery, opened raw prefixes, lost saved-original append, parent mutation,
orphan originals and wrong stage membership. Pure archive construction requires
the historical parent and constructs no native/SDK reader. Native/audio/OS and
host clocks are explicit models; real private files, locks, normal input and
strict source codecs execute. No device or native compilation is qualified.

The collector does not issue recording or permission input. Still compose a
durable grant/denial decision at the ordinary Start boundary, permission
Settings/restart recovery, independent acoustic/Actor facts and whole Audio
retirement. An observed OS grant alone never proves gate capture or playback.
All carriers remain owned under the ordinary Audio session barrier; complete
capability admission remains closed.
