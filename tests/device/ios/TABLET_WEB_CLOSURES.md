# Original Tablet native closure history

The separate `ios-tablet-web-closures` version 1 source covers actual native
Tablet contexts for owned HTTP and inline inputs. Native code is uncompiled
and unexecuted. Host tests cover the strict source DTO, actual shared transport
and source-level neutral-state routing, not UIKit execution.

The existing WebClosures HTTP versions 1–5 remain unchanged. Their default
context factory, source state, HTTP filter, serializer, version and exact DTO
field grammar are preserved. Synthetic inline URLs are never rewritten as
HTTP fixture URLs, and an empty HTTP snapshot cannot establish inline drainage.

A native Tablet context is constructed only from the actual policy identity /
URL and immutable native SourceStamp. Its descriptor preserves the actual
visual root, normal navigation, fixture, and native inline carrier/binding
birth. The Tablet history has its own original instance, bounded cumulative
contexts and counters. Native read queries cannot supply a state pointer,
context, URL rewrite, desired counter or cleanup verdict.

The internal neutral `Context` adds an optional native static-state reference;
legacy `{id}` keeps its original default state. Existing callback and resource
retention sites continue to retain the same ContextPointer. Lease creation and
retirement, image-scope keys/failure callbacks, bitmap failure and associated
native-object error/overflow paths select that context's original state.
Native-object bag keys include state instance, context ID and resource kind;
equal numeric context IDs in independent source histories cannot collide.
Pointers are never serialized and no context retains a product object.

The source records actual native policy, WK view/delegate/presentation, callback,
bitmap/software/GPU resources through the existing neutral instrumentation.
The serializer emits only the requested fixture's original stamped contexts,
with at most 1024 contexts and 1 MiB of compact JSON. It does not reset history.

The Python reader validates exact descriptors/counters and immutable original
prefixes. An independent join binds context source, identity hash, policy grant,
actual native frame and view creation to genuine TabletSources and native WK
trace originals. Policy/delegate contexts created before the new WK view retain
their actual previous creation index and are joined to the later original
view-created event; they are not relabeled as the new view. The native document
epoch also remains its actual value before first navigation.

Retirement requires positive original policy/view/delegate/presentation and
JavaScript admission plus every observed callback/resource counter drained.
A returned callback alone cannot establish native weak-object death. Empty
admission, same-shaped foreign sources, source/counter reset and descriptor
rewrites fail closed. Acquisition freshness, a real quiet window, actual view /
inline source absence, original restored pixels, script/file cleanup and the
separate UIApplication/UIEvent/UITouch lifetime source remain whole-feature
obligations. Framework-internal caches and process termination are not inferred
from these counters. Feature 7 remains incomplete until those joins, all 26
normal actions, independent observation, recovery and repeated cleanup exist.
