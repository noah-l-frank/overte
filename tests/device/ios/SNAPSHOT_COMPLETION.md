# Original still-capture completion

`snapshot_completion.completed` joins the existing durable normal-input owner,
pinned Script work, native capture lifetimes and original byte/artifact owners.
The closed initial profile supports actual still PNG/JPEG control settings.
The independently clocked pre-capture manifest must be empty. Its actual
prefix, the ordinary capture control title and the resulting original native
filename must agree with the actual Script/native request identifier.

Both work originals must admit the exact installed Script source pins and
retain their actual manager and event history. One actual `takeSnapshot` call
must return and reach its finally boundary with the newly incremented capture
counter and request. The corresponding native request must be accepted and
produce one complete status with an actual nonempty path and no error. A
matching later `onNativeCaptureStatus` call must return, finish and clear its
pending state. The actual 60-second timeout timer must never fire. Retained
capture/worker objects and native timers must separately drain; a terminal
signal does not prove those lifetimes ended.

The complete query/byte/artifact chain is revalidated from actual private
originals. Binding, role, run, process, source lock, original native event
ordering and the exact basename remain joined throughout. An acknowledged
input, cleared Script state or successful native status cannot substitute for
the actual original artifact bytes.

The returned version-1 fact explicitly still requires decoded image evidence,
destination outcomes, an independent witness and whole-feature quiet. It does
not count a completed Snapshot area, system save/share/upload, scene fidelity
or a physical deadline qualification. The five-mode UI component remains
separate; this source prerequisite does not widen its capability.

Three composed no-build host tests use real private query journals, HTTP/AFC
and normal-input transports, actual byte files/artifacts and host weak-owner
lifetimes. Native Qt/renderer work, Script events and clocks are explicitly
modeled. They reject missing/foreign/failed/held native captures, different
request identifiers, missing callback returns, timeout execution and missing
actual artifact bytes. Existing production JavaScript semantics have their
separate real Node test entrypoint. Native compilation and devices remain
unverified.

## Actual image decoding

`snapshot_completion.decoded` reuses that complete capture/source/file join and
passes the same private artifact bytes to the existing shared
`snapshot_observation.inspect_snapshot` decoder. Mode and format come from the
actual ordinary controls. The decoded full-file hash and byte count must match
the retained native file manifest. The existing decoder checks actual encoding,
dimensions, complete frame data, stream termination/checksums and nonuniform
pixels. It is not replaced with an iOS-specific expected-image encoder.

The version-1 result retains both the original capture fact and actual decoded
image observation. Scene fidelity, independent witness agreement, destination
outcomes and whole-feature quiet remain explicit obligations. Five further
composed host cases decode actual PNG/JPEG private files and reject uniform,
truncated or differently encoded native output, even when its native status,
manifest hash and durable artifact agree. Image creation occurs only in the
explicitly modeled test producer; the adapter only reads original bytes.
