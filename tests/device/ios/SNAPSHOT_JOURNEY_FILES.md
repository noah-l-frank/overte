the same actual QML root, and its original title must equal the pending owner's
restored title. Envelope pins retain the complete pending journal/result and
the capture result/artifact journal. A replacement root, process or original
cannot be adopted as continuation of the pair.

for this run. Each must retain its exact first original empty manifest query
and sample time. Only the one actual PNG from the capture result, with its exact

for removal. A third prefix, substituted first nonce or other file refuses

accepted.

actual original ACK and native callback/weak-expiry observations. Reconstruction

never resends an uncertain deletion. A stale initial file admission remains

subsequent quiet groups contains two fresh default manifest owners, the actual
