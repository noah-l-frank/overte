# Existing-SDK Tablet bootstrap ownership

`TabletWebContext` binds a run/role to its genuine prepared physical SDK binding,
independently acquired read-only admission, and original native setup packet.
It uses the actual SDK root's held `script-feature-sources.lock`. It never calls
installed-code verification, writes the installed binding, creates a session,
opens an app Script, stops the process, or deletes an SDK.

The actual bootstrap query is journaled before transmission. Matching bounded
closed-grammar native bytes are saved in the existing immutable frame store
before interpreting their PID, setup-source birth or history. A safe wrong-PID
or source-reset receipt remains owned evidence and blocks another query. Unsafe
or unknown fields are not copied into a new raw host artifact: only their
actual byte length and SHA are retained alongside the issued-query owner.

The stored bootstrap packet preserves the original admission, setup packet,
query and exact raw JSON. Native source/lifecycle/history counters must follow
the real setup original. A returned original is a source floor, not a fresh
surface observation. Source acquisitions still require new native originals.

An unknown send never retries. Lost file flushes preserve the actual opened
inode and byte prefix. Recovery accepts only the complete original bytes;
incomplete prefixes and hardlinks remain blocked. Historical construction
creates no files, invokes no SDK/process guard, and forbids bootstrap/recovery.
Temporary native-reader hooks are restored on every exit, including errors.

Six host tests use the real private-file owner, real admission decoder and
native-reader implementation with explicitly modeled native/SDK boundaries.
They cover the normal original, wrong PID and source birth, unknown send,
privacy rejection before new raw storage, empty opened prefixes/hardlinks, and
complete lost-flush recovery without querying or rewriting the original inode.
No native compilation or device execution has occurred. This bootstrap is a
prerequisite; whole Tablet actions, pixels and terminal retirement remain open.
