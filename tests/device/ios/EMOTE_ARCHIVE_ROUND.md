# Scoped original Emote archive validation

An actual retained multi-cut host run exposed repeated decoding of the same
native, rendered, keyed, pointer and animation histories. The run was interrupted
for diagnosis, with no pass claimed. Both original directories were retained
before their first raw capture; all 855 files kept their exact paths, inodes,
lengths and hashes through interruption and subsequent replay. The owned Python
runner exited 130 after its outer cleanup, and no Node process remained in the
own worktree. This does not establish product process/SDK retirement.

The partial profiler recorded roughly 687 million calls. Repeated native
animation validation and discarded history copies dominated its cumulative
costs. The profiler was explicitly stopped after collecting those costs; its
incomplete read is not counted as a successful archive verification.

`emote_archive_round.scope` now inventories the complete artifact and both SDK
directories under the actual source locks before reading. Ancestor roots cover
their children once. Every reused typed native/rendered/keyed derivation is
bound to its exact class, envelope, path and immutable reference inside one
snapshot. The memo retains actual original-file read membership. The complete
inventory is checked before/after reuse and on scope exit; changed entries,
new files, replaced inodes and changed metadata fail closed. The bounded
derivation memo ends before any caller may save metadata or acquire new data.
Current guards and mutable responsibility are not memoized.

The shared source helper `pure_original_validation` has internal API version
one and is inactive by default. Only the explicit
`ios-emote-rooted-archive-v1` scope activates it with the complete inventory
guard. Native animation validation keeps its public signature, literal history
versions one/two and full original checks. Emote native-prefix validation keeps
its literal grammar. Successful pure validation may be reused only for the
same function and all identical arguments, including original clock bounds.
Unsupported Python types run the original parser directly. Disposable marshal
keys preserve tuple/list and subclass distinctions and are never persisted or
loaded as code. There is no wire-format change, clock renewal or timeout increase.
Reconciliation with Phone/Pico must carry the shared helper together with the
native-animation wrapper; the other additions and activation are iOS-only.

The retained Primary two-cut graph passes full typed cold replay, including
comparison with the measured-graph digests produced before optimization. The
successive actual timings were 48.392 seconds (typed derivation reuse), 36.755
seconds (pure animation validation reuse) and 29.046 seconds (also pure native
prefix reuse). The first two exceed the unchanged thirty-second budget. The
last fits it; this result covers that two-cut graph only. Whole terminal,
three-pair, both-role and full journey budget qualification remain open.

Two inventory/memo counterexamples pass in 0.036 seconds. Fourteen initial
history/type/inventory regressions pass in 0.050 seconds; twenty-six native
transport/history/type/inventory checks pass in 0.186 seconds, followed by
three explicit false-inventory/type/prefix checks in 0.003 seconds. Four actual
rooted archive/native/rendered/keyed composition regressions pass in 82.638
seconds. Rewritten clocks, tuple/list or mapping subclasses, nonadvancing
prefixes, foreign processes and changed originals remain rejected. Native,
Qt, GPU, SDK and acquisition clocks remain declared models; builds and devices
remain untested.

The five no-build project suites pass in 6.95 seconds; registry and whitespace
checks pass. Independent retained Actor publication selection also passes in
3.730 seconds and rejects a one-millisecond rewritten receipt in 3.737 seconds.
This last result covers the original publication join, not a three-pair seal.

## Current component original reads

The later three-pair host run was interrupted after more than thirty minutes
of CPU work. Primary returned all three additional observations; Actor returned
the first two. It is **not a pass**. All 1,437 files in its two original roots
retained their exact paths, device/inode identities, lengths and hashes after
the owned runner's exit 130 and outer fixture cleanup. No target process-end
claim follows from terminating this host runner.

Current rooted native/rendered/keyed constructors and derivations now delimit
their pure original parsing with `component_read`. Their actual current decoder
always executes, including pending-state and unaccounted-next-file checks.
Current derivation results, SDK/native guards and writes are never memoized.
Only the existing pure validators can reuse identical successful arguments;
the complete original inventories and both actual locks are checked before
the scope returns. Any metadata change inside that read fails before its result
can escape. Legacy component readers and all wire versions remain unchanged.

The complete census now carries relative entry names during traversal, avoiding
repeated `Path.relative_to` work. Every entry still receives two real `lstat`
calls; `DirEntry.stat` caching is deliberately avoided. Ownership, file type,
link count, device/inode, mode, size, timestamps, depth/count limits, full entry
membership and exact declared mutable-path exclusions retain their existing
checks. Eleven censuses of the same retained Primary/Actor roots decreased
from 0.184/0.187 seconds to 0.064/0.067 seconds. This microbenchmark does not
qualify a feature operation's deadline.

Thirteen no-build filesystem, scope and actual rooted composition regressions
pass in 71.003 seconds, including same-length rewrites with restored mtime,
replacement, links, missing/new entries, mutation during the census, changes to
current metadata during a component read, historical prefixes and legacy
reader rejection. A separate profiled four-cut Primary archive replay preserves
its pre-optimization measured graph digest; its 53.791-second profiler timing
does not qualify the unchanged thirty-second terminal budget. Multi-cut window,
whole terminal, current acquisition budgets and full feature qualification
remain open.
