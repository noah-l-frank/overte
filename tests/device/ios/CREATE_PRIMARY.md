# Primary Create originals

Feature 4/14 remains partial. This packet joins primary observations, original
world pixels and product export bytes. Full marker recovery, paired retirement
and operation dispatch remain separate work; native code and devices are untested.

`CreatePrimary` owns two actual `CreateSources` acquisition groups per sample.
The immutable records retain exact native/host clocks, real fixture phase,
actual action ownership snapshot, source-file references, qualified GPU owner
and original export copy. Interrupted acquisitions remain historical. A complete
record saved before index adoption is recovered without repeating its reads.
An action receipt supplies owned UUID admission; public state is derived again
from actual native entity, UI, resource and renderer originals.

The initial sample precedes marker preparation and must have no owned resources.
Later observations account for the source-validated local marker Script/entity,
actual editor/picker, domain entities and native input/output files. Stable
unowned semantic maps are preserved across every source/pixel group. Native
process/birth/counter prefixes, lifecycle and original phase are joined within
a measured 1.5-second native/host window; different devices keep their own clocks.

The actual fixture stimulus determines required image/change/file evidence.
A changed image uses the last qualified original from a different actual input
ticket, including the sample owner's strict native sequence/frame chronology.
Every capture request is retained before native delivery. A failed challenge
keeps its PNG and original GPU retirement; a fresh read has another request and
never repeats Create input. Host tests also retain a lost successful acquisition.

Each export observation acquires fresh native output bytes and creates its own
exclusive private copy with a distinct actual host inode. Existing product
output is not generated, overwritten, or relabeled as a newly written product
file. The common artifact clock comes from the new bounded original read.
The native pre-Save output-absence original and actual selected rendered Model
remain part of each copy's source validation.

Historical pure source/pixel validation may be memoized only for unchanged
original hashes and predecessor content. Every use still hashes the real source
carrier and original owner bytes and reads the inode-bound original PNG with
its actual native chunk hashes. Outward values are copied. This memoization
creates no new clocks or fresh observations.

Eleven host tests cover all 21 normal action recipes with 22 primary observations,
12 modeled renderer PNGs, actual temporary input/export files, permission denial
and retry, followed by reconstruction without additional SDK/GPU commands.
The modeled renderer derives visible differences from actual material, geometry
and voxel properties; UUID or creation metadata cannot change its colors.
Counterexamples include lost reads/index adoption, replaced source
carriers/PNG, invalid native birth/counters/order, phase changes, absent/current
challenge failure, a mutated predecessor behind a warm cache and retained
failed GPU ownership. Native/SDK/renderer effects
are modeled; these are host adapter tests, not real iOS product verification.
