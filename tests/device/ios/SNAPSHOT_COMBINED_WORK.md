# Snapshot work in the normal combined default-script manager

Feature 11 remains capability-closed; five of fourteen areas are source-complete.
Normal `defaultScripts.js` includes Snapshot in its existing manager. The older
Snapshot work/capture version-1 path admits the separate Snapshot manager used
by the default-script debug option. Neither the existing HTTP reader nor a
changed debug setting supplies the missing normal combined work evidence.
This component changes no product option, debug setting or Script load.

The gated native prerequisite adds a closed SnapshotCombined profile to the
existing source and timer observers, with separate original instances. Source
observations come from the actual evaluate/include/require call sites for
exactly `defaultScripts.js`, `system/snapshot.js`, `modules/request.js` and
`system/snapshot/featureSnapshotWork.js`. The actual default-manager main code
must match its own submitted evaluation. The existing separate Snapshot and
Social1/2 profiles keep their original default schema, filters and values.

The existing work ledger has a separate Combined instance. Its initial owner
requires the actual Snapshot and helper frames, the true assigned default
manager and the actual submitted code. Later helper samples retain their own
indexed V8 caller references; every original frame must resolve against the
four observed installed modules. Unknown, foreign or missing compiled frames
cannot become an invented parent. No Script-supplied source URL alone proves
the caller. Caller records, state samples, closure entry/return/finally and
original sequence/time values remain retained.

The existing `AvatarUiWorkObservation` has one closed combined Snapshot timer
profile. A birth requires real Snapshot/helper callers in that same manager.
It observes the original QTimer handle/properties, fired callback, callback
entry/leave, QObject destruction and the return of the whole `timerFired`
dispatch. Single-shot destruction before callback entry cannot count as quiet.
Unrelated default-script timers do not become Snapshot ownership. This does
not establish weak death of the default manager, all other features or the
process/socket/SDK resources.

New observer calls catch diagnostic failures locally and retain an incomplete
flag; they do not cancel or change the actual timer, callback or Script
evaluation. Shared value-type fields use the existing uniform global E2E+iOS
guards, preserving the same layout across all participating translation units.
No target-only ABI condition, CMake change, build, install, service or device
operation is introduced.

The fixed `feature-ios-snapshot-combined-work` getter/probe/AFC route now has a
strict host reader and independent repository UTF-16 source pins. Commands
cannot request a manager, quiet state or profile. The existing query ledger
consumes each nonce before observation, including unavailable or failed reads.
The fixed Combined and preflight-HTTP original filenames use the existing
compact, private-permission atomic writer and symlink refusal. The reader binds
the actual process, native acquisition clocks and source prefixes; a normal
work event and its manager's timer births must share their actual V8 engine
and immutable compiled ScriptId identities. Every included source and the
default manager's main code must match independently reviewed pins. The
separate1 and Social1/2 readers keep their existing literal grammars.

No-build evidence is deliberately limited to declared Qt/V8/native/HTTP/AFC
models and actual unchanged JavaScript. The product default-script loader ran
in Node with a read-only boundary: its normal mode included Snapshot exactly
once, while its separate mode loaded it once; no option was changed. Eight
new codec/negative cases passed in 0.172 seconds, and the actual probe plus
three bound factory/transport cases passed in 0.185 seconds. Forty-eight
focused compatibility/source-boundary cases passed in 0.172 seconds, including
the old separate work, Avatar timer/caller and Social HTTP readers. The first
codec attempt exposed a local function/integer name collision, which was
corrected before these passing runs; its failed log remains unchanged.
The final fourteen-case loader/codec/probe/runtime selection, including the
private writer boundary, passed in 0.259 seconds.
