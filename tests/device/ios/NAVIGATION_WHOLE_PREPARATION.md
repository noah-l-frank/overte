# Whole Worlds preparation on original image owners

`NavigationWholePreparation` wraps the existing `IOSNavigationFeature`. Before
the first ordinary Go To it owns separate primary and actor untouched static
images, then acquires the actual new scene admission immediately before input.
It uses the existing runtime's candidate-qualified readers, native clocks,
Vulkan owners, static-source validators and normal input coordinator.

Each image request is durable before its first query. The two actual full-target
PNG owners and original static/native cuts remain distinct and ordered. The
fresh admission must follow both images, preserve their actual scene semantics,
pose, bookmarks/preferences and source prefixes, and retain its own original
freshness window. Acquiring the images never renews an earlier admission.
Only then can the existing normal scene-input owner enter the controlled run.

An issued request without its child original remains unresolved. Partial image
or source acquisition never queries again. A completely retained child after a
lost return can be adopted through its historical decoder without replacement
bytes, another capture or a new timestamp. The whole entry similarly adopts
only the existing actual Go To acknowledgment after a lost parent write.
Historical images and the old admission remain original after process transfer;
they cannot establish fresh observations in the new process.

The parent writes/reads `ios-navigation-whole-preparation` version 1. Child
baseline, Vulkan, admission and input versions and paths remain unchanged.
Host tests exercise real private journals, source readers, PNG ownership and
ordinary input framing against explicit native/GPU/SDK models. They cover both
images before admission, lost completed-child and whole-entry returns, unknown
delivery, partial originals and changed candidate availability. No compilation
or device operation ran.

This is whole-run preparation, not complete Worlds support. The whole dispatcher
still needs ordinary failure/restoration ownership, original paired restored
observations, its independent observer worker and its source-to-seal/process-end
decoder for the [explicit terminal profile](../feature_journeys/TERMINAL_RETIREMENT.md).
No complete feature or optional terminal capability is advertised by this owner.
