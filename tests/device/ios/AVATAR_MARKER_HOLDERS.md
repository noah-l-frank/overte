# Actual marker holders before process end

`adapters.original_marker_holders` has two closed profiles, `avatar` and
`emote`. It consumes unchanged WebClosure5, ScriptUiInventory2 with
ScriptUiRootOwnership1, and native process originals. It does not acquire an
SDK, execute input, publish a receipt, or declare cleanup complete.

Web disposition requires original source continuity and zero pending callbacks
and policy grants. Full rendered admission also requires the original resource
creation counters. Every remaining native/image/GPU resource is retained under
its actual kind and context descriptors. Its counters are never rewritten to
zero. The private holder retains all contributing original contexts.

UI disposition requires a complete current whole-tree inventory with no open
manager, picker or tablet. It separately retains actual weak-alive observed
manager/picker roots, including detached roots. `firstObserved` is an observation
time, never a constructor time. Inventory1 cannot supply this proof. Unchanged
root rows and resource counters can support a quiet interval only when the
calling owner separately validates all acquisition clocks and current input
quiet. Empty observed-root history does not prove that no transient root ever
existed.

The process holder is conservative outstanding responsibility for the actual
PID/native instance and original lifecycle. It supplies no QObject identity,
callback quiescence, weak expiry, image absence, or process-end evidence. An
independent original OS/SDK end must discharge this responsibility. The terminal
codec receives only the closed resource/kind/hash projection; complete originals
remain in the private source graph.

The profile DTO namespaces are distinct. The shared policy preserves both
features' original source DTOs; it is not an adapter capability.

Host checks use actual parsers, private immutable files, actual Python weak
objects and modeled native/GPU producers. They cover pending cached resources,
callbacks/grants refusal, missing rendered admission, detached-live roots versus
actual weak expiry, old/incomplete inventories, foreign process/source, and
profile separation. Native/iOS execution and physical timing remain untested.
