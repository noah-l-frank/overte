`emote-rooted-final-<run>-<role>-<index>.json` namespace. The existing legacy

and filenames. Neither family can be relabelled into the other.

The rooted transaction accepts only freezing and validated phases. Begin still
requires an independently obtained inactive original Emote phase packet. It
stages exact metadata values before copying, reuses an identical existing host
copy after a lost return, and independently qualifies the copied graph before
validation. Explicit false validation is rejected. Current metadata remains
present; retire raises pending and retiring/complete packets are rejected.
These host copies do not replace missing native, image or publication originals.

checked paired live window and its responsibility guards. The caller must
retain the paired inventory guard while acquiring these metadata copies.
`IOSEmoteRootedState` independently reopens those exact supplied copies. It has
no runtime or target transport. A missing entry cannot fall back to a current
SDK file; explicit absence remains explicit. Each read starts a new consumed
set and rejects extra copies outside its typed role graph.

their current five-component snapshots, latest ordinary Source/Peer/Scope/
