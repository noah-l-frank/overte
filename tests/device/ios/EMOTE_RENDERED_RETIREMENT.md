# Native and rendered Emote retirement originals

`IOSEmoteRenderedRetirement` is a separate journal above the existing native
`IOSEmoteRetirement` predicate. It does not change the latter's version 1 DTOs.
Its version 1 metadata and immutable originals use
`iosEmoteRenderedRetirementVersion` and
`iosEmoteRenderedRetirementOriginalVersion`; registered keys are
`ios-emote-rendered-retirement` and `ios-emote-rendered-retirement-original`.

Construct it from the native retirement owner, the matching original restoration
frame owner and a separate private metadata store. `retain(...)` accepts exactly
`nativeReference`, `frames` (the actual frame-owner metadata snapshot),
`initialReference` and `currentReference`. Native references must be admitted
native originals. The cleanup frame must be the last record of a frame owner
without pending ownership. The initial frame predates the actual Scope baseline.

Historical `derive(reference)` reconstructs the complete native Scope, original
callback/listener/VM/thread, Qt pointer quiet, API-return/Tree/weak-expiry, native
file absence and GPU cleanup proof. It independently joins the cleanup image
after the actual Entity/File native endpoint and before the actual source/peer
cleanup observation, whose own final pointer receipt follows that observation.
Original animation call counters remain unchanged from the quiet interval
through the Entity/File endpoint, fence and own source window. A new native
override/restore after quiet requires a new quiet interval even when the later
graph is already idle and its captured raster has returned to the initial image.
The former marker projection is measured against the untouched initial PNG under
the restored original camera/domain/body/tree.

The complete world-target raster is also compared with the original initial
raster. No image is filled, masked or rewritten. At most 0.1 percent of pixels
may change by more than ten channel levels, and mean channel delta must not
exceed 0.5. This conservative admission requires a quiescent controlled scene;
uncontrolled world/avatar motion fails the predicate. It prevents a marker-only
comparison from ignoring stale avatar pixels elsewhere in the actual target.

The derived retirement provenance names
`ios-emote-rendered-retirement-original` and the immutable composite SHA. The
existing publication protocol remains unchanged: an eventual full coordinator
must use this decoder before actor publication. Immutable-write loss resolves
the exact journaled candidate without reacquiring product data. Unqualified
originals remain in the separate abandoned journal.

Five host tests use modeled native/Qt/GPU producers, the actual staged marker
Script running in Node, real ordinary Script/File/View recipes and actual private
PNG/inode evidence. A positive joins original pre-marker camera, actual normal
Look At setup, restored camera, callback/VM/Qt/entity/file quiet, new fenced PNG
and native source observation. It also reconstructs a lost immutable-write
return without a new product read. Negatives reject a later fence borrowing an
earlier source observation, a cleanup image used as the initial image, an older
cleanup reference hidden behind a later frame, new native override/restore calls
after quiet, and stale raster pixels outside the marker projection.

This is an internal prerequisite. The full action/actor/paired repeated cleanup,
final archival, dispatch and configuration remain separately required before
advertising complete Feature 5. Native compilation and device execution remain
unperformed in this source-only task.
