# Avatar session-retirement components

`IOSAvatarSessionQuiet` observes one actual admitted SDK after the original
fixture input journal has become inactive. It uses the existing closed State3
postlogout reader, account-only original observations, Tail2, privacy-qualified
Keys2, actual UIKit keyboard/inset observations and pointer/contact originals.
The original phase status brackets each acquisition. All native samplers retain
their original source DTOs, query UUIDs, process and native clock identities.
No World, normal input, account backend GET or publication is requested.

At least three distinct complete original groups must establish three seconds
of actual host and key-source quiet, excluding the boundary acquisitions. The
pure subject calculation is shared with `IOSAvatarFinal` without changing any
Final1 packet, field, clock, history or verdict. The new component returns no
public baseline, resource list, provider availability or Complete receipt. The
whole caller must separately validate the unchanged pre-DELETE provider and
Scene/Complete originals, both account restorations and rendered retirement.

Every component snapshot and final original is an unchanged private immutable
file. Planned/opened/saved inode ownership is durable before the next operation.
A fully saved return can be adopted without a source query; abandoned partial
reads preserve actual subordinate query ownership and prefixes. A new read
uses a distinct nonce. A slow final write cannot produce a fresh result; its
unchanged original remains available only through historical reconstruction.
Unsafe legacy key payloads are rejected by the existing Keys2 admission before
any new host artifact. Historical reconstruction performs no SDK or HTTP call.

`IOSAvatarFinalArchive` retains the exact original fixed metadata, including
actual absence, before retiring any source path. It validates every retained
value against its declared source hash and private kernel file identity. The
caller supplies the separate whole-original qualification before CAS deletion.
A lost copy or discard return is adopted; an absent original source is never
recreated. Changed metadata, replacement inodes and hardlinked originals block
retirement. The immutable artifact tree is guarded across qualification and
retirement. This component performs no native, backend or normal product action.

`AvatarWholeSnapshots` provides the same private file transition protocol for
whole-coordinator references. These are retained owner data, never additional
independent product observations. Existing source DTOs and shared private-state
size limits remain unchanged.

The new version-1 contracts are `ios-avatar-whole-owned`,
`ios-avatar-session-quiet`, `ios-avatar-session-quiet-original`,
`ios-avatar-session-quiet-proof`, `ios-avatar-session-owned`,
`ios-avatar-final-archive`, `ios-avatar-final-copy` and
`ios-avatar-final-copy-storage`. Storage contracts cover their fixed namespace's
Original1 and Frame1 envelopes. They do not alter `original-frame-store`.

Host tests compose actual private files, inode/CAS checks, original phase and
account-scope retirement, existing native source owners, prefix validators and
historical decoders. Qt/application/SDK boundaries are explicit modeled
producers. The entire paired Avatar journey and canonical session wiring remain
separate pending qualifications; these components advertise no area capability.
