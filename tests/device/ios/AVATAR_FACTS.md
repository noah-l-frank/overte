# Composed Avatar and contacts observations

`IOSAvatarFacts` derives all nine public Avatar/People fields from independently
retained originals. It receives both actual SDK source histories and peer
histories, the observing role's original Vulkan sample owner, a bracketed
controlled account-provider read and exact input-phase references. The actor
uses its own primary-SDK reads and its own remote-primary pixels; it never
copies a primary normalized result or an action acknowledgement.

The original appearance decoder establishes model identity, true request
failure, loaded geometry, scale, original wearable API ownership and persisted
bookmarks. Independent Pal roots, consumed original HTTP response bytes,
reviewed VM modules and materialized complete tables establish contact state.
Pending consent requires the same actual request UUID on both targets. Account
input bindings must agree with actual native sessions and the current domain.

Fresh received AvatarMixer records and actual remote geometry establish peer
replication. The current PNG must belong to the actual selected self or remote
primary avatar, model, scale, domain and mixer, and preserve unowned entity
inventory. Both complete image phase originals must match the source phase.
The three changed-pixel steps also require the preceding phase's original
image, current full-marker exclusion and separately measured subject pixels.
All native epochs remain within their own actual process clock domains.

`IOSAvatarSurface` owns observation navigation separately for each observing
role and subject SDK. Each phase uses ordinary Home/People/Connections inputs
to obtain a fresh product fetch. Actual incoming/outgoing prompts are sampled
without accepting, declining or cancelling them. Every original Qt command and
UIKit open intent is persisted before dispatch. A lost delivery remains owned
and cannot cause a repeated input or a fresh table fetch on reconstruction.

Host coverage composes real private source/peer archives, original PNG/chunk
ownership and actual account/OAuth/social-provider logic at explicitly
synthetic native Qt, AvatarMixer and renderer boundaries. It also exercises
real ordinary Python input transport separately. Pure historical decoding
performs no SDK/provider request or file mutation. Counterexamples reject
wrong sessions, missing consumed provider responses, stale source/image
references, foreign roles and acquisition-window substitution.

The contracts `ios-avatar-facts-original` and `ios-avatar-surface` write/read
version 1. This packet does not advertise an area capability. The live
observation coordinator, full feature preparation and paired retirement remain
separate integration work. Native compilation and device qualification have
not been performed.
