# Rooted original Emote receive continuation

Feature 5 remains partial and complete capability admission stays closed.
The default and held observation decoders still write/read literal original
version one. Only the explicit rooted observer can select original version two,
adding one `peerContinuation` reference to its own earlier observation file.
Observer envelopes and record headers retain their existing versions/grammar.

When the current receive ring has dropped records beyond the phase-start
barrier, the rooted observer looks for an actual earlier literal-one
playback/restoration observation of the same measured source episode. The
decoder reopens its exact private file and verifies its digest, role, bindings,
run, original sequence and phase instance. It fully rederives that initial
observation, including actual source caller/clip/evaluations, original two-record
receive motion, changed external pose and independent image bytes. An earlier
continuation, self/future reference or missing original cannot supply the anchor.

The original baseline/before/played references must still identify the same
episode. Actual source/peer phase births and activation prefixes must continue,
as must native/source/receive/renderer identity and clocks. The latest completed
peer cut supplies the new before reference. The unchanged strict movement
decoder then requires at least two actually new differing joint records and a
changed evaluated external pose. Dropped intervals themselves prove no motion.
No absent row is recreated, no old clock is renewed, and no input is repeated.
New override episodes require their own initial proof. Quiet or static later
poses without that fresh motion remain unavailable through this profile.

All existing current source, recovery, original acquisition, marker, PNG and
publication checks still execute. Historical derivation contains no transport
or write path. No current candidate guard, process lifetime or cleanup fact is
replaced by a prior public result. The exact observed current state continues
to come from the current source and image cut, never from the anchor's answer.
