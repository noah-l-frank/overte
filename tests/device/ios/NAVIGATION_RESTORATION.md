# Worlds current-process restoration owner

`NavigationRestoration` connects the existing post-restart Worlds owner to
fresh independent restored source/image acquisitions. It pins the actual
cleanup ticket, current candidate/process, original admission, transferred
process, untouched baseline PNG, prior role image and directory original.
Both entry and every before/after guard reject a changed cleanup phase.

The unchanged canonical phase publisher can additionally decode a versioned
restoration reference against these exact original images. Historical decoding
derives the same public facts and global sequence without a live source read,
freshness renewal or another GPU acquisition. Active and post-restart references
keep their existing interpretation in the same append-only actor journal.

Each new image has a durable parent request before acquisition. An unknown
issued child remains unresolved; a complete retained child can resolve a lost
parent return without another query. Historical decoding reopens the original
files and never acquires another SDK/native/GPU source. Current observations
still enforce the existing original freshness deadline.

Public fields are derived from the actual Places, error, navigation and rendered
state validators. Retained Places and Address Qt roots remain explicit resource
aliases. At least three original restored PNG/source/input cuts must pass the
existing three-second quiet decoder. That result explicitly still requires a
native lifetime end. Hiding a panel does not establish root destruction.

The host tests exercise actual private files, journals, source/image decoders,
normal-input fixtures and lost-return cases. Native/GPU/SDK boundaries and clocks
are explicitly modeled; these tests do not qualify physical iOS behavior or
host timing. No native compilation or device execution was performed.

`from_history()` reconstructs the exact original admission, restart receipt,
transferred process, role source graph and baseline without requesting an SDK,
native source or fixture. Its write and acquisition entrypoints reject use.
An independently retained `ios-navigation-restoration-phase` version 1 carrier
keeps the original cleanup authority before the restored image acquisition;
this stricter terminal path cannot qualify an older archive lacking that
original. Existing restoration and publication reference formats remain 1.

`navigation_terminal_resources.held()` joins each retained alias to its actual
Places model or Address UI root and original carrier hash. The binding uses a
hash of the actual SDK session identifier. This privacy projection cannot
establish root destruction or substitute for the later OS process proof.

This component currently supports the already-proven restarted process only.
Partial setup, pre-restart failure restoration, paired worker/dispatcher and
source-to-terminal process/SDK retirement remain required before the complete
Worlds capability can be admitted.
