# Independent ImageReader queue source

This separate source protocol reads the optional ImageReader Qt-event bridge.
It does not migrate ImageReader Source1 or ModelOrigin History5, add a retirement
join, or establish native/device execution. All physical storage, arbitrary
byte-copy, base/pool, decoder, GPU and Resource completion flags remain false.
Actor/backend/source/process/SDK end responsibilities and overall5/14 source
completion remain open. The native bridge and optional QtCore patch are still
uncompiled; see [the native boundary](ASSETS_IMAGE_READER_QUEUE_BOUNDARY.md).

The fixed action/getter/private file are feature-ios-assets-image-reader-queue,
featureIOSAssetsImageReaderQueue and feature-ios-assets-image-reader-queue.json.
The only request fields are schemaVersion, commandId, action and runId. The
request cannot choose a Source1 parent, task, dispatch, receiver, URL/hash,
payload, desired phase or drained state. The full Probe consumes each nonce
once, including unavailable or missing-getter outcomes. Getter/ACK delivery is
not product effect or argument destruction. Missing optional API/parent remains
unavailable; an empty response is never interpreted as drained evidence.

The dedicated iOS feature-test getter uses the existing native main-thread
bracket, unchanged size/clock limits and private atomic0600/symlink-safe storage.
The canonical host factory preserves the current session, exact candidate,
current PID and foreground guards and original AFC file. No ScriptManager
product NativeCall-whitelist entry is added for this passive getter.

History1, outer read1 and acquisition1 are independent contracts, current/read1
only. The strict codec rejects unknown fields/versions, bool-as-integer values,
malformed/foreign identities, oversized/empty histories, duplicate event or
receiver identities, phase loss/rebinding, clock rewrite/regression, weak
resurrection, failure healing and invented completion. Actual event identity
and receiver/method joins supply queued provenance; FIFO, equal payload or a
single pending row cannot replace them. Direct calls retain Source1's existing
synchronous authority and gain no guessed queued event or argument destruction.
Cancelled events can destroy arguments without any delivery or receiver.

Qt UTC/steady-nanosecond clocks remain distinct from Bridge UTC/elapsed-ms
clocks. A Qt callback samples before waiting for Bridge's mutex; a receipt
published after a previous query can therefore retain an earlier original
clock. That clock is never shifted to the prior Bridge snapshot. Existing
phases are immutable and within-Qt-event chronology remains checked. Delivery
and argument destruction can finish before invokeMethod returns on another
thread; no false ordering between those independent phases is imposed.

Authoritative read requires a real Source1 reader. After reading the queue
original, it acquires a new Source1 original, re-reads its actual raw file and
checks equality with that capture and its acquisition digest. PID/run, native
Source1 instance and actual task/dispatch/resource/receiver references must
match that actual original. The Source1 packet comes after the queue capture,
so later recorded Source1 phases can support existing queued receiver IDs.
Replacing a reader object cannot heal observed Source1 failure/history loss.
The combined binding keeps the existing1.5-second limit and does not change
either underlying source's original clocks or acquisition timestamps.

The returned source record alone is structural metadata. Bound facts are
exposed only after actual-parent verification; callers composing durable proof
must retain both original packets and acquisitions. Failed binding clears
current bound facts. No source row is a cleanup or physical-end receipt.

The exact fifteen focused cases passed. They cover actual two-source model originals, reversed
equal-payload events, direct/cancel/early-delivery paths, buffered original
clocks, foreign/forged parents, schema/type/capacity/history/failure negatives,
full Probe nonce/missing-getter behavior, and actual canonical host/AFC methods
with an explicit SDK fixture. All5124 source/launcher paths retained identical
bytes, metadata and SHA-256 before and after that selection. These cases execute
the actual host/Probe/AFC methods with declared native producers; they execute
no Qt/C++ or device and establish no native, performance or end qualification.
