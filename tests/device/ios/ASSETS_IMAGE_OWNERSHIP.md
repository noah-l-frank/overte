# Assets image runtime and historical ownership

This component keeps the complete Assets capability closed. It neither
increments the 5/14 source-complete count nor establishes installed-device,
Actor publication, per-Model native drawing or whole-journey retirement.

The private runtime factory constructs the existing actual ParsedInput and
Marker parents, bound Create/ModelRenderer/AvatarRenderer readers and one
Vulkan frame child. The request nonce, target binding, run, primary role,
canonical metadata paths, independently supplied artifact root and existing
held source lock must agree. The factory performs the mandatory installed-code
identity/freshness checks, but does not prepare, acquire or advertise an image.
Host brackets use the true host callback; native samples retain their own clock.

Historical inspection constructs no transport and cannot issue input, query
current state, write, delete or retire a resource. It reopens the actual typed
sample WAL, raw-before-parse originals, immutable logical source, original PNG
and current Vulkan child metadata. A later inspect/release transcript must
extend the retained original prefix without changing its binding, artifact,
request or immutable frame. Missing native-child metadata after acquisition
started remains unavailable. Pending raw/logical writes and live/unknown GPU
ownership remain explicit responsibilities; they never imply an empty source.

The enclosing Assets inventory accepts these namespaces only with an explicit
`ImageInventoryContext`: independently supplied root, binding, run, initial
Marker ticket and the already held canonical source lock. It never selects an
external root or grants access from an envelope. The existing ParsedInput
decoders supply the actual original parent. The original Marker parent and
child must have completed normal cleanup, current files/script ledgers must be
absent, and every Marker-prefixed private file must have been physically read
by the original decoders. An active or uncertain Marker stays unavailable to
this historical route. Unknown profiles, orphan originals, foreign roles,
unread recovery files and substituted contexts refuse admission.

Even a successful closed image inventory retains `marker-originals` and
`image-originals`; the existing parsed/cache/resource responsibilities also
remain. The ordinary installed-session gate supplies no image context and
continues to block replacement/cleanup of these owners. This reader is an
explicit composition primitive, not authority to discard the retained files.

The fresh host fixtures execute original QML, normal staged marker JavaScript,
private raw/logical/WAL writes, actual PNG bytes and file/inode validation.
Parser, Qt/native, renderer and raster behavior remain declared boundary
models. Native code is uncompiled and devices are untested. A fenced original
PNG plus mesh bounds/items and global forward draw count does not alone prove
a per-Model native draw. Normal removal image comparison, Actor image/publication,
cache/texture/GPU/OS resource retirement and shared journey end remain open.

Exact focused results and retained failure logs are recorded in
[the image integration handoff](ASSETS_IMAGE_WIP_RESUME_20261027.md).
