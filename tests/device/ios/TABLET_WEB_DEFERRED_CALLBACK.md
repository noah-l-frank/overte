# Original deferred Tablet inline callback

This separate E2E-only fault scheduler is under source review. Native code has
not been compiled or executed. It does not qualify the complete Tablet Web area.

An arm request contains only run/root/native request nonce and `operation:arm`.
It supplies no envelope, text, callback, document identity, expected count or
feature result. The actual native view registry selects exactly one currently
verified, finished Tablet inline view with a current original inline binding.
The selected native SourceStamp, creation, policy grant, page, nonce and URL are
immutable admission metadata. The scheduler has one occupied slot globally,
including a callback currently being delivered whose capture is still alive.

The actual WK delegate arrival reaches `IOSWebViewNative::message` before its
existing current-generation admission guard. Only an armed actual Tablet inline
source and the next genuine controlled parity `emitWebEvent` request can be
held. Initialization, other WebChannel protocol operations, arbitrary payloads,
foreign sources and ordinary World traffic cannot fill it. The original UTF-8
envelope is capped at 4096 bytes and must contain exactly the existing parity
echo contract/action/sequence. No expected payload is constructed from a fault
request.

The retained callable contains original immutable NSString/NSURL argument
copies, original generation and QPointer owner from that particular native
arrival. It contains no WKScriptMessage, WKWebView or strong product owner.
Its eventual call reaches the unchanged original current-generation and native
document/policy admission path. After inline policy/carrier retirement this
same old callback must be rejected there; a return receipt alone does not prove
that rejection. Independent original native/script histories and the measured
three-second quiet interval must prove no late accepted request or echo.

`bufferPending` reads the actual stored callable slot. `callbackAlive` reads an
independent weak capture token held only by that callable. The real neutral
native JavaScript context lease follows the same actual capture lifetime,
including the separate Tablet inline context State. Delivery moves the callable
out of the slot once. Original body return and finally/unwinding timestamps are
separate from the later observed zeroing weak capture expiry. A delegate body
return or an empty slot does not stand in for callback destruction, source
carrier retirement, native view death or UIKit input drainage.

The 30-second deadline is measured from the original native arm monotonic clock
and checked again immediately before capture. A timeout marks the source
incomplete. A captured original remains intact until an explicit once-issued
deliver or discard; timeout never silently drops, moves or replays it. Discard
releases only this fault-owned callable. It does not close a view or claim any
product cleanup. Original bytes and timestamps remain inspectable in bounded
metadata after active buffer retirement.

Native fault commands have an issued-before-action nonce journal and preserve
original issue sequence/time and terminal decision separately. Repeating a
nonce returns the original receipt without executing it again; rewriting it
invalidates completeness. An interrupted/exceptional command can retain an
issued receipt, actual delivery/finally provenance and separate weak state.
Deliver/discard requests also carry the actual recordId from an already acquired
original. Native admission requires that exact currently pending record, so an
old interrupted owner cannot adopt a newly armed callback in the same fixture
slot. The ID is ownership metadata, never a supplied replay body.

Host owners must save their own issued intent before sending and reconcile
against the passive original history; no uncertain command is resent.

The passive source and explicit fault command have separate closed actions and
files. They do not change World Web trace/DOM/getters, the default HTTP closure
serializer, UIKit routing, or ordinary product source grants. Host verification
uses independently authored native DTO fixtures and source checks; it is not a
native execution or device lifecycle qualification.

The native delivered receipt's completed field is its actual decision timestamp.
It can precede the later qScopeGuard observation of original body return/finally;
the reader preserves that exact order. It never retimes those fields into the
receipt interval. Positive callback retirement additionally needs the later
independently observed weak capture expiry.

The mutating transport accepts an explicitly already journaled command and an
original prior source. It never creates a retry nonce. Its 1.5-second budget
starts before original validation and remains active through actual SDK/HTTP
transmission via the existing pure operation transport context. Native process
clock epochs bracket the receipt; their monotonic timer is not relabelled as
this independent producer's timer. Unknown results reconcile by exact command
from the passive original command history, without I/O or resending.
