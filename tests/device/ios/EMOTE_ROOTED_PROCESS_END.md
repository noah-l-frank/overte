# Rooted Emote process end: internal partial owner

`IOSEmoteRootedProcessEnd` owns one exact role/run/binding/seal/frozen archive.
Its process source comes from the existing installed candidate and SDK. The
three neutral functions in `installed_process_runtime.py` preserve the original
Graphics source/stopped/OS guards; Graphics retains its original delegate APIs.
The Emote Stop hook has its own typed authority and uses no Graphics Stop permit.

The actual inactive cleanup phase and fully decoded frozen paired seal remain
mandatory. The pure fence reader reopens real Scope3, key and pointer originals,
requires exactly one new Scope frame and two new key/pointer records, preserves
all old references, operations, quiet prefix and held roots, and rederives the
five acquisitions and original native clocks. A completed Actor end can authorize
only its exact three changed current WAL values for the Primary. All other copied
metadata remains equal to its frozen original; frozen copies are never rewritten.
A boolean, requested dictionary or namespace is no peer authority.

The fence cut retains paired artifact/SDK membership and original signatures
through acquisition, private fence storage and the final transport guard. Only
actual typed new original reads and this owner's exact journal/fence output are
admitted. Unknown carriers and modified old files block before Stop. The fence
must still satisfy its original four-clock 1.5-second freshness span at delivery.
Additional decoding time cannot renew or enlarge that interval.

The cut itself retains the fully decoded paired proof and original retirement
floor, checks its exact seal, and joins both inactive phase originals and held
identities before admitting new local files. The runtime requires that exact
typed cut bound to this process owner, then installs its own original-age guard
through canonical transport delivery. A caller-provided callback is not authority.

The private `stop-issued` state precedes canonical normal Stop. Lost delivery,
ignored termination or an expired final guard never resets it. Further progress
uses only `IOSProcessRetirement(profile='emote', stage=0)` through the existing
SDK's independent OS endpoint. Completion needs the original numeric PID and
bundle absence across three seconds on Node epoch/monotonic and controller
epoch/monotonic. Native UI/image/animation/phase getters are unavailable after
Stop. Completed replay opens the actual fence and OS originals without another
OS query. Partial/lost OS reads retain their durable original responsibility.

An unqualified or partial fence cannot authorize Stop. A planned unknown file
birth is not recreated. A saved fence may finish its private journal only while
its original age still qualifies; stale prepared responsibility remains pending.
If no canonical retirement was entered, the unchanged neutral OS guard can also
refuse recovery; no second Stop is attempted to conceal that uncertainty.

This process owner does not delete an SDK, retire copied metadata or zero held
counters. The separate [internal end integration](EMOTE_ROOTED_END_INTEGRATION.md)
connects typed SDK and metadata owners to terminal finish. Whole Emotes stays
partial, and no configuration or capability changes are made. Native compilation
and devices remain unverified. The retained normal paired corpus without an
inactive phase cannot qualify process end; missing originals are not reconstructed.

WAL tests explicitly model paired/native authorization and establish no complete
paired Stop qualification. A connected normal paired seal -> inactive phase ->
