# Original iOS Graphics calibration coordination

`IOSGraphicsCalibration` retains up to eight private rounds under the existing
source lock. The whole owner must exclude public samples and unrelated input
until a round completes. Each round measures the current native preferences and
actual Graphics/tablet surface before reserving unique ordinary-input calls.
It does not activate a fixture phase, change the public baseline or publish facts.

The primary opens the actual Graphics page when needed, turns off only the
actually enabled effects and retains the original native input barrier. Each
credentialed role then captures its own original off images through its own
observer. The primary waits for both role records before restoring the measured
current settings and original page visibility. Current resolution is preserved,
including when it differs from the run's initial resolution. Original restored
native and UI packets, source cursors and exact call intents remain in history.
The controller returns while waiting; it never sleeps with the source lock held.

Ordinary input is owned by the existing durable preference controller. A lost
return reconstructs that same issued call and reads its actual result without
resending a toggle. A committed private image whose return was lost is adopted
through its immutable role/frame reference and original off-input barrier.
A genuinely unknown capture stays unresolved. It cannot become a second
capture, successful calibration or public observation. Actual phase crossing
rejects further calibration; whole-run cancellation must restore preferences
and retire the original capture under that later phase.

Old-process rounds remain unchanged. A new-process round requires the strict
existing scene restart handoff, matching full old/new candidate bindings,
original source births and sequence/epoch ordering. A legacy/foreign PID cannot
be accepted by changing the outer stage. All original frame and native times
remain untouched. The canonical Graphics runtime exposes this component; the
whole feature and worker handshake are still being composed.

Ten no-build regressions cover closed/open original UI, preserved current
resolution, independent role originals, the both-role barrier, lost image/input
returns, unknown capture responsibility, phase crossing, foreign role evidence,
altered original settings, persistence-before-input and proven process
replacement. Host files, HTTP resources and normal input transports are real;
all iOS/native/GPU/OS boundaries and rasterized pixels are synthetic. Compilation
and device qualification remain unexecuted. No full Graphics capability is added.
