## Original acquisition and ownership

`AssetsSceneSources` uses the existing private candidate/session transport and
an already bound native clock. A one-attempt acquisition records the exact
query before dispatch and the raw reply before parsing: native barrier,
Create before, domain, parser origin, Create after, native completion. Its
logical and raw originals use separate, role-specific schemas/namespaces and
retain actual bytes, file identities, pending prefixes and interrupted attempts.
The existing 1.5-second clock bracket, 250 ms clock agreement, bounded bodies
and source/history/complete-tree checks remain unchanged. Native epochs are
never compared across independent process clock domains or copied into host
timestamps.

`OwnedAssetsPeer` resolves lineage from the actual `OwnedAssetsParsedInput`
parent. The actual UUID, creation epoch, creator, name, model URL and position
must still match in each complete original inventory. The two processes,
candidate fingerprints, source instances, sessions, parser histories and
reader identities must be independent; actual domain and mixer identity must
agree. Each original consumed parser body must match the independently read
qualified baked blob. `loaded` and `addedToScene` alone prove none of this and
remain insufficient to claim rendered pixels.

The peer WAL binds the independently authorized primary target directory and
its current device/inode identity. Historical inspection never follows a path
merely because the WAL contains it. The caller must supply that authorized
directory; the inspector reopens the complete actual parent chain, original
raw/logical memberships and kernel identities with no SDK/input/query/write.
Unknown owners, orphan frames and unfinished source writes fail closed. Even
an actor Scene reservation without a peer result retains a conservative peer
resource responsibility. A successful peer observation always retains peer
parser/cache/resource retirement responsibility.

The owner issues no normal input, creates no entity, triggers no parser, and
does not repair product state. Before acquiring either child, the parent WAL
records its expected logical source index. Thus both a lost saved parent/cohort
adoption and a completed child whose return was lost before parent adoption
resolve from that exact retained original without repeating its acquisition.
Unqualified cohorts remain retained and may be explicitly frozen; a later
source identity reversal must still satisfy the original domain-history
validators and is not a recovery mechanism.
