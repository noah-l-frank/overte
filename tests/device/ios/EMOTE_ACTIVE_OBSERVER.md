# Active Emote observer boundary

Feature 5/14 remains partial until the complete actor, paired retirement,
configuration and runtime dispatch are integrated. Native code is uncompiled.

The active host tests execute the actual pinned Phone Emote script in a
persistent Node VM. Normal token-based chooser inputs invoke its real handlers;
the script selects actual URLs, range/rate and random Sit variants, schedules
its own completion timer and invokes its own override/restore callbacks.
Explicitly modeled native producers expose those callbacks and evaluated
poses as original Script/Rig observations. These are host source tests, not
device, Qt, AvatarMixer or Vulkan execution claims.

The real Sources, Actions, Samples, Observer and historical decoder run over
that boundary. The fixture uses a real authenticated loopback challenge server,
untouched PNG files, complete marker geometry, original image bytes and actual
private GPU-owner journals. Every current observation acquires new originals.
The positive cases cover all ten ordinary names, all three actually selected
Sit variants, early cancellation, natural completion, close/reopen and repeated
idle observations. Failed resources remain observed idle. Lost input returns
retain the issued intent and never replay the actual script callback. Frozen
played pixels cannot establish restoration even when the current Rig is idle.

Restoration image and peer comparisons retain an actual active observation
from the same measured episode. Later quiet, close or reopen reads compare
their freshly acquired restored pixels to this original playback; they do not
require an already restored body to move again. Current inactive source,
original restoration event and full native history remain mandatory.

Observer owner metadata now writes version 2 and reads versions 1 and 2.
Version 2 stores compact `iosEmoteSampleReferenceVersion=1` references containing
the exact original request ID and SHA-256. References resolve only through the
actual admitted Sample row and immutable Sample file. The original Sample and
observation record/reference DTOs remain unchanged. This avoids nesting the
same large GPU transcript repeatedly in the bounded private observer journal;
the existing size limits remain enforced. Reading version 1 converts only its
in-memory owner references; a later metadata save writes version 2 without
rewriting original records, PNG bytes or native histories. Foreign requests,
changed hashes and unknown or boolean versions fail closed.
