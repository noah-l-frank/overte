# Independent paired postlogout originals

`IOSAvatarFinal` samples both previously admitted SDKs after ordinary logout.
It requests account-only native state, actual Avatar State3 postlogout model
properties, Tail2 UI/HTTP/timers/Keys2/UIKit geometry, and original Qt pointer
lifetimes. It requests no World, avatar-mixer join or renderer after logout.

Each subject has an actual left pointer cut, account/model read, UI tail and
right pointer cut. The original authority HTTP bracket independently confirms
revoked fixture grants, drained requests and absent controlled tokens. Every
source still has its original process, native clock and stored-query ownership.
The whole acquisition includes source validation and durable storage in its
original 1.5-second deadline; historical reconstruction never renews that clock.

Large subordinate owner snapshots are retained in separate immutable private
component files before the outer original is admitted. Their exact hashes are
journaled before creation. A lost completed return is adopted without any SDK
request. If a component was only planned, only the exact unchanged subordinate
metadata may fill it; changed metadata cannot reconstruct the missing original.
Abandoned outer groups preserve original subordinate prefixes and never resend
their queries. SDK-independent archives refuse capture, recovery and mutation.

The quiet proof requires at least three distinct complete groups. Both genuine
host and native intervals must last three seconds after all relevant actual
endpoints, excluding the boundary acquisitions. Key/IME clock endpoints retain
their actual global key-source instance; no native observation instance is
assigned to another source's monotonic clock. Actual pointer/contact drainage,
unchanged Avatar properties, account histories, callbacks, HTTP events, lifecycle,
UI root absence, keyboard visibility and IME inset are all separately checked.
Keys2 privacy qualification is mandatory through Tail2. Historical Tail1 and
Keys1 originals remain readable elsewhere but cannot establish this proof.

This is a postlogout component. It returns neither a public baseline nor
`resources: []`. The whole Avatar owner must additionally re-derive its original
nine-fact bilateral checkpoint, Scene API-return/tree/weak/file/GPU/full-pixel
retirement, original input ownership, both controlled logout and preference
restorations, and properly ordered Scene and Complete retirement receipts.

Contracts `ios-avatar-final`, `ios-avatar-final-original` and
`ios-avatar-final-proof` write/read version 1. Host tests use real private files,
source owners, prefix validators, original archives and fixture account backend;
native Qt/application boundaries remain explicit modeled producers. Native
compilation and device execution remain unverified.
