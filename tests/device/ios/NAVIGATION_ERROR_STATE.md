# Original missing-place error state across dismissal

`navigation_error_state` supplies two actual fields, `error` and `addressDialog`,
and a separate owned-dialog lifetime condition. It remains a component of the
partial Worlds area. It does not supply arrival, a whole observation publisher,
three-second quiet, restart or final resource retirement.

Before normal OK input, `missing_proof` freezes one genuine original missing
lookup. Its unchanged native dialogs/replies/UI packets must join a bounded
`NativeClockAcquisition`, the installed process/candidate binding, original
input barriers and the original same-ticket provider receipt. It calls the
existing native missing-modal join and original selected OK-control join. An
unknown modal/callback, missing source, foreign process or absent actual control
cannot be adopted. The proof retains original provider and native clocks in
their separate domains; server time is not relabelled as native time.

The frozen proof is `iosNavigationMissingProofVersion: 1`. Reconstruction
revalidates its original complete observations, clock join, admission, provider,
hash and derived modal join. One original owned error is supported for the
canonical journey. Additional unknown callbacks or dialogs retain unresolved
responsibility and cannot hide behind an earlier successful dismissal.

`compose` reads the current original native dialogs/replies/UI packets within a
separate unchanged native clock join, below the existing 1.5-second acquisition
deadline. It requires complete modal inventory and no foreign modal, preserved
source births/counters, immutable callback/dialog histories, unchanged lifecycle
and original input-source continuity. A still-visible owned modal requires the
same actual current lookup generation, original native error and actual current
OK-control source. This projects `error: not-found` independently of any ACK.

After the original normal OK response, hidden/scheduled objects or an accepted
input are insufficient. `error: none` requires actual modal and listener
destruction and the recorded original Qt OK enum response. A still-open original
Go To root remains `addressDialog: true`, even when its input controls were
suppressed by the modal. The ordinary close recipe must handle that separately.
The creator's retained lifetime stays in the original packet and is not erased
or equated with modal/listener drainage.

Later input phases do not change the missing proof's ticket or timestamps. The
original callback and original same-ticket 404 receipt remain historical while
fresh native lifetime reads establish current absence. Requiring a new 404 for
the dismissal ticket would relabel the wrong input. With no owned error proof,
the component requires empty original dialog and callback histories and returns
`ownedDialogDrained: null`; this is not a vacuous owned-resource destruction
verdict. An unknown historical callback prevents that empty-state projection.

Version 1 of the private error-state record retains current original hashes,
missing-proof hash, original native interval and measured host acquisition
start. Historical validation never performs an input, claims new freshness,
changes the fixture phase, erases an error or retires metadata. Cross-sample
durable cursors, installed ownership and original provider history still belong
to the final owner.

Host tests exercise the provider and actual Python joins, including old-ticket
preservation, visible stale lookup generations, changed source/process/candidate,
missing controls, ignored input, hidden/partly deleted objects, wrong responses,
unknown callbacks, actual modeled destruction and still-open Go To roots.
Native Qt/UI/SDK observations and acquisition clocks are modeled. These tests
do not establish native compilation, physical deadlines or device acceptance.
