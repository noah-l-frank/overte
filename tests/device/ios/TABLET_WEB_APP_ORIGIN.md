# Tablet app origin and exact reply call sites

`tablet_web_app_origin.admitted` is a pure original-data join. It reads no SDK,
native source or host file and writes no state. Its version 1 result is
preparation provenance, not an input, browser effect or cleanup receipt.

Admission requires the current version 2 four-file app ownership record, exact
original native file readback, the actual directory returned by that source,
and the unique running Script manager loading its `script.js`. The actual
submitted UTF-16 root-code hash and length must equal the independently
generated original app input. Its three required module URLs must be loaded.
The module ledger does not expose module-code hashes; this join therefore
does not establish the decoded inline document contents. The separate native
Tablet source/carrier reader checks those actual bytes.

An independent same-physical observer may acquire its own original file
readback after ordinary Script load. Manager assignment must still follow the
original setup authority, and the readback must precede that observer's
actual Script snapshot. Root-code identity comes from the actual submitted
UTF-16 bytes and exact native assigned URL, not the order of a disk read.
Exclusive native directory, app nonce, returned controls and all original
timestamps are preserved. Neither pre-load nor post-load file readback proves
which module bytes were executed; only the independent actual native/source
joins can supply such additional evidence.

All three returned `addButton` originals and actual live Qt controls must
belong to that same manager birth, assignment generation, submitted code and
app nonce. Labels, a requested URL, a click acknowledgment, or the existence
of a similarly named running script cannot establish admission. Old version
1 file ownership remains readable by its existing owner, but cannot acquire
this current control-qualified app profile.

`call_locations` derives the complete expected three-frame reply stack from
the independent original root bytes. Locations use one-based UTF-16 columns,
the actual assigned source URL hash and original UTF-16 compiled-source hash
and length. The native emitter's indexed actual V8 frames must match all
three locations through `web_script_emissions.selected`. Matching manager,
root hash or URL alone does not identify the executed reply closure; extra
nested frames and changed call locations are rejected.

Host tests execute the generated ordinary app in Node and inspect its real
V8 stack, then join explicit native Script/button/emission DTO boundaries.
They cover changed file readback, compiled bytes, assignment generation,
caller, nonce, module roots, extra unfinished modules, PID, old assignment,
extra returned buttons and nested same-VM calls. Native iOS Qt/V8 hooks remain
uncompiled and unexecuted. Full Tablet action/observer/retirement integration
remains incomplete.
