# Avatar marker API ownership and entity lifetime

`IOSAvatarMarkerEntities` selects the closed Avatar profile of the committed
`OriginalMarkerEntities` owner. It preserves the original `create_entities`
version 1 DTO and stores Avatar records in separate private files. The runtime
factory binds the actual SDK, role, source lock, native clock and original
entity reader; it introduces no new endpoint or native verdict.

Capture begins before the marker scope baseline. After scope cleanup and its
quiet interval, a later capture joins the actual submitted Avatar marker VM
and code to the original `Entities.addEntity` returned UUID, the real tree
birth, the original delete return and actual weak entity lifetime expiry.
Tree-map absence alone cannot qualify cleanup. An already ended script still
requires its actual return, birth and destruction originals. Historical archive
validation reads immutable private files and never sends an SDK command.

Host coverage runs the ordinary staged marker in Node at explicit synthetic
native/Qt boundaries. A real host weak reference keeps the entity alive after
map removal and prevents closure until released; reused UUIDs and cross-profile
archives are rejected. Native compilation and device behavior remain untested.

This is one cleanup component. Whole Avatar/People cleanup additionally needs
its own UI, protocol, GPU, account and paired actor retirement originals.
