# Original native Lifecycle callback command returns

Feature 14 remains partial and its complete capability stays closed. This
component retains exact native hold/attempt/release returns for later one-send
recovery. It neither delivers another input nor proves a current editor, focus,
keyboard, generation or resource-retirement outcome. Native additions are
uncompiled and all devices remain untested.

The existing iOS pending provider calls its unchanged native owner once. After
that original return, a dedicated E2E-only passive tap records the actual command,
original reply and native receipt-recording time. The shared native pending
owner and its other-platform defaults are unchanged. Ordinary focus/type/read
operations are excluded from this closed journal. Its value-only DTOs retain no
holder, QObject, window or callback lifetime. No query dispatches or releases
the prepared event.

Repeated identical cached native replies do not append another input or change
the original time. Reused nonces with changed bodies, an owner replacement,
clock rollback, missing original or bounded capacity exhaustion make the source
incomplete. The journal never overwrites its earlier prefix to report an empty
history. Before this actual provider installs the tap, the getter is unavailable.

The closed `feature-ios-lifecycle-pending-commands` query accepts only schema,
nonce, action and run. Its own native read bracket remains separate from each
historical native-owner/IME event clock. The probe consumes each nonce once and
saves through the existing compact private atomic writer. Later ordinary owner
reads cannot overwrite the retained mutation return. Missing native support
remains unavailable.

The strict codec validates every original command and native reply through the
existing pending-owner and prepared-event codecs, then enforces immutable
prefixes and original PID/owner/nonce/intent ordering. Delivery lookup requires
the exact full original command and positive actual native return. In particular,
a historical pending hold return keeps its original command, event and clocks
after the native hold deadline; it cannot become evidence that an event is still
pending now. Current field/context, keyboard and stale-dispatch effects still
need their independent original observations.

The canonical existing FeatureObservation factory requires the matching actual
iOS process and native clock. It creates no SDK session or app launch. Seven new
source/runtime cases plus the existing native-owner/runtime selection pass
21 cases in 0.403 seconds. These run actual codecs, HTTP/AFC gates and the full
probe JS in Node; Qt/native/SDK producers are declared models. A modeled factory
clock is chosen before its first source read, with no recorded original retimed.
The legacy complete-probe test now sends its exact unchanged JS over stdin to
avoid the OS per-argument size limit.

The [durable held callback owner](LIFECYCLE_PENDING_OWNER.md) now binds pre-send
intent and immutable receipt files to normal context replacement and the actual
retired-context attempt. This source component alone retires no ownership.
World/Actor/image/restoration and full final cleanup
remain open; source-complete areas remain five of fourteen.
