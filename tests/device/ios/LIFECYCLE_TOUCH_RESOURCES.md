boundaries directly inside that existing function. It records actual receiver

existing 0.3-second delay are unchanged.

Random opaque resource IDs are minted when the actual RSD, receiver, drain,

passive observer. Snapshot reads weak liveness and, for the exact original

completeness. Observer bookkeeping failures remain failed metadata and cannot
skip existing stop, drain or receiver-close cleanup.

The source is explicitly host-loop evidence. Its real original wall/monotonic
clocks do not become native touch or device time. A yielded body resuming is a
boundary only, including exceptional resumption. A settled drain await may
include the existing suppressed cancellation/OSError. Close-return records a

while an earlier exception is propagating; it proves neither the finally body

contextExitReturned remain separate outcomes and cannot be inferred from it.
