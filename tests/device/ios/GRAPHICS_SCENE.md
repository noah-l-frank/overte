# Ordinary iOS Graphics scene and camera ownership

This internal source packet prepares/restores a controlled serverless scene. It
does not advertise a full Graphics capability, publish feature results or replace
the independent original image/actor/lifetime checks. Native code is uncompiled
and all devices remain untested.

`IOSGraphicsScene` retains the full candidate binding, original scene/view/avatar,
actual source/scene-load histories, native camera orbit, actual provider history,
normal-input intents and UI leases in private CAS state. Its ordinary inputs use
the existing iOS Go To editor/IME, tablet and original View-menu source tokens.
Every address/camera action is issued once. Reconstructing an issued action can
read its actual outcome but cannot click/type it again after an uncertain return.

The source admits a supported original serverless address, no owned scene IDs,
closed unowned UI, upright avatar orientation and an ordinary-menu-reproducible
camera orbit/zoom. Native subject version 3 reads actual look-at rotation, boom
length and the product's real reset limits. It retains versions 1/2 for existing
readers; only iOS emits version 3, preserving the version-2 producer elsewhere.
An unsupported custom original zoom/orbit fails before scene/menu input. No
camera, avatar, preferences, scene or entity setter is introduced.

Source inspection confirms that actual `AddressManager::locationChangeRequired`
connects to `MyAvatar::goToFeetLocation`. The iOS queued serverless viewpoint uses
the real decoded `location` query after the import commits. Preparation measures
actual feet-to-camera offset after ordinary entry, then performs a separate owned
normal viewpoint navigation to align the fixture. Original entity UUIDs/geometry,
actual camera/feet pose and a committed native scene request with every retained
request/delivery lease drained determine readiness. Fixture delivery is separate
input provenance and cannot stand in for actual scene or rendered effects.

Restoration normally closes only owned UI, navigates to the original resource and
feet/orientation, restores the original supported camera mode through its real
menu, then independently checks original geometry hashes, avatar scale/pose,
frustum, orbit and boom. Repeated restoration re-observes current state. The
component can retire only its observed restored owner; the outer full feature
still owns its three-second quiet window, images, peer and fixture retirement.

The shared fixture now admits exactly one bounded finite normalized
`location=/x,y,z/qx,qy,qz,qw` query on the owned Graphics scene resource. Actual
native HTTP requests include that query. Other queries/resources retain their
closed rejection behavior. The scene response body and socket status/bytes/hash
history remain unchanged. This is fixture input compatibility, not a product
fix or measured viewpoint result. Provider/host and native epochs are never
ordered against each other; native scene/subject originals independently prove
the actual product boundary.

`GraphicsFixtureReader` attaches read-only to actual existing activation metadata
and immutable provider histories. It reports crossed phases/retirement separately
and neither activates input nor copies actor facts. The iOS restart receipt
validator additionally requires numeric original PID bindings, unchanged candidate/
session/target, actual new native birth/counters, retained original settings and
the original kernel ESRCH observation for the old PID. The restart controller and
remaining full-area coordinator are still in progress.

The no-build scene tests drive actual W3C/HTTP/AFC input framing at a synthetic
Qt/UIKit/native boundary and fetch real test-owned loopback scene responses.
They cover third-person preparation, measured alignment, original world/camera/
zoom restoration, ignored navigation without resend, unreproducible initial zoom,
and a held request callback despite HTTP success. Pure native-camera, fixture
query and restart-proof counterexamples cover missing/stale/foreign originals,
unsupported orbit, corrupted counters, unchanged birth, EPERM/unproven old-PID
exit and changed candidate/session. These host results do not qualify native
compilation, actual UI input, source timing or physical rendering.

This packet passed 70 distinct selected no-build scene/camera/fixture/restart/
world-measurement cases. The six unchanged full iOS Script/Authentication host
journey regressions also passed after the shared fixture query extension.
The five applicable no-build project checks, registry validation and whitespace
check pass. No compiler, app, simulator, device, installation or laboratory ran.
