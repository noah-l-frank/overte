# Normal Worlds form and surface cleanup

The existing ordinary Places flow now provides a private cleanup recipe under
the actual cleanup ticket. It cancels an owned unsaved bookmark form, deletes
only the run's actually present bookmark names at the original fixture address,
and clears the actual owned search text with normal original-token input.
Unknown names, addresses, popups and text are refused. The independently
retained original bookmark baseline must not already contain those run names.
The final original file/source comparison remains a separate whole-run duty.

`NavigationPlacesCleanup` retains the actual phase, before/after complete native
model and control originals, and every exact token intent before transport.
Every recipe guard rechecks the actual cleanup phase and current candidate.
An ignored input or lost/unknown return leaves the owner issued and prevents
another delivery after reconstruction. An acknowledged completed recipe can
be read again without product input. Its delivery result is not measured
restoration, source quiet or native lifetime retirement.

The existing surface journal reads versions 1, 2 and 3. Unchanged ordinary
active paths continue writing 2. Version 3 additionally retains explicitly
tagged private cleanup calls with their actual cleanup phase and separate
open/close surface transitions; it does not fabricate an active open or close
ticket. A foreign root or unresolved surface delivery cannot authorize cleanup.
The current-process path whitelist includes the new process-bound cleanup
journal, preserving initial-process and post-restart namespaces separately.

Host tests use actual ordinary Python input codecs, original tokens, HTTP,
private files and durable journals, with explicitly modeled UIKit/Qt/SDK
boundaries and clocks. They cover owned cancellation/deletion/search clearing,
phase crossing after durable intent, ignored input, foreign content, changed
journals, idempotent completed calls and unchanged legacy active recipes.
No compilation or device execution was performed. Whole-run restoration,
worker/dispatch and paired terminal retirement still gate Feature 1 admission.

`NavigationMissingActions.dismiss_cleanup` additionally delivers the ordinary
owned error OK using the actual cleanup ticket. It writes version 3 only for
this private tagged path; active recipes still write 2, and readers retain
literal versions 1 and 2. The original missing-name proof and actual modal/token
remain mandatory. Cleanup is never represented as a fabricated Act ticket.

The real phase is checked during every owned boundary and immediately before
native transport. Its own nested authority request retains local/candidate/CAS
guards without recursively acquiring the same authority. A changed phase after
durable OK intent prevents delivery. An uncertain delivered OK is never resent;
only a fresh original dialog/listener drainage observation may resolve its
outcome. Four cleanup cases and twelve legacy cases pass on actual private
journals and loopback/native models. This provides no scene restoration or
whole-feature completion by itself.
