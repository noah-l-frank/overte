# Fresh marker Web originals without a World getter

`OriginalMarkerWebReceipts` supports only the closed Avatar and Emote profiles.
`IOSAvatarMarkerWebReceipts` is the Avatar facade. It reads the existing genuine
WebClosure5 source and an independently observed unbound NativeFeature1 clock.
This remains usable after normal logout resets the product's Avatar session.
It executes no input, starts no VM/GPU request and publishes no fact or receipt.

Every clock and Web query is durable before transport. Each actual raw return,
including stale or malformed bytes, has its own OriginalFrameStore planned,
opened and saved file identity. The raw UTF-8 bytes are reversibly hex-encoded
inside the private carrier; native packets and their clocks are not rewritten.
Matching nonce/PID/source validation remains independent of file ownership.
Clock/start references point to the exact original clock raw files, keeping the
metadata small without copying large source packets into a 48 KiB journal.
The receipt's original native bracket is reconstructed from those actual bytes
and the unchanged original host scalars, then fully validated. A carrier hash
alone supplies no native fact.

Incomplete reads are retained as abandoned attempts before a distinct query.
There is no query resend. Actual qualified returned prefixes from completed
opened or saved raw files constrain every later observation. Empty or partial
opened inodes remain owned with exact byte length and hash; same-inode append,
truncation, link replacement and a planned dangling symlink cannot become
original absence. Complete local returns can be adopted without transport.
Historical reconstruction and all source validation read only original files.

The final candidate/CAS check and all local validation/storage remain inside
the original 1.5 second host/native acquisition. A delayed write or changed
candidate refuses the fresh return while retaining the actual original graph.
The owner supplies neither Web callback quiescence nor object destruction on
its own: a higher-level consumer must independently check callback/grant counts,
actual holders, fresh quiet intervals, account and UI state, pixels and OS/SDK
end. No World getter, native-source duplication or test ACK substitutes for
those effects.

Host tests exercise real parsers, native-query ownership, actual private raw
files and inodes, stale/malformed polls, loss/no-resend, empty opened files,
planned dangling links, same-inode mutation and final guards. Native sources
are explicitly modeled. Native/iOS execution and physical timing are untested;
this component does not advertise an Avatar or Emote capability.
