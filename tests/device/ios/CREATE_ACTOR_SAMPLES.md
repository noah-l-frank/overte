# Independent Create actor and durable Vulkan samples

Feature 4/14 remains partial. These owners do not enable the operation triple
or complete resource retirement. Native code is uncompiled and devices untested.

`CreateActorFacts` independently acquires primary UI and a different actual
peer app through two existing typed `CreateSources` owners. It adopts UUIDs
from its own complete source histories and actual creator/selection facts;
primary action journals and normalized primary results are not peer evidence.
Domain/mixer, entity replication, loaded model/texture, actual voxel bytes and
unchanged unowned maps are checked independently. UI does not replicate, so its
fields come from the separately acquired primary UI original.

The actor's immutable source references, own native and host windows and
genuine fixture phases derive each public field. The existing shared
`PhaseWitnessPublisher` owns the one-shot POST. A lost already committed POST
is resolved through the real journal; it is not sent again. Historical decoding
sends no SDK command and cannot acquire a new clock for an old original.

Historical native schema validation is memoized only by the actual immutable
record hash and original predecessor hash. Every use still reads and hashes the
actual file. During one publication under both source locks, previously checked
records may reuse their verified bytes while checking stable device/inode,
size, mode, link count and ctime/mtime. Actual file hashes are checked again
before the validation round exits. Returned frames are copies; mutating one
cannot alter the validated cached original or a later public derivation.

Normal source observation permits an actually pending browse closure while a
picker is open. It still validates original VM code, process, queue and callback
facts. The lifecycle worker defaults to strict quiet admission for cleanup;
an ordinary pending picker cannot become a drained resource.

`CreateSampleOwner` reserves one actual Vulkan request before acquisition. It
retains independent original Create packets around the actual fenced draw,
original PNG/chunks, actual GPU retirement, original native/host clocks and the
qualification inputs/result. Interrupted captures are not repeated. Failed
qualification retains ownership. Historical reconstruction checks the original
PNG and metadata without another native capture. Host artifact removal is a
separate whole-run duty after paired quiet proof.

A changed-image comparison requires another genuine qualified sample from the
same role/candidate and GPU birth, a strictly earlier native sequence, a distinct
actual request/frame ID, and capture time before the current request. A future
sample, reused frame/counter or replacement PNG cannot be used as a baseline.

The integrated host packet passed 23 explicit tests. The actor test drives all
21 journey actions and publishes 22 independently derived observations through
real loopback journal logic. The samples use actual temporary RGBA PNG/chunks
and private files with modeled SDK/GPU sources. Counterexamples include lost
POST/capture, delayed replication, changed candidates/carriers, mutable aliases,
pending pickers, invalid comparison chronology and missing native retirement.
This validates host adapter logic, not real Create device behavior.

The full primary observation composition, export-original integration, marker
recovery, paired quiet cleanup and final dispatch still require integration.
