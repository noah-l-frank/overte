# Assets picker unavailable-file input vertical

This source packet implements a narrow ordinary picker path. Whole Assets
capability remains unavailable: there is no installed-candidate/device result,
shared scenario dispatcher, independent publisher, AssetServer/oven worker
inventory, upload/mapping/hash/bake/import result, or full cleanup qualification.
No native source in this packet has been compiled or exercised on iOS.

The later [ordinary upload successor](ASSETS_NORMAL_UPLOAD.md) reuses picker
preparation while retaining a separate WAL for successful review/upload and
client cleanup. It does not rewrite this negative-path owner's phase or supply
whole Assets/server cleanup qualification.

The dedicated native gate requires `OVERTE_E2E_FEATURE_TESTS`, `Q_OS_IOS`,
`OVERTE_IOS_E2E_TEST_BUILD`, and the actual `--testScript` process. Interface's
existing private dedicated definition covers both its `AssetMappings` source
and `IOSNormalUiInput.cpp`; no library or production definition is expanded.

`IOSAssetControls` identifies actual component roots, model/source/window and
menu identities. The adapter presses ordinary controls, types the owned folder
through the focused field, chooses the actual primary row, and selects through
the real normal input route. Tokens and current sources are revalidated before
the normal pointer/key events. An input WAL stores the exact command before
transport. Unknown delivery is resolved only by original effects; it is never
resent. The real Tablet Navigation Home button closes the owned Assets page.

`PrivateAssetFiles` is separate from Script/Create staging. It creates closed
input bundles under a private exclusive root, keeps a canonical owner manifest
and an original native completion seal of root/parent/input inode identities,
reads actual bytes/hash/inode identities, and refuses aliases, changed files,
foreign owners, equal-byte replacement inodes, unknown entries, and unqualified consumers. Retiring the
selected primary unlinks only that original inode. The original picker
`accept()` then independently rechecks file availability and retains the exact
error `A selected file is no longer available.` The original Cancel handler
must destroy the actual weak picker before staged companion release.

`IOSAssetUiInventory` keeps weak root identity after detachment/destruction.
`IOSAssetUploadWork` observes actual weak `BundleUpload` owners, `AssetUpload`
objects, callback bodies and terminal returns. A hidden dialog, `busy=false`,
an acknowledged cancellation or a callback's return cannot replace weak owner
expiry. These are client holders; they establish nothing about server/oven work.
Release also checks actual pending-bundle/destination state and current file
identities in the native GUI acquisition bracket. Incomplete/lost mutations
retain their private owner. A partial failed release is not retried as a blanket
delete and cannot be called complete without original root absence.

The Python file/picker owners retain original requests and dual native clocks,
bind candidate/process/session/run/ticket/file-owner identities, and use one
twenty-second host budget per outer owner entry. The host clock limits work and
never supplies a native/product capture timestamp. Negative and cleanup sampling
windows retain at least three seconds on both original native clocks and on
independent host acquisition brackets; missing/stalled clocks or gaps fail.
The unavailable-file window retains the real picker/error and checks original
client work history. Cleanup waits for actual weak picker/page death, samples
client quiet, then observes original private companion/root absence.

The host fixture executes original QML JavaScript against real temporary files.
Qt roots/windows/model identity, keyboard/pointer dispatch, native envelopes,
deferred destruction and native clocks are explicit boundary models. Client
consumer holds use real Python weak references. These tests cannot substitute
for compilation, actual Qt/UIKit input/lifetime observations, an installed
candidate, an independent device role or any server/oven result. Compiler-driven
`tests/device/contracts/script_assets/*.py` are outside this packet's validation.

Twelve focused picker/file owner cases and six existing original-QML semantics
cases pass in 25.712 seconds. They exercise real host files and actual QML JS
bodies with explicitly modeled native/Qt boundaries. The final native companion
directory inode recheck was reviewed afterward and remains uncompiled.
