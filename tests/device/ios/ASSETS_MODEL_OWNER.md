# Assets model baseline, original sources and actual UUID ownership

The closed Model owner records a native world baseline before ordinary model
acceptance, then adopts the actual new UUID from independent whole-tree
originals. The adapter never supplies a desired UUID or derives success from
the dialog's input ACK/entity-return text. Existing matching models, zero/two
additions, wrong owner/domain/URL/position/creation time and stale source
brackets are rejected. The normal URL/default shape/dynamic/position input
remains owned by the existing Usage journal.

`AssetsModelSources` reuses unchanged native Create state/work and independent
native clock routes. All getter queries are durable before dispatch. Every
received nonempty raw carrier is saved before native parsing under a closed
`assets-model-native` profile; logical `assets-model-source` frames retain exact
raw references, the actual durable normal-UI frame and original host/native
clock join. Missing/partial sources never become an empty tree or finished
lifetime inventory. Native Create versions/defaults remain literal; no new
native getter or product behavior is included in this packet.

Saved raw/logical originals survive lost parent adoption without repeating a
getter or normal input. Opened prefixes remain exact owned bytes, not completed
sources. A failed readonly acquisition may be retained as an interrupted
attempt, followed by a new query/bracket; the old partial attempt is never
reconstructed or retimed. The journal bounds completed frames to 32, interrupted
attempts to 8 and raw receipts/queries per attempt to 24. Existing native body,
immutable-frame and packed-parent limits remain unchanged.

Actual baseline/after sources preserve their native clocks and PID/domain/
session/tree identities. Their entity difference must be exactly one Model,
created within the original normal-acceptance window, with the actual local
owner, unique owned ATP URL and original accepted position. Reconstruction
reopens original files and issues no clock/getter/input command.

## Scope of geometry observation

The later `geometry-observed` state records only the actual wrapper's loaded,
added-to-scene and failure flags from existing native originals. It is an
`assetModelGeometryObservationVersion`, not a resource-consumption or rendered
effect verdict. Current Create sources do not expose the actual Model URL,
render-watcher/resource origin, geometry parser bodies or complete cached
texture/resource weak lifetimes. A separate Assets origin/consumer source,
actual pixel/peer evidence and complete retirement are still required.

The private runtime factory constructs the collector/owner on the current
candidate/session without observing or mutating the app. Pure historical
inspection checks exact logical/raw membership and retains pending source
responsibility. Any issued normal acceptance continues to block as
`usage-model-retirement` and `model-resource-origin`; loaded flags never clear
either responsibility. Full Assets capability remains closed and source
completion remains 5/14.
