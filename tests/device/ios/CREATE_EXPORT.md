# Actual Create export and private original ownership

Feature 4/14 remains partial. This packet supplies output evidence and host file
ownership; it does not enable Create's operation triple or prove paired cleanup.
Native sources are uncompiled and real devices remain untested.

`create_export.exported` compares two actual native file observations: output
absence before ordinary Save, and the product-written `export.json` afterward.
The independently staged entity-import input must retain exactly its original
bytes and native stat identity. The output must have a different inode and must
contain the actual selected, owned, loaded Model's source, dimensions, name,
type and renderer-consumed texture assignment. The export's DataVersion is 0;
the staged import's DataVersion is 3. The adapter never generates or repairs
exported bytes.

`CreateExportArtifact` makes one exclusive, mode-0600 private host copy of those
actual output bytes. It records the copy intent, original file/native scene
carriers and exact source measurement before opening; the actual opened inode
is durable before writing. Reconstruction validates the source measurements and
retains interrupted responsibility without repeating the copy.

Removal requires the enclosing complete owner to establish paired native,
callback, GPU and file quiet. The component checks its own exact inode, byte
prefix/hash, mode, owner and link count, then records removal intent and checks
again immediately before unlink. An uncertain unlink can only resolve through
actual absence; it never causes a second unlink. Replacement files and unknown
inodes remain untouched and unresolved. Original metadata remains retained.

Eight host tests use real temporary product output, native stat originals and
actual host files. They cover content/property mismatch, reused input/output,
foreign ownership, changed bytes/inode, hard links, failed creation, lost removal
journaling and replacement during removal-intent storage. They validate adapter
logic with modeled SDK sources, not real product export or device behavior.
