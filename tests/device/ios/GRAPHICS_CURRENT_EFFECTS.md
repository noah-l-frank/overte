# Current enabled iOS Graphics effect pixels

`graphics_current_effects.py` supplies a version-1 observational comparison for a
current enabled haze/reflection frame against a recent original off frame. It
is separate from the existing explicit-enable-phase comparison; that contract
and its different-phase requirements remain unchanged. This component supplies
no inputs, calibration, public feature state or complete capability.

The original off and current PNGs retain their exact native metadata, hashes,
clock joins, settings, UI sources, GPU frame identities and fence retirements.
Both are validated through the existing world-image composer. Current data must
remain fresh through final processing. The off reference retains its original
time and the existing 45-second bound. A missing/expired reference cannot be
retimed into a new observation.

A normal temporary off/on calibration can produce both originals under the
same actual fixture phase. The new comparison does not require an invented
phase activation or substitute another ticket into the original marker URL.
Current frames may instead belong to resolution, background, restart or
restoration phases. Their actual resolution and other effect may differ, but
unrelated graphics preferences remain equal. Both complete original entity
inventories must independently match the same controlled scene. Geometry,
avatar/camera and recorded projection remain equivalent; effect target boxes
must not overlap. Measurements exclude the complete marker card.

Within one process, source births/cursors and authoritative native histories
advance, launch count stays unchanged, and actual background/activation counts
may advance. Across a process replacement, the exact old/new candidate/session/
target bindings and strict existing restart receipt are mandatory. Original
old-PID `ESRCH`, native lifecycle increments and changed native/UI/GPU source
births must match the actual before/current frames. New entity edit timestamps
stay unchanged in their original packets; only the geometry projection is
compared across proven process replacement.

Current native settings and issued draws must actually report enabled, but they
cannot prove success by themselves. The original target pixels still require
at least five percent change and the existing haze blue-dominance/reflection
orange-fraction delta thresholds. An independently working other effect cannot
fill the target's missing pixels. A valid current frame without those pixels
raises the existing qualified pixel-readiness error; malformed sources or
provenance fail before that classification.

Nineteen selected no-build cases pass across this component and the unchanged
explicit-enable comparator. They cover originally enabled settings, same-phase
calibration originals, resolution/other-effect changes, selectively ignored
shaders with real other-effect pixels, changed background counters, stale
references/current frames, late processing, lost guards, false same-PID launch
increments, foreign candidates, changed image bytes, strict process replacement
and original edit-time preservation. Actual normal iOS input framing, private
files and loopback resources are used. All native/GPU/OS/kernel boundaries and
pixels are synthetic. Native compilation and devices remain unverified.

The version-2 observer uses this comparator for all current enabled states,
including baseline, non-enable phases, restart and restoration. Its private
`seed_off` retains separate role originals without changing the fixture phase.
Whole-owner ordinary-input calibration, actor coordination and finalization
remain pending. This helper is not a completed
Graphics adapter.

## Current disabled-state comparison

The separate version-1 `compare_disabled` contract uses the same complete
original provenance, process replacement, geometry, PNG and clock checks. The
current native setting and issued pass must both be false. Current haze blue
dominance cannot exceed the original off reference by more than 10; reflection
orange fraction cannot exceed it by more than 0.005. These are the complementary
existing effect thresholds. Ordinary pixel changes due to resolution or the
other effect are allowed; the two target regions remain disjoint and the whole
challenge card remains excluded. No expected color or requested flag is returned
as a measurement. Disabled comparisons do not claim that enabling worked; the
unchanged full journey must independently qualify both actual enabled effects.

Observer v3 requires these original comparisons in every current false state.
A role must first acquire its own private off references through `seed_off`.
These seed images create no public sample or sequence. Only a later newly
acquired frame can be qualified. An existing off reference is replaced after
successful current-pixel qualification; delayed enable input still cannot replace
it with an early false image from that enable phase. Version-1/2 observer archives
stay readable without fabricating disabled proofs for historical samples. Every
new v3 sample must retain its actual false-state proofs. Reference age remains
bounded by the original 45-second limit; missing or expired evidence fails before
capture instead of being retimed.

The combined disabled/current/observer/calibration selection passes 57 no-build
cases. Eight new cases include stale effect pixels despite false actual settings
and zero effect draws, restoration failure, separate private role references,
resolution/other-effect changes, expired/reused evidence and strict process
replacement. All iOS/native/GPU/OS boundaries and pixels remain synthetic.
Compilation and devices remain unverified; full owner/worker/finalization work
continues without advertising a complete Graphics capability.
