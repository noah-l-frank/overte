## Actual original receipt

The original `PhaseWitnessPublisher.receipt` was called on the fourth published
Actor record from the retained 3000-second graph. This is the second completed
terminal live cut, not the third cut interrupted by timeout. Both actual source
locks were held, the persisted envelope/reference hash was checked, and complete
immutable graph inventories surrounded the traversal. SDK, HTTP, candidate and
native factories were forbidden. The publisher's own original validator and all
original readers executed; instrumentation only counted calls and measured CPU.

The retained graph is `.ios-host-tmp/avatar-full-held-terminal-3000-rkawp7wt`.
The scripts, baseline, exact ordered read trace, profiles and logs are retained
in `.ios-host-tmp/avatar-original-witness-profile-4eiea5_s`.

The baseline took **80.654622 seconds** under `cProfile`. It opened/read 13,922
original frames and 5,493 private metadata envelopes, with 67,776 actual file
opens and 908 collected original files. Its immutable inventory was unchanged.
Repeated Source frame validation took 9.032 cumulative seconds across 478 calls.
The complete receipt also repeats Final groups, Account/source history and
native animation checks; these overlapping profile categories are not additive.

A first literal-validator wrapper, without extending the existing Final scope,
took 80.612736 seconds with zero whole-frame hits. It was removed. Its profile
and exact-output/read parity evidence remain private; no gain was claimed.

One comparison against the same original receipt returned in **73.056447
seconds**, an observed **9.42%** whole-receipt reduction. This is one profiled
host comparison, not a device timing guarantee. All 478 public frame validation
calls remained; the literal body executed 262 times, giving 216 scoped pure
success hits. Its cumulative time was 4.906 seconds.

The returned original receipt and proof hash matched exactly:
`46365aee5c437b9c94270a13d7c364c884e95cbf8b4175c05cbf4261c7701d3d`.
All **13,922 frame reads, 5,493 metadata reads, 67,776 ordered file opens and 908
membership files** matched the baseline exactly. Complete before/after original
inventories were unchanged. Native/SDK/HTTP requests were zero. Both runs exited
normally within the same external 180-second host bound; production deadlines
and original timestamps were unchanged.

Focused qualification covers original inventory/owner/event/callback mutation,
foreign profiles, lost locks, PID/run/previous-frame distinctions, nested input
mutation, default validation and scope exit. Native producer boundaries in the
host fixtures remain explicit models; native sources remain uncompiled.
