# Passive Avatar UI retirement after logout

`IOSAvatarPostLogoutTail` captures original installed Avatar/Pal worker timers,
actual social HTTP lifetimes, People timers and the complete observed Qt-root
inventory after the controlled account has genuinely logged out. Account
causality is checked before any channel query and again from both native
bracket originals. The sampler requests no World or renderer and does not
require a nonnull Avatar session after NodeList reset.

Writer 2 introduced the original global Qt key/IME lifetime source
in separate immutable raw carriers and the original UIKit geometry receipt.
The current global key source must be privacy-qualified version 2: it retains
opaque press-lifetime IDs and IME activity, without characters, commit strings
or physical key codes. A stale legacy AFC response is rejected before any host
raw file is planned. The issued query and original clock start remain owned;
recovery never resends that nonce or sanitizes old bytes into a newer DTO.
Actual key release/finally and empty IME activity do not prove editor closure:
the proof also requires observed Avatar roots to be absent, the tablet closed,
and actual UIKit keyboard visibility and IME bottom inset to be clear. The
whole final owner must measure at least three seconds of both native and host
quiet after the actual endpoints. A Tail proof alone supplies no quiet period.

Writer 3 additionally retains the unchanged global UIKitInput2 source. Its
complete installed dispatcher, ended contacts and returned/finally callbacks
must be idle. Cached native views, touch objects and UIEvents may remain alive:
this is global dispatch quiescence, never weak-object death or proof that a
particular input reached its intended control. The final quiet consumer also
requires an unchanged dispatch sequence and at least three seconds on this
source's own native epoch and monotonic clocks, excluding acquisitions.

Actual raw sources, staged native records and completed acquisition partials
use bounded `AvatarTailSegments` carriers. Every segment has real
planned/opened/saved ownership, original bytes and inode identity. A raw UIKit
source near its unchanged 2 MiB limit spans four actual files below the
unchanged 1 MiB original-file bound. The packed journal contains references;
it does not nest the full growing source and native-query histories. A lost
opened-file return is retained with its actual partial length/hash, including
zero bytes, before abandonment. Appending or truncating those bytes later
invalidates historical reconstruction. Complete opened bytes can be adopted
without fabricating a saved acknowledgement or repeating a source query.

Large key histories use `OriginalKeyPackets` and the existing original-file
bound. Neither metadata nor unrelated source limits are increased. Every raw
carrier index is continuous across completed and abandoned reads, and capacity
is checked before the next native query. Completed metadata stores the actual
immutable original reference without duplicating that original's full bytes.

Every passive source, widget and native-clock query is durably owned before
transport. Unknown queries stay abandoned and cannot be resent. Returned raw
packets remain retained before interpretation. A later distinct read must
extend every actual native and channel prefix. Completed private originals
are adopted without transport after a lost local write return. Historical
reconstruction reads immutable private files and rejects mutation.

The proof requires original installed-code hashes, destruction and completed
native dispatch of newly owned timers, zero current dispatch depth on relevant
pre-existing timers, drained People and HTTP lifetimes, and actual hidden or
detached observed Qt-root absence. A periodic timer already present before the
run may remain alive with no pending dispatch. Roots never observed by the
passive inventory are not inferred to have existed or died; the whole owner
must separately retain positive UI admissions and actual input ownership.

Fresh return includes private-file and metadata writes within the original
1.5-second acquisition. Slow storage cannot retime a saved original. Raw
unrestored packets remain readable and fail their old proof even after a later
read qualifies. This component alone does not prove paired cleanup, model
restoration, rendered pixels or final resource retirement.

Contracts `ios-avatar-postlogout-tail`, `ios-avatar-postlogout-tail-original`
and `ios-avatar-postlogout-tail-proof` write 3 and read 1, 2 and 3. Tail1 retains
its exact three-channel grammar and original bytes; its proof makes no key,
keyboard or IME claim. An independent frozen three-channel producer verifies
legacy reading; a separate literal frozen writer2 verifies later Tail3
continuation without rewriting either old original. Tail2 supplies its exact
original key/geometry proof and makes no UIKit dispatcher claim. The new whole
Avatar final decoder explicitly requires Tail3.
Host tests exercise actual runtime composition, native and Qt
transport admission, historical no-transport validation, lost returns, hidden
roots and slow final storage. Native compilation and device execution remain
unverified.
