# Passive Avatar UI retirement after logout

`IOSAvatarPostLogoutTail` captures original installed Avatar/Pal worker timers,
actual social HTTP lifetimes, People timers and the complete observed Qt-root
inventory after the controlled account has genuinely logged out. Account
causality is checked before any channel query and again from both native
bracket originals. The sampler requests no World or renderer and does not
require a nonnull Avatar session after NodeList reset.

Every passive source, widget and native-clock query is durably owned before
transport. Unknown queries stay abandoned and cannot be resent. Returned raw
packets remain retained before interpretation. A later distinct read must
extend every actual native and channel prefix. Completed private originals
are adopted without transport after a lost local write return. Historical
reconstruction reads immutable private files and rejects mutation.

The proof requires original installed-code hashes, destruction and completed
native dispatch of newly owned timers, zero current dispatch depth on relevant
pre-existing timers, drained People and HTTP lifetimes, and actual hidden or
detached observed Qt-root absence. A periodic timer already present before the
run may remain alive with no pending dispatch. Roots never observed by the
passive inventory are not inferred to have existed or died; the whole owner
must separately retain positive UI admissions and actual input ownership.

Fresh return includes private-file and metadata writes within the original
1.5-second acquisition. Slow storage cannot retime a saved original. Raw
unrestored packets remain readable and fail their old proof even after a later
read qualifies. This component alone does not prove paired cleanup, model
restoration, rendered pixels or final resource retirement.

Contracts `ios-avatar-postlogout-tail`, `ios-avatar-postlogout-tail-original`
and `ios-avatar-postlogout-tail-proof` write/read 1. Native DTO versions are
unchanged. Host tests exercise actual runtime composition, native and Qt
transport admission, historical no-transport validation, lost returns, hidden
roots and slow final storage. Native compilation and device execution remain
unverified.
