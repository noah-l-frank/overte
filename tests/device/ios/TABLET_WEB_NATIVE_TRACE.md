# Original native Tablet browser transcript

This prerequisite records actual native WK document, response, bridge, signal
and callback events for the Tablet surface. It is not the complete feature 7
adapter. Native C++/Objective-C++ remains uncompiled and unexecuted here.

`IOSBrowserTrace.h` dispatches actual instrumentation by surface. World events
retain their original World producer, identity getter, DTO, instance and
history. The historical World branch delegates to that original getter even
after `scheduleOpen()` closes the policy and clears the live generation. An
independently refreshed World getter must never be replaced by an older generic
cache. A source-only regression evaluates this branch from the actual native
file; it does not execute Qt/WK code.

The separate Tablet source is `ios-tablet-web` version 1, with action
`feature-ios-tablet-web`, file `feature-ios-tablet-web.json`, at most 4096
cumulative events and 2 MiB of original compact JSON. Every actual opened
Tablet policy grant retains one original `tablet_sources::view()` association:
actual visual root, normal navigation input, fixture root, and optional native
inline carrier/binding birth. Later QML assignments cannot change this stamp.
The identity reads the actual policy source identity and URL. Inline policy URL
is its genuine synthetic token transport URL; original decoded HTML bytes stay
in the separate `ios-tablet-sources` source.

The Python reader preserves the native DTO, source birth, actual process,
independent clock domain, event IDs, ordered immutable prefix and callback
arguments/returns. `join_sources()` independently validates original Tablet
source packets, matching each grant to the actual native input and inline
carrier/binding, exact transport URL, original byte hashes and invocation
return. Cross-source monotonic origins are never treated as the same clock.
Owner death alone does not drain an outstanding callback.

Tablet Qt key-enter text/codes are not recorded by this transcript. Normal
UIKit input needs its own trusted DOM/input and native view provenance. No
World pointer/DOM receipt is relabeled as Tablet input. A native response event,
completed callback or normal input invocation alone does not prove page pixels,
DOM text, bridge effects or successful feature cleanup.

Host checks exercise closed DTOs and actual shared Node, fixture and AFC paths
using modeled native originals. Native UIKit view/window/document geometry,
passive trusted DOM, held inline callback, original WDA PNG joins, ordinary
controls and complete repeated retirement still belong to the feature owner.
