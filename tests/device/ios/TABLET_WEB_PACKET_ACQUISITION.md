# Tablet original packet acquisition

`TabletWebPackets` owns queries for the existing Tablet source, trace, DOM,
button, current-state, closure, UIKit, emission and held-callback readers. It changes neither their
native grammar nor their actual query protocol. Each role/component has its own
process-bound private journal and immutable original files. The public capture
returns only the existing reader's independently validated native result.

The query intent is saved before the actual send. A standalone closed native
grammar and current privacy policy qualify matching bytes for private storage.
Their exact original UTF-8 bytes are then stored before semantic process,
query and historical-prefix interpretation. A matching wrong-PID, reset source
birth or rewritten same-query terminal reply remains immutable rejected failure
evidence. It never becomes a valid source floor/result and permanently blocks
new live captures for that owner. Unknown/private grammar is retained only as
an actual byte length and SHA in the failed journal; its plaintext never becomes
a new host artifact. These digest cues qualify no native fact.
Pending DOM replies
remain in the original history even after interruption or abandonment. Actual
source births, counters, immutable prefixes and accepted pending clocks must
remain continuous on reconstruction. A prior unowned reader result cannot be
adopted. Current UIKit2 privacy grammar is required before any raw host file.

Writes retain the existing 1 MiB frame bound using the closed Tablet segment
profile. Actual partial file prefixes are frozen independently. A changed
prefix, hardlink, replaced inode, changed query digest or reset allocation index
fails closed. A complete opened record after a lost flush return is recovered
by reading its actual bytes; recovery repeats neither the write nor a native
query. Failed or unknown query attempts require explicit ownership archival
before another capture. Archival is not native callback/resource retirement.

Temporary reader send/read hooks are restored in `finally`. The existing final
transport guard also checks the original acquisition budget after a slow issued
journal write. Host epoch or monotonic regression blocks a new capture.
`historical=True` validates actual existing files only: capture, initialization,
archive, record recovery and ownership writes are prohibited. It establishes no
fresh source, input delivery, page effect or cleanup verdict.

`tablet_web_documents.current_document` separately joins actual native document
begin, installed passive observer, first finish and verification with the DOM
view/nonce/source and original server response ID. Duplicate finish/verification
callbacks count once. A later actual close, recreation or navigation invalidates
an old ready DOM snapshot. HTTP URL, original resource listener, status and
opaque response ID must agree. Inline completion instead requires its actual
live source root/carrier/binding and decoded input bytes; it has no manufactured
HTTP receipt. Current native state, inputs, Script ownership and pixels remain
separate required joins.

The source packet owner is bounded to 128 captures per component and the
existing 1,024 raw-frame indices. It never deletes its originals. Whole-feature
finalization must retain and later retire the actual files and any native
callback responsibility under the separately verified paired protocol.

Host tests use real private files and the actual passive JavaScript observer.
The actual fixture response generator supplies 404, recovered 200 and foreign
HTML response metadata. Lost send/flush returns, pending-source resets, partial
mutation, rejected raw retention, privacy-before-artifact, stale DOM snapshots
and forbidden historical writes are covered.
Native producers remain uncompiled and unexecuted; this packet alone does not
complete Feature 7.


The `emissions` component additionally retains the genuine shared
`IOSWebScriptEmissions` source unchanged, including actual VM/root code,
indexed V8 compiled-source stack, API/queued-capture/sink IDs and weak expiry.
It uses its own query/raw/record namespace and the already closed concrete
Tablet segment label. No World or Tablet identity/schema is relabelled. A safe
matching later source-birth reset is retained as rejected immutable failure
evidence and blocks the live owner; it cannot silently establish a new floor.

The ninth `deferred` component retains the original Tablet-only held-callback
DTO and its actual query/clock/PID, original callback body and command receipts.
It uses the existing closed `deferred` Tablet segment label without changing
other profiles, native sources, packet versions or size bounds. A callback
still held by that source remains owned; storing or replaying its readback
does not deliver/discard it or prove its destruction. Historical file reads
use the same original-read membership hooks as the other components.


Packet owner/record writer 2 reads literal versions 1 and 2. Its explicit
`reconcile(reader)` performs only an AFC read of the already issued nonce;
it never calls `send` or `read`. The original failed status, endpoint, send
return and absent result digest stay unchanged. Separately journalled readback
spans retain the actual later raw acquisition clocks. Matching privacy-safe
bytes are stored before PID/source/prefix interpretation. Rejected raw stays
owned; private or unknown grammar has only a digest cue. A complete raw file
surviving lost flush return is reread from its unchanged inode without another
AFC read. A partial raw remains blocking. An issued interrupted readback may
only retain responsibility; it does not acquire a fresh observation deadline.
These accepted old originals contribute continuity floors, never current facts.
