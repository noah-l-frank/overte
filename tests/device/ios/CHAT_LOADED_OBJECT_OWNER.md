# Chat normal owner with original loaded-object identity

Feature 10 remains partial. The explicit source integration is host-verified.
Its native hooks and C++ bridge are uncompiled. It enables no complete Chat
capability, independent peer receipt, process end, SDK end or native retirement.

The existing normal Draft runtime accepts the explicit `source_bound=True,
qml_bound=True` primary profile. New owners use Draft/observation version 8.
The default remains literal version 3, and existing explicit versions 4–7 keep
their grammar. Version 8 cannot join the peer/Receive profiles or adopt their
old journals. Existing journals are never migrated.

The existing Chat View action, result filename, authenticated transport and
nonce-before-native-invocation handling remain in use. Request version 2 with
the sole fixed profile `loaded-qml-object` requires View version 4. Request
version 1 continues to require its literal versions 1–3. No caller supplies a
desired URL, object ID, source digest or success result. The new cut contains
the complete current Chat Root census plus two original weak reads of each
same actual QObject through its existing LoadedQML observer. Owner-thread,
zeroing weak object/context, immutable loader identity and unchanged census
guards apply. No pointer string or URL/hash comparison establishes identity.

Each ordinary owner capture saves the original Script roots/code, normal UI,
View-4 cut and, for one actual current page, the existing QML-source version-3
original with both Qt API-entry images. The Draft WAL records each passive
query intent before transport. Original load/cache/compiler/evaluation clocks
stay unchanged; current reads and the identity-cut tail must lie within the
actual native acquisition/UI brackets. Earlier root/load identity associations
are checked again when a cached root reappears. Root weak expiry and absence
of current pages remain separate facts.

The existing QML getter requires one unambiguous live loaded object. This
bounded profile therefore refuses multiple current pages and unavailable or
ambiguous original loaded sources. Only a complete empty current Root census
admits `qmlSources:null` with no image bindings; a failed getter cannot supply
absence. Opening a previously absent page can create a retained pending normal
operation before a later source read refuses. Such refusal does not complete
the operation or authorize replay of consumed input.

Both API-entry originals are joined to the existing current Installed Code
binding during capture. Pure archive validation parses the saved typed binding
and rereads actual bytes of the independently selected candidate IPA. It
rederives member hash, Mach-O header/UUID and both executable file ranges.
Saved `imageBytesBound` booleans never replace that read. Historical parsing
cannot call a current process, transport, native getter or binding writer. The
selected IPA must remain independently available; its path is not selected
from the WAL or native observation. Existing frame inode/body/membership and
private-file guards remain intact.

The known root compiler-input pin is compared after the same-object join.
Imported/AOT/native-type/dynamic code, installed Qt SDK source, current root
evaluation and dependency-membership authority remain unavailable. This is a
bounded observed root/code association, not a complete QML code closure. The
existing 20-second owner operation, 1.5-second native acquisition, source
transport, frame and 64-KiB private-WAL limits are unchanged. Full-journey performance and normal-flow qualification remain unmeasured.

The selected host cases use real private frames, locks, independently read IPA
bytes, actual host zeroing weak references and the production Chat JavaScript
in Node. Native Qt/loader/UI/SDK responses and source clocks are declared
producer models. The existing runtime-factory case also models SDK discovery;
it executes the actual factory/owner/query WAL, not an installed application.
No native, device or whole-area result follows from these host cases.


All 31 selected host cases pass: six identity/protocol cases in 0.005 seconds,
eleven connected normal-owner cases in 16.405 seconds and eleven literal
legacy/local factory cases in 7.659 seconds. Separate paired source profiles
5, 6 and 7 pass their existing production-Script send/receive/archive flows in
3.848, 14.005, 171.056 seconds respectively.

The cases retain 305 actual original files across 53 roots. All 17 original
Node children exit successfully through their unchanged fixture close path
with stdin/stdout/stderr closed. Broad source/launcher/reference pins remain
unchanged in each run (7,825 pins), including both registries and native/QML
sources. Owned processes and new threads are absent before and after both
final original censuses. Historical bytes/inodes, independently selected IPA
bytes and original operation deadlines remain authoritative; producer clocks
and Qt/native/SDK responses remain declared host models.
