# Original Lifecycle editor and loader identities

This prerequisite binds the exact reviewed Create initial-text field, Chat draft
and Scripts filter from the [shared contract](../feature_journeys/LIFECYCLE_INPUT_SOURCE.md).
The Lifecycle area remains partial. Native C++ is uncompiled and no device result
is claimed.

The dedicated iOS E2E normal-UI census observes actual QQmlContext URLs and QML
object IDs, field/root/window/context weak identities, the actual TabletPageLoader
and its original load generation. It visits hidden roots independently of input
eligibility. Capacity or incomplete census remains unavailable. Dead objects keep
their first observed expiry and cannot acquire another identity through address
reuse. Object birth denotes first observation, not a construction timestamp.

The Python decoder preserves immutable identity prefixes, positive deaths,
original clocks, PID and source instance. It joins an attached current field to
its actual loader root/window/generation. An asynchronous loader may acquire its
new root once after its observed source/generation advance; it cannot replace a
live non-null root again in the same generation. Retained old contexts can remain
alive and detached without becoming the replacement's current field.

Generation qualification additionally requires a retained earlier loader barrier,
actual loader advancement and genuinely new field, page and context IDs. First
seeing an existing editor or receiving a successful input acknowledgment is
insufficient. This transition predicate is not yet the complete durable journey
history reducer; the latter must enforce the ordered four generation aliases.

The new Create and Scripts controls have separate closed `lifecycle.*` routes.
Chat retains its existing literal route. Input uses ordinary rendered pointer
delivery and the native focused-field IME helper; no text property setter or QML
handler invocation is added. The exact original token/source must still match
and a durable intent must precede transport. Only each editor's closed run-owned
string is accepted. A return reports delivery alone. Lost or ignored input keeps
its original intent and never authorizes a retry.

Host entry points are `LifecycleFieldSourceTests` and `LifecycleFieldInputTests`
in `ios.self_tests.test_ios_lifecycle_fields`. Twelve new cases plus the existing
Back and normal-input cases pass: 26 cases in 0.058 seconds. The tests execute
actual Python codecs, private CAS intent files and HTTP/AFC input transport with
explicit Qt/OS boundaries. They cover loader/context replacement, asynchronous
creation, retained live old objects, death/history mutation, ambiguous inventory,
private text exclusion, durable Unicode delivery, refused ownership and uncertain
returns. They do not execute Qt/C++, native pointer/IME or actual UIKit callbacks.

The complete durable generation/event join, native retained-commit identity join,
actual world-attempt/drive-key/three-dimensional position sources, independent

The separately integrated [UIKit source](KEYBOARD_SOURCE.md) supplies actual
notification/responder observations; QML focus is never substituted for it.
