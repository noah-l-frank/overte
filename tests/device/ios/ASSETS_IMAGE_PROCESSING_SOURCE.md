original QObject pointer in its actual destroyed callback; pointers, URLs and

thread and never calls a Texture operator, cache eviction, pool clear or wait.

A call-local Binding masks an outer invocation before diagnostic setup. It is
not claimable during QObject connection: only successful completed setup marks
it ready for the actual later processImage entry. Each processing entry also
masks an unbound recursive call. One task can register one actual input binding;
repeated attachment, nested raw bodies, overflow and diagnostic failure make
the source unavailable. Tasks that take an actual cache-only path register no
invented input object or decoder/body observation. Positive absence requires
the complete task/call prefix and actual expired derived markers, so a task
that could still enter processing cannot qualify from an empty call table.

Each native event records its original common native clock and actual thread
context before the metadata mutex. A later publication preserves that clock.
The getter snapshots fixed metadata and weak-owner expiry only. Signal callbacks
pin the diagnostic State, never a product owner. Disarm irreversibly marks the
source unavailable and atomically removes its publication; already pinned
callbacks may finish without a waiting product drain or mutex/Qt teardown cycle.
Source1 and processing locks are acquired separately, with no nested product lock.
