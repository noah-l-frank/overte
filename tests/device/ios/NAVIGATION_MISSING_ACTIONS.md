# Ordinary missing-name input and original OK ownership

`navigation_missing_actions.NavigationMissingActions` owns the normal
`navigate-missing` and `dismiss-error` components on the existing bound iOS
session. It enters the run's actual hidden name as `hifi://<hidden-name>` through
normal Go To pointer and focused IME input. The product's real lookup reaches the
owned `/api/v1/places/<hidden-name>` route; no synthetic error or direct
AddressManager invocation supplies a result.

Before normal input, a fixed private journal retains the actual fixture phase,
provider status and a bounded native-clock bracket around the original dialog,
reply and UI sources. The admitted preexisting error state must be empty, and
both tablet and address editor must actually be closed. Native callback and
provider barriers derive from these separate original clocks. Every normal W3C
and Qt input intent is retained before delivery.

Input completion returns delivery acknowledgment only. `observe_missing` joins
the actual 404 socket response, original native callback, still-live modal and
current OK source reference for that exact run/ticket/generation. A complete
no-error read can be observed again; it cannot supply a requested error. A partial
source read stays unresolved and cannot be replaced. `recover_missing` resolves
a fully retained lost proof return without new source reads or retimed clocks.

Dismissal requires another fresh original bracket linked to the retained error
proof. Its exact original OK reference is persisted before normal pointer input.
An uncertain delivery cannot be resent. `observe_cleared` requires the genuine OK
response plus destruction of both dialog and listener. Hidden widgets, an input
ACK, and scheduled or partial deletion remain insufficient. Original error
history stays retained after dismissal. Cached proof/drainage returns are
historical originals; whole-run cleanup must acquire fresh sources separately.

The owner retains a still-open address editor as a separate responsibility;
normal original-root closure and complete scene/bookmark/restart/peer/quiet
cleanup remain obligations of the unfinished Worlds coordinator. It deletes no
ownership metadata and advertises no complete capability. Its candidate-bound
factory is `IOSNavigationRuntime._navigation_missing_actions`.

Host verification uses actual fixture HTTP 404s, private atomic journals and real
normal Python transport/validation with modeled SDK/native sources. It includes
ignored input, lost input/OK/proof returns, proof-only recovery, changed original
source counters, foreign modals, partial reads and partial lifetime destruction.
Native compilation and devices remain unverified.
