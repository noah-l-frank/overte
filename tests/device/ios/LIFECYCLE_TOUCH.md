# Original ordinary Lifecycle touch routing

This is a passive source component, not a complete input owner or feature.
Native sources remain uncompiled and no UIKit/device qualification is claimed.
The complete Lifecycle capability stays closed; five of fourteen areas remain
source-complete and previously host-qualified.

## Native originals

The existing `feature-ios-lifecycle-world` action now writes literal world
version 2. Literal version 1 remains readable without inventing a contact
history or pad. The new nested `ios-lifecycle-touch` version 1 has its own
instance, birth, real native UTC/monotonic clock bracket and domain. Its
monotonic origin is independent of the enclosing world read.

The first gated source query installs the recorder. Application's actual
ordinary Begin/Update/End/Cancel dispatch copies event timestamps, pointing
device weak identities, native point IDs, original local coordinates and
contact transitions. It records the actual UI-forwarded, script-captured or
world-handler route, including an editor-intercepted attempt. The internal
Begin-to-Update method call is not counted as another original event. A world
route alone says nothing about effective movement or pad acceptance.

The observer never accepts, sends, redirects or retains an input event and
never calls a product setter. Only the dedicated iOS E2E build records it,
after its existing test-script admission. Device death is an actual QPointer
observation; cancellation is an actual event, not inferred weak retirement.
An unresolved route, missing contact, unfinished terminal, clock rollback or
capacity limit fails closed. Event and device capacities are 128 and 8;
history is not evicted to keep a run green.

The actual existing TouchscreenVirtualPad plugin supplies read-only control
viewport, center/radius, enabled/hidden/fixed flags and current movement touch
ID/origin/position. No control positioning or plugin update runs in the getter.
An unavailable or uninitialized plugin is null. Its weak identity and the
touch-source identity participate in the version-2 world context.

## Qualification and remaining ownership

The decoder replays original transitions, preserves the complete immutable
event prefix, rejects late appended historical events and device resurrection,
and checks active contact membership. Exactly one newly observed contact is an
attempt. An ACK does not create it. Literal older sources cannot claim it.

`active_forward` additionally requires that exact still-active world-routed
contact, matching current native plugin point/ID, actual forward-only effective
drive keys, grounded measured 3D displacement of 0.3 through 3 metres, vertical
delta at most 5 cm and a contact age of at most 12 native seconds. Original
geometry is read, never selected by a desired outcome. A completed ordinary W3C
down/move/up sequence cannot supply this held proof. `contact_released` requires
the actual terminal for the same contact, empty original active set, inactive
native pad and zero raw/effective keys. It is not the later native/host quiet
window or lifetime retirement.

The 24 explicit Lifecycle touch/world source and canonical runtime host cases
pass. They cover UI interception, completed versus held contacts, cancellation,
foreign pad/contact, changed prefixes/clocks, late events, additional pointers,
bounded grounded displacement, real terminal requirements and literal-1
compatibility. The transport still uses the existing original HTTP/AFC source;
native physics, Qt events and SDK boundaries in these tests are declared models.

Still integrate a durable one-send ordinary world-input owner, bounded held
contact execution with explicit release and uncertain-delivery recovery,
independent host/native release quiet, editor history joins, Actor/image
publication, restoration and whole process/source/SDK retirement. The existing
synchronous Appium gesture returns only after pointerUp. A source reader must
not relabel that return as an active held input. No safe default touch sequence
or product behavior was changed to manufacture a held state.
