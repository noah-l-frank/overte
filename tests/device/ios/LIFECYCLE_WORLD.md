# Original Lifecycle world measurements

Feature 14 remains partial with its complete capability closed. This component
reads actual avatar drive keys and three-dimensional feet positions. It neither
sends a gesture nor reports a requested movement as an effect. Native additions
are uncompiled; no device or simulator execution is claimed.

The dedicated E2E iOS source uses the existing native read bracket around the
original version-two scene inventory, lifecycle counters, connected domain and
Avatar Mixer identities, weak MyAvatar object identity, actual model scale,
feet position, velocity, orientation and grounded/flying state. The domain
address uses `currentAddress(true)` because the ordinary address contains the
changing position. Every native drive key retains raw, disabled and effective
values. Positive native `TRANSLATE_Z` is forward in the existing MyAvatar motor;
disabled raw input does not become an effective held input.

The closed query accepts only schema, nonce, action and run. Native clocks and
the nested original scene bracket remain unchanged. The existing probe consumes
each nonce once and saves the native result through the private atomic writer.
Missing support is unavailable. Canonical `_lifecycle_world` reuses the existing
installed Script runtime, process, source and native clock gates, without opening
another session or launching the application. Background and changed-candidate
reads refuse before HTTP or AFC.

The codec checks the original native counter bounds, drive-key relationship,
PID, clock ordering and full scene/domain/avatar context. Measured displacement
is the three-dimensional difference from an original neutral grounded anchor.
Literal version 1 does not supply a gesture ID or world-attempt count. The
[version-2 touch source](LIFECYCLE_TOUCH.md) now supplies original native contact
attempts and current pad ownership independently of these physics facts. A release position window
needs at least four originals spanning three native seconds, no effective held
keys, bounded observation gaps and all positions within 2.5 cm of that same
anchor. A constant-distance arc cannot pass by preserving only distance from
the origin. This window supplies native position facts, not host quiet time,
Actor evidence, gesture-owner retirement or complete cleanup.

The explicit compatibility selection passes 42 cases in 0.537 seconds, including
twelve new world-source/runtime cases and existing scene/input cases. Tests run
actual codecs, private transport boundaries, the probe in Node and installed
factory gates; physics, Qt/native source and SDK boundaries are declared models.
The new model's clock is selected before its modeled scene import, so no recorded
scene origin is retimed to satisfy installed freshness. The final counter-bound
counterexamples are checked with the same selection before commit.

Normal editor/Back input, original pending callback rejection and Chat
background/resume now have their separate documented owners. Still required are
ordinary world gesture execution/ownership, held-input release, independent
Actor/image evidence, restoration and repeated full cleanup. Neither this
component nor its touch-source extension changes the five-of-fourteen
source-complete count.
