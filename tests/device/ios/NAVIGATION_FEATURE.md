# Worlds active action coordinator

`IOSNavigationFeature` is the internal first-process admission/action vertical.
It retains the original candidate binding, provider attachment and immutable
static admission hash before ordinary Go To scene entry. Reopening the parent
uses the actual existing child journals. It cannot reacquire an expired first
admission or resend an uncertain normal input. Neither its `ready` phase nor
its `performed` return is a product effect or proof of successful arrival.

The coordinator routes normal open/close, bookmark cancellation/CRUD, search,
bounded selection/arrival/close composites and the named missing lookup/modal
recipes through their existing original input owners. After a lost parent
return, an actual retained child acknowledgment may finish that same parent.
An unknown child input prevents both another delivery and a later ticket.
Every action checks current fixture ticket, verb, inputs and exact URL before
delivery. The 30-second action budget includes preparation and child dispatch.
Its original host epoch/monotonic beginning is retained before delivery and
checked by child input guards. Reconstruction cannot renew an expired issued
call; slow parent or child storage cannot permit a late input.

Native original observations, first-open directory recovery, independent actor
publication, actual restart transfer and final static restoration are existing
separate primitives. Their complete whole-run joining remains required; this
coordinator currently refuses restart rather than reporting an acknowledged
process replacement. It provides no whole public observation/cleanup operation
or capability advertisement. The role may read existing admission but only the
primary can send scene entry/action input.

`NavigationSurfaceActions.directory` now derives the first-open directory join
from the actual original surface action and a complete retained observation.
It takes its native barrier from that open's untouched before packet, provider
barrier from that action's original provider status, HTTP event floor and origin
from the original static admission. It requires the same observed page, ticket,
candidate, process and private directory. The returned proof uses exactly that
observation's original HTTP, model and provider responses. Joining it performs
no read, input, capture or clock renewal. The historical observation recovery
can then adopt those originals; a later public return still needs a new fresh
acquisition. This method adds no serialized schema or version.

Host tests exercise actual ordinary HTTP/W3C codecs and private original input
journals, using modeled Qt/SDK/native sources and one shared producer clock
configured before any fixture response exists. They cover ordinary scene entry,
open/close, child and parent return loss, candidate/original replacement,
actor/input separation and original deadlines. Native compilation and devices
remain unverified. Worlds remains partial until the remaining full joins pass.

The connected first-open host fixture runs the actual normal Go To and Places
clicks, real loopback HTTP and the original JavaScript/QML materialization,
followed by original native-field and untouched PNG owner acquisition. Its
physical native, Qt and Vulkan producers remain explicit models on the same
clock. Ignored opening cannot trigger a directory request or image; a genuine
response predating the actual open and a changed in-memory action original
cannot establish first-refresh ownership. These tests do not admit a whole
Worlds capability or claim device execution.
