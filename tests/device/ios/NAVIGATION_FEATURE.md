# Worlds active action coordinator

`IOSNavigationFeature` is the internal first-process admission/action vertical.
It retains the original candidate binding, provider attachment and immutable
static admission hash before ordinary Go To scene entry. Reopening the parent
uses the actual existing child journals. It cannot reacquire an expired first
admission or resend an uncertain normal input. Neither its `ready` phase nor
its `performed` return is a product effect or proof of successful arrival.

The coordinator routes normal open/close, bookmark cancellation/CRUD, search,
bounded selection/arrival/close composites and the named missing lookup/modal
recipes through their existing original input owners. After a lost parent
return, an actual retained child acknowledgment may finish that same parent.
An unknown child input prevents both another delivery and a later ticket.
Every action checks current fixture ticket, verb, inputs and exact URL before
delivery. The 30-second action budget includes preparation and child dispatch.
Its original host epoch/monotonic beginning is retained before delivery and
checked by child input guards. Reconstruction cannot renew an expired issued
call; slow parent or child storage cannot permit a late input.
The enclosing source-lock scope also registers this pure work-clock guard at
the canonical SDK/native HTTP transport boundary. Freshly constructed SDK
clients cannot bypass it through late serialization. Active acquisition narrows
the same scope to its original 1.5-second host window before new field/image
reads; child scopes cannot grant a new deadline.

Native original observations, first-open directory recovery, independent actor
publication, actual restart transfer and final static restoration are existing
separate primitives. Their complete whole-run joining remains required; this
coordinator currently refuses restart rather than reporting an acknowledged
process replacement. It provides no whole public observation/cleanup operation
or capability advertisement. The role may read existing admission but only the
primary can send scene entry/action input.

Its internal `observe_active` now connects the first-process acquisition path.

For the first open, the complete retained raw group gains its exact directory
join and becomes historical. The coordinator then acquires a distinct new

stays owned; it is not abandoned or replayed automatically. Later observations
re-derive the retained directory barriers from the actual original surface
journal. A final host epoch/monotonic check includes original revalidation and
candidate continuity inside the original 1.5-second acquisition budget.
One synchronous locked call shares pure historical validation by actual owner

carrier, in-memory envelope and original PNG. The next call checks the history
again; no cross-call cache supplies source facts or extends freshness. This
avoids repeatedly decoding the same immutable predecessor chain while keeping
late file replacement and changed state visible to the final deadline.
This remains an internal measurement; global actor sequence across restart,
the full public operation and paired final restoration remain required.
