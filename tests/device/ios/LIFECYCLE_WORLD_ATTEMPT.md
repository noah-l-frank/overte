# Ordinary world attempt under the original Create editor

The internal `world_attempt_child` uses the already held editor lock, existing
installed candidate/session/process/source and canonical original HTTP/AFC
transports. It creates no SDK session or application launch. It implements the
first intercepted world-input step only; Feature 14 remains partial and its
complete capability stays closed. Native sources remain uncompiled and devices
untested.

`LifecycleWorldAttempt.act()` requires the actual first Create context with its
owned Unicode text, focused field and settled original UIKit keyboard. It
retains a new original editor history entry and original world, UIKit geometry,
WebDriver window rectangle and independent native/host acquisition bracket.
Actual safe-content pad geometry is projected through observed native insets
and dimensions. The fixed normal action is down, a 150 ms forward move, a 300 ms
pause and up; there is no product setter, direct QML handler or requested effect.
Hidden/disabled editor pad flags do not become an assertion of world acceptance.

The common clock join indexes direct fields. Its `worldClock.capturedEpochMs`
is an explicitly checked alias of the unchanged original world's
`clockAfter.epochMs`. It is not a new native packet, host/file timestamp or
replacement monotonic origin. Both original native bracket packets and the
complete original world/geometry remain retained and validated.

The exact body, pointer identity and preparation are durable before a single
ordinary W3C POST. Its host/native admission is bounded; expired original
geometry cannot issue a touch. A lost POST result never resends it. The owner
announces one session DELETE before releasing actions, even if candidate
continuity fails during POST. That cleanup-only CAS changes only release
responsibility in the exact previously validated private WAL under the held
lock. It admits no new input and derives no native fact. A lost DELETE return
remains owned; a later native pointerUp is not an SDK callback-drain proof.

Success requires a separate fresh world original containing exactly one new
real contact at the original projected pad points, real terminal release and
UI/script interception on every phase. Actual raw/effective keys remain zero,
3D position stays within 2.5 cm of the original neutral anchor, and a separately
retained editor original preserves the exact text/context/focus/keyboard.
An ACK, ignored gesture, foreign coordinate, changed editor or unexpected
movement cannot qualify. Completed repeated calls return their original
historical result without new input or source acquisition.

The private journal retains planned/opened/saved originals in the existing
immutable file store. A saved preparation or outcome can be adopted with the
same byte/hash/inode identity before any source query. Missing, partial,
negative or substituted originals stay unresolved. Session teardown already
rejects this `ios-lifecycle-` namespace; this component retires no ownership.

normal-input/recovery cases and the 24 previous source/runtime cases. Actual
