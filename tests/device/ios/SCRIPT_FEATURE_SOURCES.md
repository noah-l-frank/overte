## iOS survey and ownership

`IOSNormalUiInput` performs a separate bounded passive survey of the original
HUD/tablet Qt windows, including hidden items. It retains weak roots already
seen until actual QObject destruction. Input eligibility, modal suppression and
an empty control list cannot erase a manager or pending native file request.
A partial scan returns `complete:false`; it cannot establish absence.

The optional `scriptObservationVersion:1`, original `scriptSourceSequence` and
`scriptInventory` fields extend the existing native UI packet only in the E2E
configuration. `NativeInput` checks the actual inventory/tablet agreement and
retains the complete nonce-bound outer receipt. The dedicated Script reader
uses a separately acquired original native clock. The normal legacy capture
API retains its previous behavior.

`IOSScriptUISource` projects original field names and strips only input geometry
from its typed control view; its entire original receipt remains attached.
`ScriptUISource` verifies each projected field against that original, enforces
original source/elapsed/input cursors and does not send feature inputs. UUID
format and iOS nonce prefixes remain original; they are not stripped or changed
to match Phone data. Neither private file times nor host UTC fills native time.

The native source is default-off. Host transport/counterexample tests use
explicit synthetic native SDK responses and real Python HTTP/AFC framing.
These checks do not establish native compilation or physical UI semantics.

The combined no-build dependency/iOS selection passes 302 cases, including the
new original UI transport counterexamples. It rejects stale native time despite
host clock skew, nonadvancing source cursors, lost/foreign read receipts,
projection changes and incomplete hidden-root inventories. No source packet is
retimed, no failed input is replayed and no area is promoted by these counts.
