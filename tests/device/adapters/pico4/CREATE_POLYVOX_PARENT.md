# Pico Create normal PolyVox parent extension

Feature 4/14 remains **partial**. The existing private Create parent v2 now
connects `voxel-create` and its following ordinary `delete-owned` to the normal
NativeCreate detail selector, original NewPolyVoxDialog, original product
callback, and independent native insertion/volume observations. It creates the
canonical 8³ volume with a central 4³ cuboid, names the original entity through
Properties, sets unit dimensions and position two meters along the independently
measured avatar forward direction, and independently observes normal Delete.
No `feature.create.*` full-flow capability is advertised.

The normal detailed selector requests the actual original PolyVox dialog. The
three actual IntValidator fields receive pointer/focus/NativeFieldInput input;
normal combo/key input chooses the original texture preset, box and surface
style. Original `edit.js::fromQml` pops the real tablet stack **before** handling
`newPolyVoxDialogAdd`. The parent observes that return; it never directly pops,
loads QML, calls product JavaScript, sets entity properties, or writes voxels.

The additive `create-extra.*` controls bind the exact resolved original QML URL,
actual native base types, actual QML identities and wrapper alias, actual window
and finite scene geometry. Changed geometry or original objects changes the
source token. The common hit walk still enforces clipping, finite/bounded
traversal, visual z and foreign/disabled opaque occlusion. Its optional exception
is limited to the source-qualified original paintless Row/Column/Item containers
and exact original translucent field frames. The original Row can accept touch
for child delivery; the actual original Pico/OffscreenQmlSurface touch bodies
are exercised against it. An opaque parent or foreign touch/paint surface is
never treated as that original decoration. Popup key input also checks the
actual focused native item's unobstructed point.

The private native-only EntityScriptingInterface insertion collector is gated
by the existing dedicated feature/Pico definitions, `--testScript` and prior
validated private observer admission. It observes successful original local
**domain** Tree insertion, with original UUID, type, creation timestamp and
actual last-editor session. Failed insertion, prior/unarmed insertion, remote
Tree packets, avatar/local UI entities and a caller-provided name are not
creation receipts. Its finite history retains all later domain insertions and
refuses on ambiguity/overflow; it cannot drop old ownership. The v4 entity getter
compares that history before/after capture and retains actual QObject lifetime
identities. Original v1-v3 entity packets remain readable. Production v4 is
required before any primitive input.

The actual renderer's passive PolyVox getter reads Ready/state/dirty flags,
volume dimensions, surface style, actual mesh readiness/vertex/index counts,
original compressed data and all 512 canonical
voxel values under **one original volume read lock**. It cannot combine values
from distinct independently locked revisions, and makes no asynchronous mesh,
pixel or domain-server receipt assertion. Noncanonical volumes have no claimed
512-value snapshot. Oversized original data refuses. The parent matches the
new insertion against its pre-input native history, actual domain generation,
actual original entity, current session and original creation time before
naming it. More than one new domain insertion refuses adoption. Quiet completion
requires the original complete 512-value central cuboid, actual current entity
properties/selection/readiness, original script compilation and quiet work,
and three seconds of advancing host and original native/UI clocks. The
original creation entity/callback/work bytes and hashes are retained in a bounded
compressed checkpoint with the original UI frame, surviving later Delete. A
final fresh sample must still equal the qualified original entity before the
parent completes the call. Model-only generic renderInfo counts are never used
as PolyVox mesh proof.

Every parent intent retains the original phase fence. The root atomically
records the exact original Add envelope with its input cursor before dispatch;
a pre-dispatch phase refusal cannot be mistaken for an uncertain delivered Add.
A consumed or uncertain Add is never resent. A lost final Properties Apply can
be reconciled read-only from independently measured canonical effects. Partial
configuration remains pending. Cleanup can issue a distinct normal Delete of
the independently identified original entity; ambiguous insertion histories,
uncertain Add with no observed insertion, retained QObject or retained QML
context keep the original owner open.

The append-only native extra UI inventory uses actual QPointer page/context/
window identities, reusing the same identity for the same surviving QObject.
It retains original first-observed times and actual liveness after disappearance.
The parent preserves original baseline pages and requires both actual new page
and actual original context death before whole-owner retirement. Shared window
survival is separately observed. No forced GC, event pumping, product deletion,
cache eviction, process restart or fabricated retirement is introduced.

`create-polyvox-native-ui` loads original NativeCreate/NewPolyVoxDialog and real
controls under Qt5, uses the complete original Pico pointer/Offscreen touch
source bodies and NativeFieldInput, and passes the actual emitted Qt callbacks
through the original Node validation/fromQml/dialog/createNewEntity functions.
Tree, Tablet delivery, math, HMD/sound and host window are explicitly substituted
boundaries. Original local-insertion and atomic volume C++ bodies are separately
compiled with declared Tree/storage actors under Qt5/Qt6 by
`create-entities-native`. `create-primitives-owner` runs the actual parent,
phase reader, private CAS journals, source lock, token UI and original packet
readers with declared native/domain/UI/renderer actors. These host checks do not
claim a complete Interface, V8, server, Pico, OpenXR or GPU run.

Remaining full Create work includes the normal controller voxel brush effect,
actual denied/rez authority and exact restore, independent peer/current state,
actual completed stereo draw/texture/pixels and artifacts, and complete original
lifetime closure. Existing cached resources, retained QQmlContexts and original
physical setting restoration limits remain retained boundaries. This packet
adds `create-primitives-owner` and `create-polyvox-native-ui` selectors (local
catalog 66 to 68); integration must add two to the parent's actual catalog.
