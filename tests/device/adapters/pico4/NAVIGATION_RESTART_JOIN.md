immediately after the actual renamed-bookmark return to A. Its first complete

## Actual transport and reconstruction boundaries

The existing `AndroidAdapter.invoke('app.stop')` performs the original
`am force-stop`, waits for process stop and discards the current host Session
file (`adapters/android/adapter.py:1076`). The unchanged `app.launch` may call
`launch_debug_app`, which can stop a running orphan and cleans/rebinds the host
Session (`adapter.py:492`). Calling that bootstrap again after a lost response
would violate this action's one-send ownership. The exact actual force-stop and
controlled `am start -W -n ...` SDK calls need their candidate/target/process or
stopped-state guards completed before the final independent phase admission;
no later discovery, retry or bootstrap may intervene. Their input receipts are
not old-process death or successful new startup.

The old Session must be observed under its original lock before Stop and
preserved as an immutable original with the last actually published envelope
and sampled owned-stream status. Its nonce/cursor and old binding must never be
silently replaced by proposed new values. The existing normal restart route may
rotate its managed current Session entry, but the predecessor's original stays
in the restart lineage. A grant/host-save gap remains unresolved, as in the
normal Open boundary; an acknowledgement supplies no feature effect.

`PicoBoundAdapter._script_paths` uses one per-target UI path
(`binding.py:224`), and `PicoNavigation.__init__` strictly checks that file's
original process identity and bridge (`navigation.py:260`). Reconstructing the
old UI through a new live process therefore correctly fails. New Navigation
runtime ownership must use a separate generation-1 UI path through the same
`normal_scripts.runtime`/`NativeNavigationIO` route; it must not erase the old
file or relax its original process/bridge checks. Historical validation uses
its old expected PID/bridge, never a current source impersonating the old PID.

Likewise, the original `NavigationPrefix` scope is bound to its first actual
process, source binding and Session. A continuation requires an explicit
lineage between that unchanged original forest and the independently admitted
new runtime. Native source cursors are continuous inside one actual birth.
Across restart they must reset only through the exact closed original proof;
old and new observations must not be passed to a relaxed ordinary continuity
validator. Both roles acquire new original source brackets on the new binding,
keeping old role frames and their original timestamps unchanged.
