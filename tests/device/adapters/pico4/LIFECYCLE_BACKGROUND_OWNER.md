# Owned normal Lifecycle background and return

This private source/host component composes the actual Lifecycle Reply Chat,
ordinary OS HOME/activation, original native Qt history and current avatar/UI
quiet. It exposes no `feature.lifecycle-input.*` capability and establishes no
device, peer, image or complete sixteen-step acceptance.

`_lifecycle_background_owner(target, run, source_lock=parent_lock, world=world)`
reuses the exact parent Script source lock and existing World owner. Call
`prepare(chat)` with the actual typed `PicoLifecycleChatDraft` whose X join owns
that same World. Preparation freshly observes the original Reply field, one
actually consumed/neutralized world gesture, unchanged original feet and the
native settings/lifecycle source. Exact Chat, Create, X and Back owner archive
hashes are preserved and checked before further input. It reports no editor
generation; the whole parent must derive that separately from the earlier
original Create/X/Chat context history.

`run_owned()` persists every observer arm/release request and ordinary
HOME/activation intent before delivery. It reuses the unchanged
`PicoGraphicsBinding` OS routes: actual installation, PID/start, original OpenXR
session identity and OS foreground package are checked. HOME requires the
original foreground scope. Cold reconstruction reads private originals and OS
status first; no Qt/native foreground reader is created while backgrounded.
The remaining owned activation requires actual background. Uncertain HOME or
activation is never repeated. Lost observer mutations reconcile their original
native command IDs and immutable frame prefix through a read-only query.
Each durable OS intent invokes that existing operation once. Its original
bounded HOME handling may itself retry OS-observed ignored HOME events; this
owner adds no retry of the operation or its uncertain response.

After HOME the autonomous native source must contain a Hidden/Suspended timer
sample at least 250 ms after its first background sample on both native clocks.
The original interval through native Active return has no sampling gap above
500 ms. Host waiting, input acknowledgement, requested keyboard state and
resumed-only absence cannot establish this interval. The exact original
field/page/context/window/loader and enabled/created VR keyboard remain bound,
with no visible, raised or pressed key. The original field loses focus while
preserving Reply. Fresh full normal UI/native sources after return must advance
beyond history cursors, retain PID/native instance and the same field, advance
actual background/activation without another launch and preserve the original
graphics/audio/account settings subset.

Three seconds of current full UI/native/gesture/feet observations precede
observer release. Its actual timer must then stop through the exact one owned
release; another three seconds of current originals verify quiet after release.
Repeated completion obtains a new full quiet window. Native lifecycle counters
and original neutral gesture history cannot change inside those windows. All
three position coordinates use the existing 0.025 m stability and original
position checks. Final copying and persistence precede the last candidate guard
and native clock read; native/monotonic source age stays at most 1500 ms.

`pico-lifecycle-background-owner:1` stores `lifecycle-background-owner.json`.
Its closed payload retains source indices, complete raw World/native frames,
mutation requests, OS boundaries and both quiet windows. Lossless raw/SHA
references use `pico-lifecycle-background-originals:1` in
`lifecycle-background-originals.json` and the exact reviewed shared
`chat-journey-source-chunks:1` container. Its scope binds this original run,
candidate/process and Lifecycle background role. Every immutable child contains
one complete original raw packet, preserving whitespace and hash; the root
keeps its existing reading intent and SHA manifest. Bounds remain 512 children,
16 MiB original bytes and 64 KiB per private file. Owner and original manifests
must agree before recovery. Failed child/root/owner writes, orphan files,
changed signatures, wrong scope and modified bytes stay unresolved. There is
no adoption, truncation, migration or deletion operation.

The source QObject/Qt connection, original editor contexts, all input journals
and original files remain process-owned. Timer release does not retire them.
Missing background facts, refocused Chat, failed persistence, a restarted
process and unavailable sources cannot pass. Final process retirement and full
resource closure must still compose the independently proven OS absence and
original-state restore. Scripts/pending/stale input, later world movement and
independent peer/image evidence remain outside this component.

The focused device-free group executes the actual Python owners, readers,
existing input-session cursor, shared lock and private container over explicit
synthetic OS/Qt/input/feet boundaries. The existing native background-source
compiler harness is separate. This packet changes no native/product source.
