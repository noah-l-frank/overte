# Source transaction lexical-wire prerequisite

`emote_source_transaction_wire.py` is an exclusive Host prerequisite. It does
not construct a Native source, replace the Primary factory or provide current
Emote facts. Its transport argument currently runs a declared Host shell model.
The six test payloads deliberately are not valid Native observation packets.
No TSI, Probe, TabletBridge, Binding, existing source or SDK code is changed.

The proposed real transport must return one actual opaque wire containing all
six complete lexical source packets. Historical six-return acquisitions cannot
be reclassified as one. The Host uses the existing AudioRawArchive1 container
in an explicit source scope, with no second writer or raw quota. Its existing
512 reservations, aggregate512 parts and16MiB stored/decoded limits remain.

## Qualified component behavior

One original reservation precedes transport. The actual reservation, archive,
bound retainer and limit remain strongly held before dispatch. Even if public
archive/pending/format configuration changes during the actual return, its
permitted bytes go into that original reservation before business rejection.
First-clock and first-guard reentry retain the outer claim and issue zero
transport calls. A new unknown reply cannot expose the previous read's literal
as its current result. Distinct request nonces cannot be replayed, including
reusing a consumed nonce with changed policy bytes. The existing original
journal supplies this history; only the current command/claim is retained by
this decoder, so a second command-history buffer cannot silently outgrow its
metadata allowance.

The entire returned wire precedes framing, UTF8, JSON, expiry and callback
checks. Actual process TimeoutExpired and CalledProcessError stdout prefixes
are also retained before failure. The eventual SDK exchange must use
`execute_bytes(..., check=False)` because its default error path does not
return acquired nonzero stdout. Complete framing, six ordered labels, original
sizes/hashes and all up-to51 actual Native-pending lexical records are required.
Pending records remain originals and cannot substitute for a current source.

Root independently passes fifteen explicit Host cases in0.577s with76 loaded source hashes/full
physical signatures unchanged. All88 terminal files are compared before/after
the actual RawArchive close. Actual subprocesses are reaped; no persistent
workers remain. Cases include exact incompressible1MiB/NUL, actual173-byte
timeout and211-byte nonzero prefixes, unknown second reply, all three existing
compound caps before dispatch, callback/global/archive substitution, Unicode
decoded expansion and51 retained pending records. Native execution, real SDK
devices and whole Common behavior remain unqualified.

## Bounded decoder copy accounting

Let W=1,048,576, the existing literal bound, and L=262,144, the largest source
lexical packet. This decoder admits at most W aggregate canonical source JSON.
It decodes one packet at a time, uses the existing `canonical_size` to count
strings recursively without a complete serialization buffer, deletes body/text
temporaries before adding a value, and makes no full-frame deep copy.

The conservative simultaneous byte-domain bound is:

| Live item | Bound |
| --- | ---: |
| Original wire | W |
| Previously admitted canonical values | W |
| Next lexical body slice | L |
| Original UTF8 text | L |
| Newly parsed canonical value | 5L |
| JSON number token or later scalar serialization | L |
| Total source data | 4W |

Unicode can expand into escaped canonical text. Finite scientific notation
also matters: `1e15` becomes18 canonical bytes, so a blanket3x JSON bound would
be false. Each newly decoded packet is checked against5x its actual lexical
size, and the aggregate canonical cap remains W. Oversize decoded graphs
refuse after the complete opaque original is retained.

Metadata is checked at16KiB, including the actual parsed header, original
header text, request and every typed extent. Another8KiB conservatively covers
original-header/frozen-request/transient overlap. Thus the decoder's reservation
is4,218,880 bytes, below the unchanged existing4,224,088 sideBytes guard. This
is canonical/decoded-byte accounting; it does not bound Python RSS, object
overhead, arbitrary external callbacks or a future complete source factory.

## Mandatory unresolved integration

The Native producer and its fixed file writer have not been implemented. Its
actual closed total byte gate must fit this wire, preserve all produced Native
partials strongly on overflow/failure, and retain the same original policy,
process/role, native counters and deadline. The individual old six getter caps
do not prove their sum fits. Async Native pending work must never block the GUI
or renew its nonce/clock. The same existing NavigationUi observer must supply
widgets, with no new instance, UI setter or requested observed values.

The future SDK outer envelope must verify actual process birth, original
Native root and complete held-file physical identities before/after copying.
It is absent from this lexical-container component. It must address its body
with absolute extents into the original SDK wire, avoiding an extra1MiB body
copy. Every original Native packet validator, sequence/history link and final
freshness test still needs the actual Source integration.

Native file/metadata reservations, old/current Native buffer overlap, full
Source frame copies, cold marker/probe/UI gets, ordinary input UI reads,
captures, independently advancing Actor observations and whole compound bill
are not proved by this decoder. Selecting a raw profile after an eager getter
cannot repair the cold-first-get gap. A typed lazy runtime selected before any
getter, same original Parent and archive, actual initial validation before
baseline/input, and original120-second ownership remain required.

This component does not establish a minimal complete Common budget, warm
captures, image carry, background, quiet or final retirement. All Native,
stereo, independent-Actor and public whole-feature qualifications remain open.
