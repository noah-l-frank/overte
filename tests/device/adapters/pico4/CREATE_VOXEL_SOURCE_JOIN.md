# Create original voxel source join

Feature 4 remains partial. This owning host selector joins the existing normal
Create TOOLS fixture to current original CPU volume and geometry sources. It
reuses `CreateEntityLifetimes`, `CreatePolyvoxResources`, the atomic
`featureCreateVoxels` getter and the existing Python volume/resource/retirement
predicates. It does not add a product getter or enable a device capability.

`create-voxel-source-native` starts from one explicitly owned, isolated 8³ edged
Marching Cubes fixture containing a 4³ filled block. Initial insertion, the
controller SDK/pose, entity-list transport, tree/simulation and scene removal
are named host endpoints. The actual original QML, Pico/offscreen pointer
bodies, field input, NativeCreate bridge, EditModes and whole EditVoxels module
handle the normal TOOLS configuration, controller mapping callback, remove
stroke and restoration of all seven settings. Controller delivery itself is
not an OpenXR/device observation.

The cuboid call passes through the complete original EntityScriptingInterface
worker and RenderablePolyVoxEntityItem mutation bodies. The full current
VoxelVolume and both Marching Cubes/Cubic extractors compile unchanged. This
fixture executes the original edged Marching Cubes path, update state machine,
asynchronous mesh construction, compression and collision-point preparation
without replacing Ready or geometry results. Real QtConcurrent tasks build original CPU
gpu::Buffer storage and graphics::Mesh objects. The fixture has no neighbors,
uses no texture URLs and has no domain element; network publication, texture
acquisition, materials, physics integration and GPU submission remain outside
this selector. Shared CPU Mesh/Buffer preparation is reused by the original
ModelCache/Baker selector; its default body selection is preserved.

The existing original asynchronous renderer method copies the actual newly
built mesh on a joined worker thread. Weak mesh/entity/renderer histories are
observed at the original atomic entity and render-thread notification seams.
The test observes the older render copy while the new entity mesh is ready,
then observes equal new entity/render mesh identities on the same renderer.
The original EditVoxels settlement callback runs through real 100 ms QTimers;
the test observes invocation and eventual QObject destruction of those timers.

After settings restoration, normal PROPERTIES input reaches the original
NativeCreate Delete branch and complete original edit.js selection deletion
functions. The host tree removes only the owned UUID. A declared host scene
endpoint releases its actual renderer owner after that Delete. This endpoint
is not the product render scene or a cache-release proof. At least three seconds
of bounded observations then use the existing retirement predicate on an
explicit minimal retirement slice. This slice does not claim validation as a
complete feature-create-entities response.

Three fresh-process modes share one fresh compilation: normal, retained renderer
and ignored controller. Retained renderer must keep the original entity,
renderer and mesh alive after tree removal, so the same retirement predicate
refuses it. Ignored controller must leave all 512 original values unchanged and
produce no cuboid call or saved stroke. Process exit and cleanup after a failed
case are never retirement evidence. Raw native frames are append-only and
persisted immediately. A separate live host reader binds each original line by
SHA and sequence to its actual monotonic and epoch receipt times. Quiet starts
at its first captured frame, then continues for at least 3100 ms. Native
QElapsedTimer/epoch and independent host monotonic/epoch spans must each reach
3000 ms; native/host cadence and source receipt age each remain within 500 ms.
The 512-observation and 16 MiB limits remain.
The compiler limit is 90 seconds and the registered selector limit is 120 seconds.

The final Native6 selector passed in 25.949 seconds: one fresh compilation,
all three modes and 13,455 repository input files unchanged. It executes the
complete original constructor, initializePolyVox and destructor and the actual
typed deleteLater lambda selected from the original factory. The original
destructor resets VoxelVolume under its original write lock. Full product
factory creation is still outside this explicitly owned initial fixture.

The normal volume changed from 64 to 16 occupied voxels; original geometry
changed from 96 vertices/564 indices to 48 vertices/276 indices. One actual
settlement timer invoked and was destroyed. Normal Delete left both observed
meshes, the renderer and entity dead and the original CPU-buffer count at zero.
Retained renderer left the original entity and renderer alive with four CPU
buffers and the existing retirement predicate false. Ignored controller left
all 512 values and compressed data unchanged, with no mutation, saved stroke or
settlement timer.

Native and host epoch spans also passed the strict 3000 ms checks. All actual
native/host gaps and receipt ages remained below 500 ms. Raw frames, independent
host receipts, original fragments, provenance and all attempts remain in
private local evidence.

Four earlier attempts remain preserved. The first refused three host compile
bindings. The second freshly compiled the original path and restored settings,
then refused a wrong host tab before Delete. The third passed its then-current
assertions, but its original quiet span was only 2926–2933 ms because its first
frame followed a 100 ms wait; this does not meet the required 3000 ms window.
The fourth stopped before compilation on a duplicated Python block while
adding independent host receipt capture. The changed Native5 selector removed
that duplicate, passed AST parsing and required all complete strict clock spans
above. Earlier incomplete quiet assertions and process cleanup are not
retirement evidence.

Native5 independently passed strict clock checks in 26.361 seconds, but used
implicit host entity field destruction. Its original normal/retained/ignored
quiet spans were 3129/3138/3129 ms natively and 3122.892/3143.736/3123.697 ms on
the host. It must not be presented as execution of the original entity
destructor. Native6 added that actual release seam and freshly compiled it.
After its green selector terminated, an erroneous repeated source hash in the
outer administrative receipt writer was stopped with no compiler/test child
remaining. The unchanged source receipt was recomputed once; no native mode
was interrupted or repeated and no resource release was derived from that
administrative process stop.

The existing `create-polyvox-native-ui` selector also passed both unchanged
legacy cases in 11.856 seconds. The shared CPU preparer's two complete default
Mesh/Buffer fragments and 29 original body/file hashes match the fixed earlier
Baker evidence byte for byte. The narrow repository documentation, source-layout
and project-coverage suites passed, as did Pico coverage, the contract registry,
both changed JavaScript syntax checks and the staged whitespace check. The
catalog gains exactly one selector; no existing selector is removed or split.
The final native selector and legacy regression commands were:

```sh
python3 android/vr/pico/tests/pico4-test-suite.py --test create-polyvox-native-ui --timeout 120
```

Full application/controller/domain authority, actual normal creation and Rez
failure, product scene/material/texture lifetime, stereo effects, and full
allocation retirement remain open. In particular, the original
SurfaceExtractor base has no virtual destructor although the original worker
owns a derived extractor through `unique_ptr<SurfaceExtractor>`. This source
finding is an unconfirmed heap-retirement limitation; the selector does not
repair it or infer a full heap proof from weak Mesh/Renderer and CPU-buffer
counts. The existing full-parent physical observation inventory also remains
unqualified; this selector does not reset or relax that budget.
