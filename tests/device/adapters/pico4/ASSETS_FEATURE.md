`assetsControlsVersion: 1`. The private `_assets_controls` factory projects its
actual original references onto the shared Assets recipes. Inputs still use the
existing `NativeNavigationIO` installation/process/foreground guards and final

relative companions, main-file review and destination confirmation.

Native source resolution binds actual resolved QML URLs, original context IDs,
real Rectangle/Dialog base types, finite scene center/extent and actual window.

identity. Changed row paths, moved controls or replaced windows invalidate
original references. Traversal and original picker arrays remain bounded.

`probe-disabled` operation is allowed only for the actual disabled

scene hit traversal checks that exact original child's center and excludes

permission/UI and unchanged independent server mappings must still qualify it.

## Narrow host qualification

`assets-native-ui` compiles the entire original Pico NavigationUi observer and
input body, the shared helper, original Pico/Offscreen pointer bodies and whole
original FileDialogHelper/NativeFieldInput. It loads actual repository QML at
its resolved URL, with explicit unavailable unrelated platform services and a
keyboard-device endpoint. Real ordinary events browse/import/rename/delete,
select three real relative bundle files, review/submit a destination and call
the declared upload endpoint. The real selected primary is then unlinked; normal
Select produces the original unavailable-file error, no second upload, and
Cancel closes the picker. Disabled-runtime admission is checked separately.

Asset Server/entity/oven endpoints remain explicit host seams. Their counters
are not actual backend or loaded-model proof. The host keyboard endpoint is
not physical VR keyboard retirement. No Android application, live server/oven,
physical Pico or OpenXR device session is run by this check.

`assets-controls` separately exercises the real canonical Pico factory,
NativeNavigationIO and token recipes with declared SDK/widget endpoints. It
refuses ignored effects, unconsumed sequences, changed/foreign references,
missing producer markers and a failed final original input fence. Its closed
disabled probe does not enable Delete or create a confirmation.
