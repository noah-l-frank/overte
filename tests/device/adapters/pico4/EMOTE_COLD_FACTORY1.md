# Private cold Emote factory 1

`emote_cold_factory.create_cold_common` constructs the existing Parent2,
Common1, StreamCycle1, Capacity1/Policy2/Originals2 and normal Sources2/Inputs2
graph before the first marker, probe or UI JSON acquisition. It returns that
same Cycle and its two cold runtimes. It creates no second Parent, recipe,
raw archive, source quota or deadline. No public capability is enabled.

The caller supplies both held original role locks and, per role, exactly
`adapter,target,binding,phase,lock,subject`. The binding is an execution fence,
not an observed UI or native fact. Actual installed-candidate/kernel-PID/host
session guards run during construction. Native reader constructors perform no
source acquisition. The existing Parent's baseline intent starts its original
120 seconds; existing Cycle bootstrap admits both policy roles and the single
aggregate raw archive before the first controlled-debug getter.

Marker/probe/UI/native/script-root/script/inventory/work literals use fixed
paths and the existing physical-stat wire grammar. Every getter reserves its
maximum bytes in the original range archive before dispatch. Actual returned
or timeout bytes reach its pinned original reservation before UTF8/JSON,
schema, business-clock or late-source guards. Failed reads are sticky. Read
ownership precedes clock and kernel callbacks; a refused recursive read cannot
clear the outer claim. The original `PicoScriptIO` initializer, capture and
normal pointer/OpenXR input implementation execute after raw admission.

Fresh Source acquisitions use their own original Native reader objects. The
already-installed Stream4 control fence stays attached exclusively to its
control reader; it cannot be used as an inactive ordinary-source fence.
The last Parent admission precedes each actual control-command writer.
