input, then after the existing normal tablet/open/Create/focus owners run. It
does not replace the common-v16 journey or grant public Lifecycle capability.

The worker owns fresh Pico UI, Gesture, Drive, Pending, NativeFeature and

The Parent and worker execute real Python, HTTP, process, descriptor and file

Only complete raw native responses cross the query transport. No Parent
measurement, expected facts, requested generation, input command or Parent

reads the same target feet/orientation/scale and must agree with Drive; there
is no Actor-side pose simulator. This stage uses Subject2 avatar pose, without
claiming Subject3 framework/stereo qualification or a mixer/remote avatar.

## Closed authority and storage

`PicoLifecycleActorSource` accepts only initial fixture baseline and subsequent
baseline or normal Create-open phase. Initial phase readiness is required before
the first native query; a missed initial baseline cannot be invented later.
Generation derives from actual newly observed native weak editor identities.
Text/focus/keyboard, held inputs and displacement come from those original
sources. This stage refuses actual new world-start events, pending runs,
commits, archived callbacks or pending intents; absence is measured, not
selected by the requested action. Later recipe stages need additional admission.

Each complete raw response is retained before the next query. Own prior UI/
Gesture/Drive, Pending, NativeFeature and Subject cursors are checked before
acquisition. Every result is checked against the independent current fixture
prefix and retains its original native/host age anchors. All copy/persistence
work precedes final identity/file/candidate/native/host checks, repeated after
the actual outer source lock exit. Same bytes on a replacement root inode are
refused. No old packet is replayed as a fresh observation.

The actual original source result is bound to a durable publication intent
before its HTTP POST. Fixture prefix is rechecked after that CAS. The received
transport reply is archived before advancing to delivered. A landed POST with
a lost reply retains issued ownership and refuses another source query; neither
the reply nor the caller supplies measured facts or a successful input.

Private `pico-lifecycle-actor-source` version1 is additive. The root is
`lifecycle-actor-originals.json`; its root and orphan `.frame-*` files retain
canonical cleanup responsibility. Root/chunk physical identity, full bytes,
hashes, bounded inventory, immutable scope and exact current process remain
mandatory. There is no cold live-owner adoption. Existing Source1–4, Process,
World and native protocols are unchanged.

Limits stay128 Actor rows,512 child parts,16MiB unpacked transcript-container
