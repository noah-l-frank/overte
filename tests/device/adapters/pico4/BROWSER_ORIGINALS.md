# Pico original browser sources and native tablet input

This private v1 component reuses the closed document, bridge and inline-lease
owner from fixed Phone commit `5527d540e99cc6dba4204a5e904a854e6e1cd2b4`.
`PhoneWorldWebE2E.inc`, `overte_phone_world_web_source.py`,
`overte_phone_tablet_web_source.py` and `overte_phone_tablet_web_dom.py` are the
reviewed origins. The selected source bodies are adapted locally; the Phone
checkout and its work in progress remain untouched. Complete feature capabilities
remain unavailable. Neither a native-screen screenshot nor a mono capture can
qualify Pico stereo rendering.

The selected production backend is `android/common/web/src/NativeWebViewItem.cpp`,
linked by `overte_target_embedded_web(picoOpenXR)`. The historical PicoWebViewItem
is not this source. Instrumentation is default off and requires the original
explicit test script and results launch boundary. The private TSI/Probe endpoint
validates a closed owner/run/native-view command, and the factory shares the
exact original Script source OS lock. Witness readers are read only. Existing
HTTP-only DOM v1 and stronger native/Java/renderer runtime v2 stay distinct.

The actual owned document source supplies measured element bounds, viewport,
hit-test result, connection/enabled state and original focus/text/selection.
Caller coordinates and arbitrary selectors or JavaScript are rejected. Native
validation joins the original source to the exact current handle, creation,
grant, page and document; zoom, viewport offset, stale measurements, foreign
owners and invalid geometry fail closed. The actual image aspect must match.

The Pico provider reacquires the shown system tablet, actual root, surface,
window and ancestor membership. The original occlusion/clipping checks precede
`sendPointerAt` through `OffscreenQmlSurface::handlePointerEvent`. It does not
use Phone direct Java touch dispatch. One pointer attempt precedes a bounded,
read-only wait for the original focused DOM and matching native editor metadata.
The actual window receives one ordinary `QInputMethodEvent`, describing the
measured complete surrounding range. This asynchronous browser route cannot use
the synchronous native Quick-control text replacement assertion. No element
value, browser navigation, page handler or product state is assigned by the
adapter. Normal product IME handling remains unchanged.

Every attempted input retains its actual closed command, original JNI geometry
and focus strings, native metadata before IME, actual attempt clocks and original
terminal delivery receipt. Document/bridge/DOM and held inline callback histories
are cumulative and bounded. A delivery ACK supplies no desired text, echo,
HTTP result or pixels. Native completed nonce replay preserves original packets
without reissuing input or changing their clocks; old evicted observation nonces
are rejected. Explicit native observer retirement requires owned views absent,
no held callback, no outstanding Java read and actual focus-timer destruction.
It clears retained observer payloads and keeps only bounded nonce hashes to
prevent reuse. A final independent runtime v2 Java UI fence and renderer/source
closure are still required by a whole feature owner.

The focused host checks compile the actual selected native backend, Qt5 moc/rcc,
original Pico pointer/provider bodies and actual production Java against existing
Android/WebKit APIs. The host JVM substitutes WebView and its scheduling; the
Tablet singleton and DOM packets are declared boundaries. The test drives the
actual native/Qt pointer and IME path, then validates its original native output
through the Python source reader. Its model remains unchanged at the Android
editor boundary: a positive delivery cannot manufacture a successful DOM effect.
Pure JS checks execute the actual passive source in a synthetic DOM. These are
host checks, not an APK, Android WebView, OpenXR or device qualification.

Remaining whole-flow work includes normal fixture-app opening, native wheel
scrolling to offscreen controls, keyboard/presentation handling, actual stereo
captures and markers, independent actor publication, original Script/service
closure and durable end-to-end finalization. World input also needs its actual
Pico entity/VR surface route; this tablet provider rejects world items. The
reserved reference profile does not qualify media or general web origins.
