# Original per-role Graphics lifetime v1

The internal [`GraphicsLifetime`](../graphics_journey/lifetime.py) composes the
existing original source protocols under the same Graphics/Script source lock.
It sends no normal input and changes no provider phase or product setting.
Each role/process stage has a separate journal and original queries.

Active evidence requires the explicit Pico surface fixture v2, original scene
delivery, all seven independently observed entities and separate current
native/Java/renderer ownership for all three Web sources. One marker's renderer
cannot establish the other surfaces. This lifetime readiness is separate from
the observer's original per-eye GPU/pixel effect evidence.

After normal world restoration and provider retirement, every quiet group joins:

- Original avatar, complete sensor-to-world matrix, scene and framework facts
  against the complete restored scene archive. Restart restoration uses only
  that archive's qualified new-process baseline and preserves old originals.
- Released scene request leases and current native/Java Web views, creation
  authorities, callbacks, renderer worker threads and release results.
- Actual tablet QML service roots, XHR handlers, timers, callback depth and
  independent reply destruction, including retained completed objects.
- Passive Pico Graphics UI v2 roots, QML components, menu callbacks, focus and
  keyboard, plus the separate complete Script manager/picker/tablet inventory.
- New original native complete-issuer inspections of both roles' previously
  retired acquisitions. All current role/legacy capture owner files must be
  absent; original memory/callback counts and every issued receipt must remain
  absent. These inspections send no release/removal input and cannot recreate
  an acquisition or retire an unresolved foreign owner.

Groups retain original epochs and source cursors and must fit within 1500 ms.
Query identities cannot be reused with advanced cursors. Each call starts its
own three-second local and original-epoch window, with at least three complete
groups, bounded observation gaps and a twenty-second/64-group budget. Partial
windows remain history and never accumulate into a later successful window.
Final freshness includes original clock and actual local time through archive
validation. The owner advertises no complete Graphics operation or capability.

Immutable `graphics-lifetime-archive` v1 files contain packed original groups or
the complete restored scene archive. Exact canonical SHA256 references bind
their private directory and basenames, keeping durable histories within the
existing unchanged packing bounds. Missing or changed files prevent archival
reconstruction. Historical validation accepts no live clock or successful guard;
only the original source records and their intervals are checked.

Host counterexamples exercise the real Pico normal scene owner, seven source
protocols and actual private receipt files with synthetic SDK/native boundaries.
They cover separate actor windows, retained renderer/reply/UI/capture callbacks,
foreign ownership, changed current framework, pending scene leases, frozen
original clocks, observation gaps, interrupted windows, reused queries and
missing archives. No native compilation or physical device qualification is
claimed. The full feature/actor dispatcher still must join these owners, all
shared Graphics checkpoints and recoverable final metadata retirement.
