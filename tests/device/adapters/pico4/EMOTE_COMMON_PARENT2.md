`PicoEmoteNativeCycle(..., common=PicoEmoteCommon())` selects the explicit
Parent2 input/effect policy before baseline acquisition. The default constructor
continues the existing Parent1 Open/Play/Cancel/Close algorithm and journal.
The original Parent class, process, lock, source, input, effect and lifetime
owners remain authoritative. There is no second recipe, Parent or clock.

Parent2 handles a normal input once and records its actual acknowledged input
header separately from later fresh effect observations. A handled natural
completion or Cancel can remain `picoEmotePendingRestoreVersion1` while the
actual native override remains active. Later `observe()` calls never replay
the input. The next action requires an actual completed effect. An idle Sit
reset uses the original input owner's `idleReset` evidence, rather than
inventing an active-to-inactive restoration.

The plan contains ordinary verbs and inputs only. Expected animation, requested
Sit variant and acceptance predicates stay in the runner. Common's 28 nominal
steps expand to at least31 and at most169 actual calls: each of the three Sit
checkpoints uses normal Cancel/Sit pairs, at most24 attempts. Missing observed

New owners are strongly retained before descriptor construction. Failed or
unknown writes remain owned and cannot authorize replay. Host finalization
closes only verified original descriptors and preserves all journals; it is
not source, Actor or whole-feature retirement. Parent2 rejects cold adoption.
Historical Parent1 reopening is unchanged.
