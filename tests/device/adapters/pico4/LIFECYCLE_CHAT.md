# Original normal Chat draft after Create Back

`pico-lifecycle-chat-owner:1` adds an owned normal Chat draft to the partial
Lifecycle journey. `_lifecycle_chat_editor(target, run)` binds the existing
normal Chat controls and an independent original Lifecycle UI reader to the
actual candidate/process and exact same Script source-lock instance as World/X.
`_lifecycle_chat_draft` advances only unissued phases; issued phases reconcile
their original effects without replaying normal input. No new catalog group or
complete `feature.lifecycle-input.*` capability is advertised.

The original X join must already be observed. Its exact private archive hash is
bound before normal Chat input. A fresh original source must still show Home,
the original Create field/page gone, no focused editor and the real released
VR keyboard. The original surviving Create context stays retained. The owner
does not toggle another tablet, invoke a handler or silently close a foreign
page. Chat starts from the actual shown Home produced by that original X.

Normal CHAT entry, pointer focus and native IME Reply replacement reuse the
existing `TokenChatUI` and `PicoChatIO` routes. The stable normal interfaces read
version 1 or 2 in the integrated adapter; no shared Chat control code is changed
by this packet. Each native reference, scope, token, intended action and actual
consumed cursor is persisted privately before another input can proceed. Only
Home/CHAT entry and Chat field activate/replace are admitted: there is no Send,
Return, Erase, channel switch, storage write or Settings-format assumption.

The empty new Chat field is independently observed before focus/type. Its
original field/page/context identities must differ from Create's and from the
initial inventory. Generation 2 names that actual current owned Chat context,
including its opened/unfocused state; focus does not create a generation.
Normal focus must agree with the original passive Qt source and actual native
VRKeyboard visibility. This run's Reply must agree across both original field
sources on the same context. Actual channel/row counts/source digest remain
unchanged across the draft. These visible facts are not a delivery, storage or
network-quiet verdict.

Before any field input, the independently measured current Chat identity is
checked again inside its durable intent, before transport. A replaced source
cannot inherit the owned Reply, even if replacement occurs during normal
reference acquisition. Existing backend token/weak-object admission still
protects the subsequent original normal input. Lost entry/IME replies may only
read the original consumed cursor and original same-context effect. Ignored
focus, requested keyboard state, an ACK, wrong text or a new alias of an old
context cannot qualify. Original raw UI bytes/SHA, reference snapshots, X hash
and all owner journals remain private and retained. The final result is built
before the last candidate guard and native/monotonic freshness checks.

Host tests execute the real editor/World/X/Chat owners, token readers, source
lock, private storage and input session over explicit widget, native input,
keyboard and physics boundaries. Actual Qt normal input has separate focused
compiler checks; this packet changes no native source and establishes no device
run. Background keyboard/focus release, Scripts/pending/stale generations,
second movement, independent peer/image proof, normal original-state restore
and complete resource/process closure remain unfinished. The current reader's
foreground guard is preserved; no background VR keyboard fact is inferred from
an unavailable foreground-only query.
