# Pure host retention for Background3 raw storage

The original generic Pico cleanup now checks the explicit Background3 raw
family before any target query, ordinary input or base application stop.
The root, rootless range parts, index pages, pending and unknown suffixed names
all retain responsibility. A broken symlink is retained without opening it.
The bounded scan validates the actual canonical private target directory and
never parses, adopts, removes or rewrites an unknown original.

Constructor-error cleanup closes only known original host owners. A false or
raising close retains that actual owner strongly under its exact namespace.
The namespace stays blocked even if no raw journal was committed. A recycled
foreign descriptor is never closed; no later cleanup call can infer retirement
from the absence of files. The original construction failure remains the
caller's failure. Process finalization remains responsible for uncertain host
resources. This does not retire any target collector, source or application.

The existing Background1 path and its historical interpretation are unchanged.
The post-stop diagnostic also recognizes the new raw names. These host fences
do not enable a Storage3 writer or qualify a source, whole seven-action flow,
complete Lifecycle feature, Native binary or device.

The disjoint five-case `lifecycle-background-raw-retention` selector executes
the actual canonical cleanup and real Linux descriptor checks. It covers
root/rootless names, a dangling part, known closure, a genuine same-inode
recycled descriptor half and raising close ownership. The foreign handle stays
open and every refused generic cleanup performs zero target/input/base-stop
operations while retaining original files. Source/FD ownership checks run
without a compiler or device.
