This is a source plan after the actual
[sixteen-action primary result](LIFECYCLE_OPERATIONS_RESTORE.md), not an
executed cleanup, new-source qualification or public capability. No protocol
or runtime change is made by this plan.

## Existing authority to reuse

`PicoLifecycleProcessRetirement.observe()` already retains the actual G1
NativeFeature, presence, domain, UI, gesture and drive reader instances in
`_final_delivery['readers']`, and the same NativeFeature source in `['source']`.
`run_lifecycle_restart()` calls `final_delivery()` after its real outer lock
exit. It checks the original result/disk hashes, current candidate/source
guards and original native/monotonic clocks. This memo can be a warm handoff
authority; `next.frames` alone cannot construct or resurrect a live reader.

`_lifecycle_restore_restart` already connects original Prepare, RestartInputs,
normal stop/launch, recovery and Process observation. `require_stop_ready`
checks the exact just-completed Prepare under its original1.5s ceiling.
Neither it nor `prepare_inputs()` adds a World triple. `RestartInputs.capture`
does acquire a distinct NativeFeature birth packet; it must not be counted as
a World triple or hidden from the Native-query/original bill.

The current default app-stop/app-launch transport is not yet a final
Lifecycle-phase-fenced once-only transport. `launch_debug_app()` can also
force-stop an unexpected running process and reset the host session. The new
coordinator must not inherit that as recovery authority. Existing
`PicoChatRestartIO.stop/launch` already provide the needed neutral primitives:
one SDK command, original candidate/PID/profile checks, final `before_input`,
no repair/retry/discard, and an actual `OriginalBindingTransfer` holding the
original cursor/FDs. Reuse those primitives rather than invent another input
channel; do not invoke its Chat-profile queries as Lifecycle evidence.

## Proposed closed version boundary

Keep World2, Process2, Source1/2/3 and their formats/operations exact. A new
coordinator version3 would add its own cleanup intent/phase and live handoff;
existing roots remain retained and cannot be migrated into a new live owner.
The later cleanup observer needs an explicit new source discriminator rather
than rebinding Source3's old PID or resetting its record array.

The closed handoff scope must pin:

- the exact live operations/source/process owner objects and same source lock;
- original run/v16/fixture URL and independent actual cleanup activation prefix;
- G0 binding and its exact last externally returned Source3 original/cursor;
- the actual successful Process result, same memo object, disk identity/hash,
  G1 binding and exact retained reader/source instances;
- actual installed candidate, native process birth and original old-PID/start
  absence proof, distinct from app-stop ACK or Android process-list absence;
- original age anchors through final parent CAS and actual outer lock exit.

At the handoff boundary call the existing actual final-delivery checker;
copying metadata must precede its final clocks. Cold/missing/changed memo,
foreign objects/binding, lost final save or late exit refuse without input
replay. No new source packet or clock read may renew that original admission.
Later current observations must make genuine fresh G1 acquisitions. The
retained last Process originals serve only as continuity floors.

Global observation sequence must derive from the exact consumed Source3
cursor (71 in the measured result), so the next actual external observation
is72. There is no caller offset, replayed private observation or cursor reset.
Measured World/stale counters remain original event history, as the unchanged
common cleanup already requires; new UI/keyboard/pose/resources come from G1.

The existing readonly acquisition already aliases the exact original
`PicoLifecycleWorld.acquire/originals/now/fresh_current` bodies and owns no
state/save/input. Its present constructor is specifically bound to an old
World with separate initially empty readers. A typed post-Process entry would
instead pin the actual retained G1 readers and their complete original floors.
It must not mutate the old World or create another mutating World to evade a
cap. Its complete new originals belong in the existing immutable chunk/bundle
machinery under the explicit new source scope.
