# Normal Pico tablet close and fresh Navigation frames

These are internal source/host components. Scripts, Authentication and Graphics
remain the three complete source/host areas; the other eleven full areas remain
unavailable. No Navigation operation triple is registered. All native code is
uncompiled and devices untested. This packet adds no native instrumentation,
product behavior, new capture transport or second test system.

## One owned normal controller close

`navigation-tablet-close` v1 (`_navigation_tablet_close`) follows a completed v2
[Navigation transit](NAVIGATION_TRANSIT.md) on the same original manager, binding
and explicit `script-sources.lock`. The parent must already own the Home tablet
and original transit. The owner refuses legacy QML Home history or an unrelated
input session. It records the original pre-close source group before calling
`PicoScriptIO.tablet(False)`, which uses the existing normal Pico/OpenXR
`tablet.close` controller route. It invokes no private handler or property setter.

The original Home instance/tablet/entity must match the actual transit Home
proof. Independent sources must agree: original Qt UI open/ready/generation,
weak Places/Go To root retirement, actual native pose, unchanged native bookmark
map/file, actual Home entity state and passive generic VR UI. The normal physical
close leaves the separate Qt control-command count unchanged and changes the
actual open-state generation. An acknowledged controller command alone proves
neither close nor cleanup. Keyboard/editor focus, retained foreign generic/menu
roots, a replaced Home entity or a live Navigation page refuse input/success.

A missing command result leaves phase `closing` owned. Recreating the owner
observes the original close effect without another toggle. An ignored command
stays unresolved; it is never resent. Success requires three seconds with seven
normal half-second samples, unchanged destination/bookmarks/input/generation,
actual closed UI and advancing original Home, generic UI, native pose and Qt
wall/elapsed clocks. Gaps over 1500ms and changed roots/storage fail closed.
Historical before/current/quiet source groups and unique query IDs use the
existing bounded private CAS history. At most 81 close-effect observations fit
inside the 20-second action deadline; journals retain at most 1024 queries.

The owner proves this post-transit tablet close. It does not infer retirement of
all QML loads, XHR, Scripts, Web callbacks or metadata, or implement the later
Go To/end-of-journey page closure. Those remain explicit enclosing obligations.

## Passive fresh original frame publication

`navigation-frame-publication` v1 (`_navigation_frames`) requires an already
completed normal-close owner. `read` performs only passive observations and
one explicitly owned world acquisition: it never invokes `close`, opens/hides UI,
stages a controller input or repairs a page. Visible or replaced UI fails before
capture. The publisher accepts no image policy, desired location or expected
feature state. Its result is internal source data, not the full Navigation
state/resource/actor projection.

Before acquisition it durably allocates an independent `journalId`, frame
sequence, current action ticket, original close digest and original closed
source group. It then uses the existing [v2 stereo owner](NAVIGATION_STEREO.md)
and actual original GPU/camera/OpenXR/file protocols. Each acquisition retains
its own `navigation-<run>-<role>-<journalId>.native.json` and exact original PNG.
The original native buffer/callback and complete issuer-file retirement must
succeed before publication. Both `primary` and `actor` use separate role owners,
source journals and acquisition nonces under the same existing source lock.
This does not by itself supply the full independent Navigation actor service.

The common verifier and publisher share pure original source clock/cursor
extraction; pixel measurement remains independent in the external common
Journey. Native/UI/subject/probe/camera/acquisition/submission cursors advance,
original source births/generation stay pinned, and original render IDs and all
seven source query IDs cannot be reused for a different published frame.
Current original pose must still agree after capture. The oldest original
source epoch is retained, with a maximum age of 1500ms after persistence and a
20-second read/history-validation budget. No screenshot is retimed.

The CAS publication journal retains at most 128 original records. Every record
reopens its original metadata and PNG, checks the exact raw metadata SHA-256 and
original body/file/retirement identity, and reconstructs source facts. Private
file reads reject symlinks/hardlinks and nonregular or changing files. Altering
only JSON whitespace still violates the pinned original metadata identity.

The internal `after_sequence` tracks this publisher, separate from an enclosing
feature's observation cursor. The current cursor allocates a new source. The
immediately previous cursor can recover a lost publication by returning the
same still-fresh original sequence, epochs and artifacts. It sends no second
capture. Older cursors and stale competing CAS holders fail before acquisition.
An uncertain capture keeps the same pending identity/native owner; it cannot
be replaced with another request. A known completed source rejected for stale
source clocks/cursors or metadata also remains pending for the enclosing finalizer.

The result contains measured location, original lifecycle/oldest epoch, source
sequence, artifact declarations, journal identity and the independently acquired
closed source group. It does not invent missing error, search or actor fields.
Historical source artifacts remain available for independent review; retiring
active ownership/indexes is a separate unfinished whole-feature obligation.

## Verification and integration limits

Host tests execute original Python normal Pico navigation/controller dispatch,
private CAS and PNG files, original source owners and complete native receipt
protocols. The same common external two-eye verifier checks original PNG and
journal artifacts for both source roles. Counterexamples include ignored/lost
close, foreign Home/page/focus/input, changing bookmarks or clocks, reopened UI,
lost publication/acquisition, stale originals, changed metadata/PNG, competing
publishers and replayed original render identity. Qt/HMD/GPU/OpenXR/OS/native
sources are synthetic. The synthetic producers use their advancing native
boundary clock before observations; acquired originals are never rewritten.

The shared source helper refactor changes no existing v2 wire shape or pixel
policy. New private contracts are versioned independently; default/legacy
Navigation, Graphics and Phone/iOS producer contracts remain readable. The
52-group Pico catalog and full-capability advertisement remain unchanged.

Full Navigation still needs independent state/actor/public composition, actual
normal page setup and Go To lookup/closure, maturity/origin/scene restoration,
original restart/bookmark transfer and complete Script/XHR/Web/timer/callback/
active-metadata retirement. The source and selected host evidence are privately
backed up; integration remains exclusively on the own isolated local branch.
