# Original Graphics role observer v2

The neutral [`GraphicsObserver`](../graphics_journey/observer.py) reuses the
frozen Phone role transaction architecture, with exact Git-object provenance in
[`FROZEN_REFERENCE.json`](../graphics_journey/FROZEN_REFERENCE.json). It composes
the original owned fixture reader, Pico stereo sampler v5, paired immutable PNG
and metadata files, native receipt retirement and original per-eye effects.
There is no ordinary UI input, fixture activation, requested-state projection
or primary-observer forwarding in this owner.

Each role has its own durable baseline/current frame, source histories, off
frames and effect records. Private frame references preserve bounded state;
loading a reference validates its original hash, role, stage and both original
file identities. Recreating an uncertain reading owner cannot start another
capture. A separate actor capture publishes only that role's independently
measured projection through the existing fixture journal protocol. The complete
feature coordinator must authorize phase/process entry while holding the shared
source lock; this internal class is not a public operation or actor dispatcher.

Marker readiness permits at most sixteen fresh measurement attempts within
twenty seconds. Only a rejected owned code with independently retired native
buffer/callback/receipt ownership may retry. Unknown UI, missing/corrupt files,
foreign context and incomplete retirement keep their actual failure/ownership.
Every retry is a new original GPU acquisition; no product input is resent.

Effects have distinct pure historical and live APIs. Archive decoding recomputes
original per-eye effects without a synthetic current clock or guard. Live
comparison additionally verifies actual current time, guard and elapsed budget.
An ignored native Haze pass is reported as observed; it cannot become an off
baseline for a later effect claim. Original restart observation still requires
old/new native lifecycle continuity and qualified original old-PID absence;
normal restart input and new-process framework restoration remain separate.

Selected host tests exercise the actual sampler, file owners, fixture journal
and independent verifier at synthetic native/UI/GPU/OS boundaries. No native
compilation, physical input/rendering/timing or device qualification is claimed.
The full feature coordinator, actor dispatcher, normal background/restart and
combined UI/QML/XHR/HTTP/Web/scene/capture quiet cleanup are still required.

The v2 role journal retains its explicit v1 baseline reader. On a Pico process
restart the actual native NavigationUi bridge UUID changes, so the original
new binding must have a distinct canonical bridge UUID with the same candidate,
target and current zero-valued host generation. Stage transfer preserves old
frames and independently requires new native birth/capture and old-PID absence.
It never copies the old GUI bridge into the new process. Legacy preserved-session
restart receipts remain a separate v1 reader; the Pico producer uses the
explicit `pico-native-qt-bridge-v1` receipt policy in restart-proof v2.
