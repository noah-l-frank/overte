## Intent and final publication

One canonical `lifecycle-primary-operations.json` owns full original phase
packets in existing immutable chunks/bundles. Its version1 scope pins run,
binding and fixture URL. Independent phase responses must retain the exact
activation prefix/ticket and next expanded recipe verb/inputs. A durable
parent `issued` row precedes the child operation. Existing root or orphan
ownership refuses construction; it is never adopted as a live input owner.

The initial primary baseline precedes installation of input callbacks. Only
after the first durable parent intent are typed optional fences attached to
the exact Editor, World and X owners. Existing defaults/layouts/codecs remain.

- Editor marks before each existing child intent CAS. Its one final normal
  Create/field callback checks owner freshness, independently rechecks phase
  after the child write, then checks original host age before Qt publication.
- Tablet/World/X recheck phase after outer intent CAS before the session lock.
  The existing locked intent durably saves the exact envelope. Only original
  host-age/equality checks run there and in final `before_publish`; no HTTP,
  ADB, source guard or session reentry is added inside that lock.
- World release marks/rechecks outside the session. After the existing locked
  release CAS, original host-age checks precede exact owned grant removal.
- Observe retains fresh phase before and after the new Source3 acquisition;
  its final Source3 guard/clocks run after actual outer lock exit. Act delivery
  also checks its original post-action phase/clock after that exit.

Failed lock exit, phase, final clock or uncertain publication latches the live
owner. Even a landed `returned` row is not success when later delivery fails.
Original journals remain owned and a repeated call cannot resend input.
Pending's separate callback ownership is untouched; later integration must
extend its existing responsibilities rather than replace its callback.
