# Original Pico Emote effects

`PicoEmoteEffects` v1 joins [durable ordinary inputs](EMOTE_INPUTS.md) to
[original role-specific sources](EMOTE_SOURCES.md). The private Pico factory
requires the actual primary input/source journals, target binding and shared
source lock. An actor may use its separately owned current source; primary
before-input originals provide causality and never become actor effect facts.
The implementation is selected from the fixed committed Phone architecture;
[the provenance manifest](PHONE_SHARED_EMOTE_EFFECTS_20261022.json) records exact
source and target hashes. Phone background policy is excluded.

## Measured behavior

Playback requires the actual separate Pico Emote compilation/caller, original
manager membership, requested and consumed FBX identities, advancing loaded
clip evaluations and changing final joint poses. Normal selected names must
match the measured native asset; Sit variants come from the original loaded
resource. Replacement also proves prior restoration and a new native override.
An ignored click or highlighted chooser cannot provide that proof.

Natural completion and cancellation reopen the original qualified playback,
then require actual native restoration. Early cancellation additionally uses
the original pre-click native barrier and native/caller time before the nominal
clip end. Idle reset has a distinct result and cannot supply early restoration.
A still-active native override after cancellation remains pending; it is never
reported complete from the input receipt.

An open/close effect follows the actual controller visibility generation edge,
original Qt command cursor and unchanged process/bridge. Baseline and cleanup
idle phases require actual native graph/animation readiness and inactive
native override without fabricating a normal input journal.

## Freshness, replay and limits

Current measurement reopens immutable original files, verifies durable owners
and the current fixture ticket, and includes final guards and both actual clocks
in its 1.5-second freshness and five-second operation bounds. It does not query
or input during fact derivation. Archival contexts recompute history without
native I/O and cannot acquire current measurement authority. Changed originals,
foreign callers/assets, frozen poses, changed phase and slow final guards fail.

The owning `emote-original-sources` group includes eleven effect counterexample
cases on real Pico host owners with explicit synthetic Qt/OpenXR/VM/Rig
boundaries. `normal-emote` exercises the private factory including separate actor
source selection. These checks do not qualify actual playback, GPU pixels or a
device. Existing native component compiler checks have their separate limits;
no complete app/APK build is established here.

No complete feature capability, image/actor publisher or resource release is
added. Whole-run three-Sit behavior, actual Pico background continuation,
current original two-eye avatar evidence, independent actor publication and
callback/timer/Qt/native retirement remain required. Journals remain retained.

The [original manager work source](../../native/SCRIPT_WORK_OBSERVATION.md)
now supplies selected real timer/callback origins through the existing Pico
private native observer. [The fixed selection manifest](PHONE_SHARED_SCRIPT_WORK_20261022.json)
records shared source provenance. The native queue/body test uses real Qt5
objects with explicit manager/engine seams. Whole Emote lifetime and final
