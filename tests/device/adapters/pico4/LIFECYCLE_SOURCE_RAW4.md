## One journal and two restrictions

SourceRaw4 is selected explicitly before the first getter. Its scope is
`lifecycleSourceRawVersion:4`, role `lifecycle-source`, the original run and
binding. It uses exactly one existing `AudioRawArchive` journal1 at
`lifecycle-background-raw.json`, the exact original Namespace/SourceLock and
the shared raw-range verifier. Background roles remain UI/Gesture/Drive/
Background/Feature; the additional Pending role is limited to the original
32768-byte literal maximum. Other roles retain 256KiB. There is one shared 512
read count,512-part count and 16MiB bill, including actual metadata, namespace,
pending reservations, decoded DTOs, temporary range batches and CAS overlap.
There is no new quota, reader reset, old-clock retiming or live reopening.

Before its first namespace lease, Raw4 binds an identity guard to the original
Namespace and its unchanged expanded-state callback. The SAME actual callback
result is size-preflighted and must contain each registered family writer's
actual state object by identity. Missing, deepcopied or stale equal states do
not count. The guard traverses only that already-bounded graph, never calls
the callback twice, and cannot be replaced or resealed. A family state may be
None only before its first publication. Every view/family registry remains
bound to the original exact objects; removing a registry entry cannot remove
the corresponding state from the bill.

SourceRange4 contains the explicit role and existing original journal range
reference. Every acquired literal within its admitted role limit, with its
original clock/command/physical receipt, stays in the journal, including
rejected source responses and uncertain transfers.
Background and Pending views each have an immutable confirmed tuple and a
separate provisional projection. A Pending projection may reuse an actual UI
range in that same pool. A Background view cannot reinterpret a Pending
range. A projection holds the exact acquired graph before any guard or budget
can fail. Mutating a projected cost cannot reduce the recomputed bill;
replacing/dropping a held graph or cost seal is refused and retains originals.
No subsequent query is allowed while a projection or family permit is open.

preflights its complete physical namespace, validates every recorded range,
