# Normal World Web source prefix

Feature 6 remains partial. `PicoWorldWebPrefix` composes the first thirteen
unchanged common v16 steps: normal Script load/open, ray/IME Unicode input,
Send, Clear, B/Back, foreign-origin navigation/message/Back and actual
404/reload/server-restoration/reload. It does not implement a second Journey
or expose public feature operations. The final reference navigation,
background/return, final text/message/Clear, normal Close, independent actor
publication, stereo/scene joining and whole resource/archive retirement remain
unfinished.

The private `_world_web_prefix` factory uses the original Script source lock
and target-specific `world-web` namespace. It reuses `NormalScriptManager`,
`TokenScriptUI`, `PicoBrowserScriptIO`, original `NativeNavigationIO` and the
existing Session intent/publish hooks. Home/3D Tablet entry and normal Running
Scripts URL/submit/close controls execute before the world page input. The
unchanged fixture `client.js` creates the world Web Entity; its optional tablet
WEB TEST button is not the world entry route. Every child input has an original
parent phase/input intent before delivery, with the exact current fixture phase
checked again after private CAS work and immediately before publication.

The normal Pico URL-field grammar previously accepted only a ticket's
`missing.js` under `/feature-fixture/`, although the existing normal manager
already admitted the World/Tablet ticket `client.js`. The E2E-only navigation
extension admits that existing client grammar only after binding the exact
parent-owned URL, including scheme, authority, run and ticket. The last check
before writer preserves that exact binding. Generic navigation, ordinary
`script-management` clients and the previous missing-script path keep their
existing restrictions. No product URL or input transport acceptance changes.

The page action uses the existing `PicoWorldRayClick` and `PicoWorldTextInput`
owners. Tracking calibration, entity geometry, actual hit/focus, pre-IME text,
original command, and post-IME text are retained independently. A Session
acknowledgement cannot manufacture focus, edited text, a Script engine or a
page request/reply. The Script/compiled-code/HTTP/three-QObject source uses the
existing original `PicoBrowserVm(surface='world')` and pinned world code.

Every observation independently reads current original native feature brackets,
world DOM, runtime/renderer inventories, HTTP receipts and normal diagnostic
Script rows. All fifteen common world state fields are derived from those
sources. Primary and actor roles retain separate original requests/cursors,
VMs and immutable source chunks; this private prefix does not yet run an actor
process or publish actor facts. It emits no image artifacts. Existing world
stereo ownership and the common image policy are not bypassed or relabeled.

The unchanged shared history/chunk mechanism has an explicit `world-web`
profile with a distinct `picoWorldBrowserHistoryVersion: 1` discriminator.
The default tablet profile keeps `picoBrowserHistoryVersion: 1` and its old
wire shape. The prefix now writes `picoWorldWebPrefixVersion: 2`; its v1 reader retains
the previous exact three-step limit. The v2 parser admits only the original
closed nineteen-step v16 recipe, while actual input dispatch stops at thirteen.
Opening an existing v1 ready owner preserves its bytes until the next explicitly
authorized ordinary action; the normal mutable owner CAS then writes v2.
Historical immutable source chunks are never migrated or rewritten. Both
private DTOs are registered separately. The common v16 contract is unchanged.
Historical sample validation joins the selected surface's actual sources and
its existing world-specific VM scope; it never queries the target as history.

Observation/source files are pinned with the existing `ClosedOriginalFile`
reader: exact original bytes, full dev/inode/mode/UID/link/size/mtime/ctime stamp,
and actual descriptor closure. Action and observation publication occur after the actual outer
source-lock exit, revalidating current owner, physical files, process/candidate,
exact independent phase and actual native/host clocks. An unresolved applied
input retains `acting`; cold reads cannot replay it. `PhasePending` is published
only after that same final join, outside the original lock. The shared lock's
exception behavior is unchanged.

Before reservation, all existing foreign shared capture stores must be empty:
original default world render, browser and emote captures for both roles, and
both graphics-role render stores. This prefix acquires no render capture.
The existing `_world_web_retained` guard already blocks ordinary global cleanup
when any World owner or rootless original remains in its namespace. No owner,
chunk, journal, Script, Web Entity, VM or timer is retired by this prefix.

The owning `world-web-prefix` selector exercises actual Python factories,
normal navigation/Session delivery, loopback HTTP bytes and immutable physical
originals. Qt control consumption, V8/Script engines, Android IME/runtime, OS
identity, tracked controllers and native Web sources are explicit host producer
seams. No device, HMD, GPU pixel, complete client or whole feature claim follows.
Initial rejected runs and first exception chains are retained separately from
successful sources; no original packet was retimed or overwritten to pass.

The next executable extension is final reference navigation and actual
