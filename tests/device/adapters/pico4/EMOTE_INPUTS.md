# Durable ordinary Pico Emote inputs

`PicoEmoteInputs` v2 joins normal `open`, `play`, `sit`, `override`, `cancel`,
`wait-complete` and `close` inputs to the existing original phase reader and
[Pico original sources](EMOTE_SOURCES.md). It remains a private component:
`performed` means the input was handled, never that playback, pixels or release
have been proved. It advertises no complete feature capability.

The durable phase, intent, receipt and immutable archival design is selected
from fixed Phone commit `abb7f6b60d97daf17752aadf94e2b5df099bb7ba` and documented
in [the selection manifest](PHONE_SHARED_EMOTE_INPUTS_20261022.json). Actual
The canonical `PicoOpenXrAdapterSession` controller path and original
`PicoEmoteIO`/`TokenEmoteUI` pointer transport replace the Phone SDK/UI boundary.
The private factory requires the actual primary source journal, shared source
lock, candidate/process/VR binding and original existing input session.

## Original input ownership

A new call is tied to its actual closed fixture ticket/verb/inputs. Each Qt
pointer or scroll intent is saved before delivery. A play/cancel intent first
acquires and retains a fresh original source barrier matching the exact UI
control/token. Cancel additionally requires the original active chooser name
and native active Rig. A native Qt receipt joins advancing source cursors and
the actual original command sequence; it does not claim a playback effect.

Each tablet controller operation similarly retains an original before-frame
and writes `issuing` before the existing OpenXR transport. Its independent
after-frame must show the actual visibility edge and newly observed generation
while Qt command sequence and process/bridge stay bound. Neither a transport
ACK nor a requested target visibility is substituted for that original source.

Lost delivery/receipt, ignored effect, changed tokens/context and missing source
response retain the original journals. Reconstruction cannot repeat the input.
An already acknowledged identical call can report input idempotence without
delivery; independent current effect observations remain mandatory.

Completed input records use private immutable originals and bounded manifests.
`recover_archive` finishes only exact frozen archival bytes and matching
manifest prefixes. It invokes neither product input nor a native read and
returns no current observation. Incomplete source acquisition retains its own
responsibility independently. Neither operation retires journals.

## Host checks and remaining composition

The owning `emote-input-effects` group tests normal open/play/cancel/close,
actual controller-generation transitions, ignored/lost Qt and controller
boundaries, missing original sources, archival recovery, fixture/candidate
changes and historical replay. `normal-emote` also verifies the actual private
Pico factory and retained input ownership after base process teardown.
Qt/OpenXR/Rig boundaries in these device-free checks are explicitly synthetic;
the actual native component compiler checks remain separately qualified.

One counterexample deliberately leaves the synthetic native Rig on its older
Waving override after consuming a Crying click. Input acknowledgement contains
no effect state and cannot satisfy the independent playback measurement.

The [original effect join](EMOTE_EFFECTS.md) now supplies measured playback,
natural completion, early cancel and replacement. The complete owner still
needs interruption/background recovery, all Sit variants, current
two-eye images, independent actor and actual callback/timer/Qt/native-resource
retirement. General teardown retains both source and input journals and refuses
success while they remain. No application build or device qualification is
established by these host results.


## Version 2 exact controller ownership

Each controller intent now retains the exact canonical session nonce, sequence,
command ID and normal1000ms tablet operation before transport publication.
The callback runs under the original session sequence lock and performs only
private host CAS/fsync and elapsed-host admission checks. It never reenters
ADB, candidate guards, the PhaseReader or the controller session. A slow writer
with a frozen native clock refuses before publication; the uncertain original
envelope remains owned without resend.

A separate original require_owned_neutral query must identify that exact
stream before an independent after-frame can acknowledge visibility. Missing,
foreign, active or future neutral packets refuse. Original streams retain one
nonce and strictly advancing sequences across immutable input archives.
controller_retirement reads the last exact stream again after a normally
acknowledged Close and a fresh original closed-tablet frame. This supplies only
controller retirement, preserving all journals and all other cleanup duties.
Call it before a later View-restoration stream changes the canonical cursor.

Every Qt input, including entry/scroll, now retains its own full original source
barrier. Final exact fixture-phase/native-age checks include intent persistence
and guards. The controller envelope CAS additionally uses the original combined
native/host anchor while the transport lock is held. Oldv1 input owners stay
retained and are rejected byv2; later queries never invent original envelopes
or grant them new stream authority. No whole Emote capability is added.

The original source/storage checks stay in `emote-original-sources`; manager
work and lifetime checks are now `emote-lifetime`. The two added selectors
retain every previous case under the unchanged120-second per-group limit.
The combined source group exceeded120 seconds, including after the initial
lifetime-only split; no failing or slow case was omitted. Selector counts are
test partitions, never completed feature counts.

## Final original QML publication fence

The actual Pico factory forwards one owned `NativeNavigationIO.before_send`
callback to the existing QML transport. It compares the final command's original
control, token, bridge, generation, sequence, elapsed reference and direction
to the already durable input intent. Only then does it check the exact active
fixture ticket/prefix and combined native/host source ages after internal
navigation guards, immediately before the existing single writer. A phase or
native-age change at this boundary leaves the original issuing record owned
without publishing or replaying the input. The canonical controller intent
callback remains host-only. These are admission checks; actual Rig, pixels,
actor and resource effects still require independent observations.

## Actual controller publication admission

The normal Emote controller operations now pass a pure host `before_publish`
validator to the original canonical Session/Android transport. It compares the
already durable exact envelope and original host journals, then checks the saved
native/host anchor age after the original SDK guards and again before native
grant commit. It performs no second intent CAS, phase/native/SDK query, guard
or session reentry. Late SDK work cannot publish an expired input. An uncertain
original remains owned without resend. View's ordinary Home-ray uses the same
optional forwarding; the default shared Home/controller paths are preserved.
Five focused owner checks pass3.992s, including late transport refusal under a
frozen native clock, host-only callbacks, ordinary open/play/cancel/close and
all six setup/restoration streams with independent neutralization. Synthetic
transport boundaries remain explicit; original SDK serialization/publication
checks are separately covered by the real transport's device-free tests.
