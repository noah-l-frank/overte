## Prefix 2: reserve raw bytes before acquisition, decode afterward

Before native/Stage send and before each actual getter, including another poll
of the same query, `AssetsRawArchive` reserves one bounded literal read.
The guarantee covers up to 4 MiB UTF 8 bytes in at most 64 binary leaves, complete
metadata/root/overlap bounds and the actual prospective 64 KiB root. Existing
reader semantic limits, including smaller file/upload limits, are unchanged;
retaining an invalid literal grants no semantic admission.

Each admitted literal is written unchanged into<=64 KiB readonly
`.child-raw-<read>-<part>.bin` leaves before parsing or another query. Binary
storage avoids JSON escaping amplification. Writers use existing original FD/
independent kernel-alias ownership; immutable readers use `ClosedOriginalFile`
windows under the exact original directory OFD. Recycled same-inode writer/
directory descriptions and identical replacement files are never adopted or
force-closed. Current physical identity and original bytes remain checked.

For multi-part copies, expected complete byte count/SHA are saved before the
first part. Single-part copies already have durable reading/query intent. A
verified final root CAS seals compact full physical references, their exact
receipt and cleared pending read together. Names derive from original root/
read/part; compact rows retain byte counts, part/full SHA and all eight physical
fields. Scope/request/phase/original clocks stay unchanged. Fact-free archival
does not query a candidate or renew authority; death after response still
preserves that response.

Only **after durable literal sealing** is exact escaped JSON/history capacity
preflighted. `quoted_bytes` computes ordinary ensure-ascii size without
allocating an expanded string. An actual 4 MiB NUL literal is retained exactly,
then its>24 MiB quoted form refuses before the native parser. Insufficient raw
capacity refuses getter/send before acquisition. Failed scopes never retry,
reset cursors or increase limits.

Actual raw leaves, including uncertain partial leaves, source metadata, nested
decoded child originals, packed child root copies and still-owned source
histories are charged. Limits remain 512 frames/parts,16 MiB decoded/stored and
64 KiB per root. Archival comparison reuses admitted root serialization while
rereading current full raw bytes/OFD/eight-field identity; candidate guards are
separate and unchanged. UI input references/fixture phases are validated DTOs,
not falsely labelled transport bytes. Dedicated UI source reads are literal.
The guaranteed read window is 4 MiB; unbounded returns outside it and arbitrary
parent-host/storage-owner death are not claimed.
