# Owned normal Create draft, first gesture and X

`pico-lifecycle-editor-owner:1` persists the first normal editor segment in
`lifecycle-editor-owner.json`. `_lifecycle_editor(target, run)` binds the actual
candidate, original process, normal navigation bridge and OpenXR input session.
Its independent Lifecycle reader and existing Create/field controls share the
same `PicoScriptJourney` source-lock instance as World and X. The owner adds no
new input transport, catalog group or complete Lifecycle capability.

`prepare()` requires a hidden tablet, no current editor and an actually released
native keyboard. `tablet()` journals the exact ordinary `tablet.open` envelope
before transport, requires the original session's neutral receipt, and separately
observes shown Home with no editor/keyboard. This receipt establishes input
ownership; it is not proof of client button consumption or a visible tablet.
An unexpected restored page remains unavailable. No callback or Home handler is
invoked to manufacture the desired route.

`open_create()` uses the existing normal Home/CREATE/tab controls. Each actual
normal input reference and subsequent consumed bridge cursor is retained before
another input can be issued. The original empty Create editor and separate
normal-control field/page/context/window identities are frozen. `focus_create()`
uses normal pointer input and requires actual focus plus the separate native
VRKeyboard observation. Only then is generation 1 reported. `type_create()` uses
the existing original native IME route for this run's closed Unicode fixture.
Actual field text must agree across the normal control and independent original
Lifecycle source on the same objects. No entity creation or Submit is exposed.

All normal input intents precede transport and use private CAS/fsynced storage.
An uncertain tablet, Create click, focus or IME operation stays issued. Recovery
reads the same original cursor and independently observed effect; it never
repeats the input. Cursor consumption without actual focus/keyboard/text cannot
advance the owner. Replaced field/context identities, changed bindings, failed
writes and stale observations fail closed. Original raw Lifecycle JSON and SHA,
normal references, input cursors and all owner journals remain retained.

`_lifecycle_create_world_back(target, run)` composes this owner with the existing
World and X owners for the first shared journey segment. World freezes its
baseline before opening the tablet. The first world envelope requires this exact
original typed editor and an original UI query strictly after the typed source.
Only an actual original Pico override `started` publication counts as a world
attempt. Effective held input and three-dimensional feet displacement come from
the independent actual avatar reader. Original client neutral and three seconds
of stable feet precede the ordinary X press. Current editor/text/generation 0
after X are derived from fresh original Home/no-editor/released-keyboard facts.

After X, the editor journal's typed snapshot is historical. It is not queried or
reported as a current draft during recovery. The current result comes from the
World/X join, which retains the original weak Qt flags. A surviving original
QQmlContext remains `retainedContext=true`, `editorRetired=false`; a disappeared
field/page cannot retire it. Process-owned retirement is a separate proof.
For a later controlled restart, `_lifecycle_process_begin` must run before this
segment so its original settings/avatar/domain baseline precedes every input.
This segment does not create that baseline after the fact.

The device-free owner tests execute the actual token readers, owners, private
stores, lock, input session, gesture/drive/UI validators and recovery over
explicit UI, native input and physics boundaries. Separate actual Qt5 checks in
[the draft packet](LIFECYCLE_DRAFT.md) verify the real normal pointer/IME path.
Neither establishes a hardware run. The full journey still needs Chat/Scripts
generations, original pending/stale dispatch, background/resume, second world
motion, independent peer/image proof, normal original-state restoration and
complete final owner/process/file/lease closure. No journal is retired here.
