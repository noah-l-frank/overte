# Shared original-source Script coordinator

This package extracts the complete source-bound v16 Script flow from frozen
Phone commit `fe4684bf46585088370b3a328a738f147e670b97`. See
[original module hashes](PROVENANCE.json). It supplies shared control logic,
not a platform transport, acceptance verdict or device qualification.

`ScriptFeature` joins `ScriptActions`, durable original source history,
five-source observations, original fixture HTTP receipts, per-role restart
proof and verified cleanup. A concrete adapter must implement the factory/store
interface used by these classes, preserving current candidate/process/session
admission and normal platform input. It must supply actual original native
file, execution/code/CommonJS/load/membership/effect, complete manager/picker,
Script service and lifecycle sources. Unknown sources remain errors.

`ScriptFileIO` validates the version 1 original Qt file-source envelope. Its
concrete transport owns the actual nonce, native window/root, clocks and source
identity. The passive inventory is independent of eligible input controls:
hidden surviving managers/pickers cannot disappear behind modal filtering.
`file_scope.join` adds the original file envelope/cursor to the four other
original frames and computes resources from actual presence/bytes. It receives
no expected feature state. `causality` verifies actual callback/result/code and
manager membership after the persisted pre-input barrier.

The shared package uses its own `script-*` journal names and source-kind values.
It does not automatically adopt or reinterpret existing `phone-script-*` files.
A later Phone migration must explicitly preserve and migrate those originals.
The frozen Phone source files and its worktree are unchanged by this extraction.
Shared observations and file-scope joins remain version 2 where the fifth
original frame is mandatory; source/input/feature/history/lock/scope components
retain separately registered version 1 contracts.

Readers persist uncertainty before acquisition and cannot repair a native
session, retime history or replay an input. Both roles independently acquire
originals behind the exact same private source lock and maintain separate
journals. Original process death and new empty startup must be measured before
restart transfer. Actual quiet engine/module/effect/UI absence must precede
file release; separate original location/byte reads must prove actual release.
Both roles retain their final cleanup evidence until hash-bound host retirement.
The internal retirement-only source has no network or fixture credential.

The source-compatible primitives, fixtures and registry entries are recorded in
Pico's [reviewed selection manifest](../pico4/STABLE_PHONE_SELECTION.json).
Native all-known membership uses the narrow `0c2cecbc3f` dependency rather than
later unrelated native Script work/caller instrumentation. The fixture server's
original HTTP404 receipts and read-only adapter credential remain distinct from
runner assertions and independent actor publication.

Device-free source/causality/history/ownership/worker tests prove host logic
only. Native instrumentation is uncompiled; no real input, rendering, lifecycle,
installed client or device is qualified by this package.

The extracted resource join is stricter than the frozen Phone component: a
manager or picker still present in the passive whole-tree inventory remains an
owned panel resource even when the tablet is hidden. Cleanup cannot release
files or retire journals by merely hiding such a consumer. Independent original
panel absence must follow normal close/cancel. This is a new neutral-package
contract; the existing Phone implementation is unchanged and needs explicit
reconciliation. The current acquisition/clock profile is Android epoch-bound;
iOS has different original-source clocks and is not implicitly admitted by this
package. Existing shared primitive iOS readers retain their compatibility.
