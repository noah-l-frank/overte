# Independent repeated original Chat publications

`ChatObservationPublisher` version 1 owns a new unused actor
`ChatObservationCursor` from initial source absence. It requires the actual
independent `Client` and retains that exact client across stage selection.
Every `publish()` queries new native/compiled/view/lifecycle originals through
the cursor, even when the fixture ticket is unchanged. `actorSequence` counts
that complete original actor query history; it is never a private fixture phase
number or a copied primary cursor. The original 26-row `ChatWitness` path is
unchanged and supplies none of this publisher's reported facts.

Read-only preflight uses the actual completed input journal and independent
HTTP phase authority. Expected waiting before the actual normal input finishes,
or before selecting its active source successor, leaves publication/source
intent and query counts unchanged. Once acquisition begins, any uncertainty
is retained and cannot be retried. It is not converted into phase waiting.

The exact measured payload is durably recorded before the one ordinary
independent `POST /samples`. Its bytes contain only this actor's current ticket,
global query sequence, original captured epoch and actual projected facts.
The transport ACK is unused as an observation. Only the common independent
journal reader can establish reception. Lost responses, phase changes, final
copy/write delays or original lock-release delays never permit a resend or
make old target facts fresh. Original native clock functions and the existing
1.5-second bound are checked after the outer source locks release successfully.

Physical source/cursor/publication roots and chunks, exact cached JSON types,
cursor references and payload digests are checked. This actual publisher owns
the cursor's one-time freeze guard; another callback cannot silently replace
it. Failure blocks further cursor queries. Cold or rootless pending histories
are retained. No deletion, adoption, process start, expected-state request,
actual release or whole-feature success API is provided.

Pico's private factory requires the fixed independent actor cursor path and
current binding. The fixed publisher root and rootless chunks keep generic
cleanup closed. Public observer-process dispatch, later native/cache cleanup,
source seals, complete archival/host closure and stereo admission are still
separate work. This packet does not make the old 26-phase parent or its archive
compatible with the new publisher.

`self_tests.test_chat_observation_publisher` checks actual Python owners,
compiled source joins, physical journals and independent journal receipt.
Native/widget/input/clock and HTTP delivery producers are explicit seams. It
proves repeated initial/active observations, original normal Open, non-mutating
pending input, exact lost-POST intent/no-resend, cached mutation and frozen-host
native-age failures. The Pico factory checks use its existing owned stdin peer
fixture, not a product or Assignment Client process. Device acceptance is zero.

The outer source-lock context's actual exit is inside the same failure latch
as the publication body. Its exception freezes the original cursor even when
the inner cursor read, one received POST and final ready CAS already completed.
The regression injects an exception only at depth zero after the actual held
context exited. It was red before that enclosing latch; expected read-only
`PhasePending` still leaves the owner usable before intent.
