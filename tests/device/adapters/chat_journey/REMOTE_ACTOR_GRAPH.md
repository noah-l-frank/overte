# Typed historical independent Chat graph

`ChatRemoteActorGraph` version 2 admits historical original bytes only. It does
not construct `PicoChatCursorActor`, source owners, native readers, descriptor
owners or a new observation from private files. It remains `pending`; it has
no operation that returns a completed process, cleanup or whole-feature result.
The distinct original live-process/nonce/kernel join remains required.

The original typed Parent supplies all fixed paths and expected run, fixture,
bindings, original Actor host identity/instance and original Stop command.
Manifest contents cannot discover a path. The parser admits exactly the current
Actor version 2 or 3 terminal `host-closed` payload, the literal current original
Actor file and physical stamp, original private Stop bytes/stamp and original
source seal. Legacy Actor version 1 gains no qualification. The current Actor's
two captured descriptor pairs must have distinct original handles and nodes;
their historical descriptions alone do not prove kernel closure.

Actor 2 admits only the unchanged exact-current Stop1 grammar. Actor 3 admits
Stop1 or the explicit [Stop2 prefix boundary](../pico4/CHAT_CURSOR_ACTOR.md).
Its mandatory `returnedPublication` certificate must match the final original
publisher row, both sealed root values and their actual physical stamps.
Builtin JSON types and canonical equality are checked; bool/number equivalence
cannot adopt a different stamp. No certificate is invented for legacy Actor 2.

The original seal must enumerate exactly nine fixed graph roots: independent
Publisher/Cursor, Initial/Active/Cleanup observation and sample roots, and the
single unchanged independent witness code root. Every root, original manifest,
frame hash and original physical signature is checked against that seal.
Physical child identities are captured before the complete load and must match
afterward. Rootless extra chunks, changed roots, symlinks, wrong private modes,
changed original directories or same-byte replacements refuse admission.
Existing archive limits bound the original graph's total files and bytes.

Historical validation reuses the original source grammars:

- `samples.compose` and `continuity` recompute actual native Chat, peer, UI,
  keyboard, lifecycle and compiled V8 source packets at their original epochs.
- `validate_transaction` is the existing original root/script/root transaction
  validator, now also called by the unchanged warm code owner method.
- `original_authority`, `observation_sample` and `validate_original_row` are the
  existing original phase/observation grammars, now also called by the warm
  observation owner. Current Parent flow and cleanup admission supply authority.
- `stage_transition` is the existing initial-to-active and active-to-cleanup
  continuity check, now also called by the warm global cursor.
- The parser joins exact local observation references, global cursor sequences,
  original sample hashes, publisher payloads and actual Stop sequence/ticket.

No expected recipe state is passed into source validation. A phase/flow row
supplies input authority only. Historical captured epochs are never advanced
by a new HTTP read or host clock. All three stages must exist; no caller offset,
missing initial absence or old private 26-row witness can replace a global
cursor prefix. This version refuses code continuation extensions rather than
adopting a new source graph shape.

The parser pins original root bytes/stamps, child identities and the complete
validated cache. Subsequent `verify()` rechecks those physical originals,
canonical cache digest and exact builtin JSON/container/signature types. A
failed verification latches failure. Mutable tuples/subclasses cannot preserve
a JSON digest while changing the admitted source types. No original is removed.
The current Actor root is pinned as `host-closed`; a later legitimate
`parent-consumed` successor still needs an explicit controlled return join.

The two source tests use the actual existing Python Actor/seal/source bodies,
actual ordinary first Open, actual cache retirement, and real Linux descriptor
closure. Native producers, original Parent provenance and the remaining 24
input rows stay explicit fixture seams. No observer/product/device process is
started. The first parser run was red after its nine graph validations because
the cache digest attempted to JSON-serialize held bytes (1 case, 9.950 seconds).
Only digest representation changed to SHA-256 of those unchanged held bytes.
The positive then passed in 10.621 seconds, including refusal of an identically
replaced original child. The separate wrong-scope/native-PID/cache-type cases
passed in 11.831 seconds. After the final pair-identity admission check, the
complete two-case module passed in 11.446 seconds. These are historical parser
checks, not process return
or full common-journey qualification. Public Chat capability remains disabled.

The next composition is the actual typed Parent consumption of the original
Actor return, including the controlled `parent-consumed` successor, fresh nonce
echo and actual original process absence. Remote common cleanup must bind the
Stop2 request's consumption digest to actual externally consumed common cleanup
bytes and its requested payload to the original consumed Actor prefix. The
historical parser only checks that prefix against the complete original
publisher graph. It cannot prove external consumption from request metadata.
Stop1 keeps its exact-current requirement.

The explicit [typed return join](REMOTE_ACTOR_RETURN.md) now supplies the one
controlled `parent-consumed` successor through the original neutral receiver.
It retains the original payload cache/stamp, derives every successor field from
the original consumed nonce record, and pins the new physical identity once.
Only that separate typed return's real process-absence finalization consumes the
attached pending graph; the historical parser itself provides no completion.
