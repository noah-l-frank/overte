# Bounded original Phone Graphics image readiness v1

`PhoneGraphicsReadiness` wraps a live version-3 `PhoneGraphicsSamples` under its
already-held shared source lock. Its `read(ticket,after_epoch)` performs only
original measurements and exact scoped measurement retirement. It sends no
ordinary product input, fixture activation, desired setting or expected pixels.
It advertises no complete feature capability. Native instrumentation is uncompiled
and all physical clients remain untested.

The existing common PNG verifier now gives ambiguous/stale/foreign challenge
pixels the specific `MarkerNotReady(AssertionError)` failure with independently
decoded actual marker bits or actual ambiguous cell/RGB. The common verifier
continues to reject those bytes immediately. No common expected-state, byte
comparison, projection/subject or freshness requirement is weakened.

The source producer may retain such a failure only after all other native/view/
UI/Tablet/GPU/hash/provenance checks passed, saving the complete original PNG and
separately proving permanent native memory/callback drainage, complete issued
receipt removal and fresh whole-set absence. Original final clocks and the local
elapsed-age floor remain mandatory. `GraphicsMarkerPending` returns no facts.
Only that same live producer can retire this exact failed acquisition for another
measurement. Recreated pending records, missing/replaced/partial original files,
foreign context, changed phase or incomplete cleanup stay failures.

The wrapper catches only that specific fully proved acquisition outcome. It
preserves an immutable complete rejected-frame/cursor/marker record, independently
checks unchanged actual active/provider phase and empty GPU-owner journal, then
acquires an entirely new original frame. It never reuses a prior good image,
retimes an original, changes a setting, repeats user input or treats a rejected
image as current. Actual rendered-marker convergence after normal scene/page
loading can therefore be observed without reconstructing lost provenance.

At most sixteen new acquisitions are allowed within a 20-second whole readiness
budget, with at most one second between attempts. Each acquisition retains its
existing native/file/freshness budgets and must retire its own ownership before
retry. The final returned result must independently pass all original common
image checks and current freshness. A persistent wrong/missing marker exhausts
the bound and returns no sample, even when an earlier good frame remains stored
as historical evidence. Other source, geometry, hash, file and cleanup failures
are terminal and never enter this retry path.

The v3 source journal retains up to 64 immutable rejected marker records with
their actual sequence, original frame, active/provider observations, complete
source cursors and original marker diagnostic. Later acquisitions cannot mutate
those saved prefixes. Pure archives revalidate the actual original PNG bytes,
marker diagnostic and native/file retirement. Version 1/2 source journals are
refused without migration; no original/cursor prefix is fabricated.

Sixteen focused host cases exercise synthetic original source clocks/pixels and
real private PNG/receipt/journal files. They cover stale and ambiguous frames
followed by new actual ready pixels, persistent failure, refused cached fallback,
immutable cursor snapshots, refused pending reconstruction, ignored memory/file/
journal retirement, missing/replaced originals, unrelated source failure, forged
marker/capture/role/sequence history, changed-ticket retirement, SDK-free archives,
deadline costs and frozen native clocks. The combined original-source/effect/
measurement/shared-evidence selection passes 99 cases; the broader ownership/
restart/all-common-journey selection passes 266 cases. These establish adapter/
test logic only; complete independent Graphics orchestration and fixture/Web
lifetime retirement remain required before activation.
