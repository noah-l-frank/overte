## Privacy and omissions

Only allowlisted `.py`, source `.js`, source documentation and the fixed
controller `profile.json` are copied. No generated SDK/run/access configuration,
private environment file, credential/token/certificate, account/device selector,
APK/JAR/WAV/image/archive, raw stdio/HTTP body, runtime original, log, result or
evidence inventory is exported. Broad old source/stat/hash manifests are omitted.
Superseded version trees already represented by the current composite are also
omitted. Runtime originals/evidence remain untouched in their original private
locations and are not included in this backup.

Static content review found no private-key blocks, recognizable provider/API
credentials, JWTs or credential-bearing URLs. Credential values in harnesses
are generated at runtime or read from a runtime configuration that is not
exported. Fixed fake fingerprints, repeated-character fixtures, standard
OpenXR profile paths, `31:456`, and named synthetic targets such as
`private-wire-settlement-target` are test constants, not real device/account
selectors. No product test or build was run for this static export review.
